# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — Трассировка — это именно выполнение по шагам с фиксацией состояний, а не запись или перевод.
2. **в** — Условие проверяется перед каждой итерацией и ещё один раз, когда оно оказывается ложным.
3. **в** — div даёт целую часть от деления, дробная часть отбрасывается.
4. **б** — В неполной форме нет ветви «иначе», поэтому при ложном условии управление сразу передаётся дальше.
5. **в** — Без записи состояний ошибку невозможно найти: непонятно, на каком шаге значение разошлось с верным.

### Ответы к Части Б (макс. 4 балла)

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Чётные i прибавляются, нечётные вычитаются. Сумма чётных: 2 + 4 + 6 + 8 + 10 = 30. Сумма нечётных: 1 + 3 + 5 + 7 + 9 = 25. Итог: s = 30 − 25 = 5. По шагам: после i = 1 s = −1, после i = 2 s = 1, после i = 3 s = −2, после i = 4 s = 2, после i = 5 s = −3, после i = 6 s = 3, после i = 7 s = −4, после i = 8 s = 4, после i = 9 s = −5, после i = 10 s = 5. Ответ: s = 5.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Итерация 1: a = 2, b = 2. Итерация 2: a = 4, b = 3. Итерация 3: a = 8, b = 4. Итерация 4: a = 16, b = 5. Итерация 5: a = 32, b = 6. Проверка 32 < 20 ложна, цикл завершён. Ответ: a = 32, b = 6, проверок условия шесть: пять истинных и одна ложная.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Шаги: 5074 div 10 = 507, k = 1; 507 div 10 = 50, k = 2; 50 div 10 = 5, k = 3; 5 div 10 = 0, k = 4. Условие 0 > 0 ложно, цикл завершён. Ответ: k = 4 — алгоритм подсчитывает количество цифр в десятичной записи числа, отбрасывая по одной цифре за итерацию.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
