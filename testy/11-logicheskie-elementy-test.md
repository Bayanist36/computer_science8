# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — Элемент И даёт единицу только при единицах на всех входах, а здесь один вход равен 0.
2. **в** — Инверсия переводит 0 в 1 и 1 в 0, поэтому элемент НЕ называют инвертором.
3. **в** — Каждый из трёх входов принимает два значения, поэтому наборов 2³ = 8.
4. **в** — ¬(A ∧ A) = ¬A, поэтому элемент И—НЕ с объединёнными входами работает как инвертор.
5. **г** — Конъюнкция равна единице только тогда, когда оба операнда равны единице.

### Ответы к Части Б (макс. 4 балла)

**6\.** A ∨ B = 1, инверсия даёт 0, F = 0 ∧ 1 = 0. Ответ: 0.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** Три входа дают 8 строк. Столбцы: A, B, C, A ∧ B, ¬C, F — всего 6.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Восемь наборов. Промежуточные сигналы: A ∧ B и его инверсия, а также ¬C. Наборы 000–101: A ∧ B = 0, значит, первое слагаемое равно 1, и F = 1 независимо от C. Набор 110: A ∧ B = 1, первое слагаемое 0, ¬C = 1, F = 1. Набор 111: первое слагаемое 0, ¬C = 0, F = 0. Ответ: F = 0 только на наборе 111.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Четыре набора. 00: A ∨ B = 0, слева 1; ¬A = 1, ¬B = 1, справа 1. 01: A ∨ B = 1, слева 0; справа 1 ∧ 0 = 0. 10: слева 0; справа 0 ∧ 1 = 0. 11: A ∨ B = 1, слева 0; справа 0 ∧ 0 = 0. Значения в обеих частях совпали на всех наборах, закон верен.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

F = (A ∧ B) ∨ (A ∧ C) ∨ (B ∧ C). Восемь наборов: 000, 001, 010, 100 дают 0 (сработал не более один датчик); 011, 101, 110 дают 1 (сработали два); 111 даёт 1 (сработали три). Ответ: F = 1 на четырёх наборах из восьми.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
