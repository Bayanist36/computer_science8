### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Блок-схема: Начало → ввод price, count → S := price * count → вывод S → Конец, все блоки соединены одной стрелкой сверху вниз. Трассировка: шаг 0 — price = 120, count = 3, S не определена; шаг 1 — S = 360; шаг 2 — вывод 360. Ответ: 360.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Ошибка в порядке: ввод m стоит после первого вычисления, поэтому команда h := m div 60 попытается использовать переменную m, которой ещё нет. Исправленный порядок: ввод m → h := m div 60 → r := m mod 60 → вывод h, r. При исходной записи исполнитель остановится с ошибкой обращения к неопределённой переменной и результат не будет получен.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Перестановка меняет результат, если вторая команда использует значение, которое изменяет первая. Пример: x = 5; x = x * 2; y = x + 1 даёт y = 11, а после перестановки y = x + 1; x = x * 2 получим y = 6. Безопасна перестановка независимых команд: например, a = 2; b = 3; s = a + b — здесь присваивания a и b не зависят друг от друга, и результат не изменится.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
