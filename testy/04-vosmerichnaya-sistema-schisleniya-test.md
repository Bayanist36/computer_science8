# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **в** — Максимальная цифра в записи — 7, значит, основание должно быть больше семи, то есть не меньше 8.
2. **б** — Поскольку 8 = 2³, каждая восьмеричная цифра кодируется ровно тремя двоичными разрядами.
3. **в** — Старший разряд имеет вес 8² = 64, поэтому 100₈ = 64₁₀.
4. **б** — Младший разряд должен оказаться в конце последней триады, поэтому разбиение начинают справа.
5. **в** — В восьмеричной системе допустимы только цифры от 0 до 7, поэтому цифры 8 и 9 в записи невозможны.

### Ответы к Части Б (макс. 4 балла)

**6\.** 2 → 010, 7 → 111, 4 → 100; получаем 010111100₂, то есть 10111100₂.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** 001 101 011 → 1, 5, 3, значит, 153₈, что в десятичной системе равно 107.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Через развёрнутую форму: 7·64 + 5·8 + 3 = 448 + 40 + 3 = 491. Через двоичную запись: 753₈ = 111 101 011 = 111101011₂; разворачиваем: 256 + 128 + 64 + 32 + 8 + 2 + 1 = 491. Результаты совпали: 753₈ = 491₁₀.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

500 : 8 = 62 (остаток 4); 62 : 8 = 7 (6); 7 : 8 = 0 (7). Читаем снизу вверх: 764₈. Проверка: 7·64 + 6·8 + 4 = 448 + 48 + 4 = 500. Через двоичную запись: 764₈ = 111 110 100 = 111110100₂; 256 + 128 + 64 + 32 + 16 + 4 = 500. Оба способа дают одно значение.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

У числа 40₈ старший разряд весит 8¹ = 8 и равен 4, значит, значение равно 4·8 = 32. У числа 100000₂ единственная единица стоит в разряде с весом 2⁵ = 32, значит, значение тоже 32. Числа равны: 40₈ = 100000₂ = 32₁₀. Сравнивать записи «по виду» нельзя: 40₈ выглядит как сорок, хотя означает 32, а шесть знаков двоичной записи означают то же самое число.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
