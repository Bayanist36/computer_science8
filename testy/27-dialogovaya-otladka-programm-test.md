# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **в** — Программа синтаксически верна и не падает, но алгоритм или условие записаны неверно.
2. **б** — При достижении отмеченной строки выполнение приостанавливается и управление переходит к отладчику.
3. **в** — Это главное средство отладчика: видно, чему равна каждая переменная именно сейчас.
4. **в** — Сравнение ожидаемого с фактическим на простых данных сразу показывает, где расхождение.
5. **б** — Без метки непонятно, какая строка напечатала число, особенно если выводов несколько.

### Ответы к Части Б (макс. 4 балла)

**6\.** Синтаксическая ошибка: после строки с двоеточием (например, после if) ожидался блок с отступом, а его нет. Нужно выделить тело ветки четырьмя пробелами.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** Выведется «ноль»: первое условие ложно, второе истинно.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Действуем делением области пополам. Ставим точку останова в строке 32 и смотрим, верны ли значения переменных: если верны, ошибка ниже, если нет — выше. Затем ставим точку в середине оставшейся половины (48 или 16) и повторяем. Каждая проверка уменьшает область вдвое: 64 → 32 → 16 → 8 → 4 → 2 → 1, то есть шесть остановок достаточно, чтобы указать строку. После каждой остановки сравниваем значения с ожидаемыми по алгоритму и фиксируем первую точку, где они расходятся.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Второе условие повторяет первое (`x > 0`), поэтому ветка вычитания недостижима: для отрицательных и нуля не выполняется ни одна ветка, и число печатается без изменений. Правильно: `elif x < 0:`. Тогда при x = 5 получаем 6, при x = −5 получаем −6, при x = 0 остаётся 0.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Отладчик: показывает все переменные сразу, без правки кода, позволяет двигаться вперёд по шагам и возвращаться к другому месту, не меняя программу. Его минусы — нужно освоить среду и расставить остановки, а саму программу иногда нельзя запустить под отладчиком (например, она читает данные из файла в чужой среде). print: не требует инструментов, работает в любой среде и в длинном цикле, легко копируется в отчёт; но значения видны только в точках печати, нужно править код и потом убирать вывод. print выбирают, когда задача маленькая, среда недоступна или нужно зафиксировать много значений подряд в цикле.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
