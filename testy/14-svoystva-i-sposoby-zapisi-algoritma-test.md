# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — Дискретность — это разбиение на отдельные законченные шаги, между которыми нет «половинок».
2. **в** — Массовость — пригодность алгоритма для целого класса однотипных задач.
3. **в** — Условие изображается ромбом, из которого выходят две стрелки — «да» и «нет».
4. **а** — Условие всё время остаётся истинным, поэтому выполнение никогда не закончится.
5. **б** — Формальный исполнитель понимает только команды своей СКИ; остальные для него не существуют.

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Словесно: 1) ввести число рублей r; 2) умножить r на 100; 3) вывести результат. Блок-схема: Начало → ввод r → k := r · 100 → вывод k → Конец. Программа: r = int(input()); k = r * 100; print(k). Проверка: 27 · 100 = 2700 копеек. Все три записи описывают один линейный алгоритм и дают одинаковый результат.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Нарушена определённость («немного денег», «все продукты» — неточные величины), понятность (команда «купите продукты» не входит в СКИ формального исполнителя — это цель, а не команда), дискретность (нет чётких шагов с условиями и границами), результативность (ожидание «пока не откроется» и повтор «пока не купите всё» не гарантируют завершения). Массовость формально есть, но остальные четыре свойства нарушены, поэтому алгоритмом описание не является.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

На каждом шаге пара (a, b) заменяется парой (b, a mod b). Остаток от деления всегда строго меньше делителя, поэтому новое значение b меньше старого. Последовательность натуральных значений b строго убывает, а ниже нуля опуститься не может: конечная убывающая последовательность натуральных чисел обрывается. Значит, через конечное число шагов b станет равно нулю, и цикл завершится — свойство результативности выполнено.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
