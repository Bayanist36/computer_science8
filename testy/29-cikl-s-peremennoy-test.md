# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — range(1, 10) содержит числа от 1 до 9, то есть 9 значений.
2. **в** — Начало 2, шаг 2, правая граница 9 не входит, поэтому последнее значение — 8.
3. **б** — Граница 101 нужна потому, что правая граница range в диапазон не входит.
4. **в** — Нулевой остаток означает деление нацело, то есть d — делитель n.
5. **г** — Делители образуют пары с произведением n, поэтому один из пары всегда не больше корня.

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Суммируются числа от 1 до 20, кратные 3: 3, 6, 9, 12, 15, 18. Их сумма 3 + 6 + 9 + 12 + 15 + 18 = 63. На экран выводится 63. Условие проверяется на каждом из 20 шагов, но к накопителю прибавляются только шесть значений.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Перебираем d от 2 до корня из 119, то есть до 10. На d = 7 получаем 119 % 7 = 0, поскольку 7 · 17 = 119. Делитель найден, значит, число составное; флаг is_prime получает False, цикл прерывается по break. Ответ: 119 = 7 · 17, число составное.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Количество цифр числа зависит от самого числа и заранее неизвестно: у 7 одна цифра, у 4729 — четыре. Цикл for с range требует известного числа повторений, а while естественно останавливается по условию n > 0. Фрагмент: n = 4729; s = 0; while n > 0: s += n % 10; n //= 10. После выполнения s = 22.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
