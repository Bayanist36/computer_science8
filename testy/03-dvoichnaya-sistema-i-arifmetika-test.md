# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — Две единицы одного разряда дают ноль в этом разряде и перенос единицы в следующий: 1 + 1 = 10₂.
2. **в** — 1023 = 1111111111₂ — десять единиц; число 1024 = 2¹⁰ требует уже одиннадцати разрядов.
3. **в** — В записи 102101 присутствуют цифры 2, которых в двоичной системе не существует.
4. **г** — Единственная единица старшего разряда разменивается последовательно, все младшие разряды становятся единицами: 16 − 1 = 15 = 1111₂.
5. **б** — Первый полученный остаток — младший разряд, поэтому запись читается от последнего остатка к первому.

### Ответы к Части Б (макс. 4 балла)

*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Уравниваем записи по длине: 110010 и 010111. Разряд 0: 0 − 1, занимаем у разряда 1, где стоит единица; она становится нулём, текущий разряд получает две единицы: 2 − 1 = 1. Разряд 1: теперь там 0, снова 0 − 1; разряды 2 и 3 нулевые, поэтому заём идёт цепочкой до разряда 4, где стоит единица: она становится нулём, разряд 3 получает две единицы, одну оставляет себе, одну отдаёт разряду 2; разряд 2 оставляет одну и отдаёт одну разряду 1. Получаем 2 − 1 = 1. Разряд 2: 1 − 1 = 0. Разряд 3: 1 − 0 = 1. Разряд 4: 0 − 1, занимаем у разряда 5: 2 − 1 = 1. Разряд 5: 0 − 0 = 0. Результат: 011011, то есть 11011₂. Проверка: 110010₂ = 50, 010111₂ = 23, 50 − 23 = 27, а 11011₂ = 16 + 8 + 2 + 1 = 27 — совпало.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Деление: 1000 → 500 (0) → 250 (0) → 125 (0) → 62 (1) → 31 (0) → 15 (1) → 7 (1) → 3 (1) → 1 (1) → 0 (1). Остатки снизу вверх: 1111101000. Вычитание степеней: 512 (остаток 488), 256 (232), 128 (104), 64 (40), 32 (8), 8 (0) — единицы в разрядах 9, 8, 7, 6, 5 и 3, остальные нули: 1111101000. Первый способ потребовал 10 делений, второй — 6 вычитаний, но второй требует помнить степени и аккуратно считать остатки. Оба дают 1000 = 512 + 256 + 128 + 64 + 32 + 8.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Наибольшее n-разрядное двоичное число равно 2^n − 1 (это n единиц). Сумма двух таких чисел не превышает 2·(2^n − 1) = 2^(n+1) − 2, что меньше 2^(n+1). Значит, для записи результата достаточно n + 1 разряда и больше никогда не потребуется. Лишний разряд появляется тогда и только тогда, когда сумма достигает 2^n, то есть когда перенос выходит за старший разряд. Пример: 1101₂ + 1011₂ = 11000₂ — было по четыре разряда, получилось пять (13 + 11 = 24, а 24 не меньше 16 = 2⁴). Пример без лишнего разряда: 1010₂ + 0101₂ = 1111₂ (10 + 5 = 15, что меньше 16), результат уложился в четыре разряда.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
