### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

После `a = b` в переменной a оказывается значение b, а прежнее значение a теряется. Затем `b = a` просто повторяет то же значение, поэтому обе переменные равны. Нужна третья переменная: `t = a`, `a = b`, `b = t`, либо запись `a, b = b, a`, где правая часть вычисляется до присваивания.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

При y = 0 возникает ошибка ZeroDivisionError, так как делить на ноль нельзя. При любых других целых значениях программа выведет результат деления, причём тип результата будет float.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Утверждение неверно. Переменная — одна ячейка с одним текущим значением; при присваивании новое значение заменяет старое, и вернуть прежнее без отдельного сохранения в другой переменной нельзя. Чтобы сохранить оба значения, нужны две переменные, например `x1 = 10` и `x2 = 20`.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
