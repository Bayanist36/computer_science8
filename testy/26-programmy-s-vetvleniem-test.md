### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Три числа можно упорядочить обменами: сравниваем пары и при необходимости меняем значения местами — `if a > b: a, b = b, a`, затем `if b > c: b, c = c, b` и снова `if a > b: a, b = b, a`. Одной ветки мало, потому что результат зависит не от одного сравнения, а от соотношения всех трёх чисел: после обмена первых двух порядок со вторым и третьим может снова нарушиться, поэтому нужны три последовательные проверки.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Вместо and использована операция or, поэтому достаточно выполнения одного из требований. Контрпример: x = 3 — число положительное, но нечётное, однако первое условие истинно, и программа выводит «да». Правильно: `if x > 0 and x % 2 == 0:`.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Условие: `(year % 4 == 0 and year % 100 != 0) or year % 400 == 0`. Для 1900 первая часть ложна (делится на 100), вторая ложна (на 400 не делится) — не високосный. Для 2000 вторая часть истинна — високосный. Для 2023 год не делится на 4 — не високосный. Для 2024 первая часть истинна — високосный. Порядок проверок и скобки здесь принципиальны: без скобок and связался бы только с последним сравнением, и правило «делится на 100» перестало бы работать.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
