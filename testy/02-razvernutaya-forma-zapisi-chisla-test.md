# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — Вес разряда — это p в степени номера разряда, именно на него умножается цифра.
2. **б** — Основание равно 2, старший разряд четырёхзначного числа имеет номер 3.
3. **в** — 2·64 + 7·8 + 3 = 128 + 56 + 3 = 187.
4. **б** — В записи пять цифр, значит, пять слагаемых — по одному на каждый разряд, включая нулевые.
5. **в** — Разряды нумеруются с нуля, поэтому у n цифр старший номер равен n − 1.

### Ответы к Части Б (макс. 4 балла)

**6\.** B = 11, поэтому 1·16 + 11 = 27.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** 1·2⁴ + 1·2³ + 0·2² + 1·2¹ + 1·2⁰ = 16 + 8 + 0 + 2 + 1 = 27.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

745₈ = 7·8² + 4·8¹ + 5·8⁰ = 7·64 + 4·8 + 5 = 448 + 32 + 5 = 485. По схеме Горнера: 7 → 7·8 + 4 = 60 → 60·8 + 5 = 485. Результаты совпадают.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Разворачиваем: 1·x² + 2·x + 1 = 16, то есть x² + 2x − 15 = 0. Корни: x = 3 и x = −5; отрицательное значение не подходит. Проверка: 121₃ = 9 + 6 + 1 = 16, цифры 1 и 2 допустимы при основании 3. Ответ: x = 3.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

У числа 1001₂ четыре разряда, старший вес равен 2³ = 8, поэтому значение заведомо меньше 16: 1001₂ = 8 + 1 = 9. У числа 21₈ два разряда, старший вес 8¹ = 8, вклад старшей цифры 2·8 = 16, плюс единица: 21₈ = 17. Следовательно, 1001₂ меньше 21₈. Длина записи здесь ничего не решает: у 1001₂ четыре знака, у 21₈ всего два, но каждая восьмеричная цифра «весит» втрое больше двоичной.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
