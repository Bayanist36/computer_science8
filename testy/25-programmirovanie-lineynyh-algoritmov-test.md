# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — В линейном алгоритме нет ветвлений и циклов, порядок команд фиксирован.
2. **в** — Две звёздочки — операция возведения в степень.
3. **б** — `//` берёт только целую часть, дробная отбрасывается.
4. **в** — Остаток от деления 17 на 5 равен 2, так как 17 = 3 * 5 + 2.
5. **в** — Деление на ноль недопустимо, Python сообщает ZeroDivisionError.

### Ответы к Части Б (макс. 4 балла)

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Деление имеет более высокий приоритет, чем сложение, поэтому в первом выражении сначала делится b, а потом прибавляется a. При a = 5 и b = 4 первое даёт 5 + 2 = 7, второе — 9 / 2 = 4.5. Скобки заставляют сначала вычислить сумму.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Часы: 8000 // 3600 = 2. Остаток: 8000 % 3600 = 800. Минуты: 800 // 60 = 13. Секунды: 8000 % 60 = 20. Ответ: 2 часа 13 минут 20 секунд; проверка 7200 + 780 + 20 = 8000.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Операция `//` возвращает только целую часть, поэтому остаток отбрасывается. Первый способ — использовать обычное деление: `print(7 / 2)` даст 3.5. Второй — вычислить целую часть и остаток отдельно и собрать результат: `print(7 // 2 + 7 % 2 / 2)`, что также даёт 3.5.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
