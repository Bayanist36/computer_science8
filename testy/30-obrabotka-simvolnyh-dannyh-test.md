# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — В слове шесть латинских букв, len("Python") возвращает 6.
2. **в** — Отрицательный индекс −1 указывает на последний символ, то есть на «а».
3. **в** — Срез берёт индексы 3, 4, 5, 6, 7 — символы «г», «р», «а», «м», «м».
4. **в** — Буква «о» стоит на позициях 1, 3 и 5, всего три вхождения.
5. **в** — Буквы «я» в слове нет, поэтому find возвращает −1 как признак отсутствия.

### Ответы к Части Б (макс. 4 балла)

**6\.** len(s) = 11, s[2:5] = 'дир'.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** 5 букв: выражение "Абракадабра".lower().count("а") даёт 5, а прямое count("а") — только 4 строчные буквы.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Программа считает гласные буквы. Символы «и», «о», «а», «и», «а» входят в перечисленный набор, поэтому счётчик увеличивается пять раз. На экран выводится 5. Согласные «н», «ф», «р», «м», «т», «к» условию не удовлетворяют.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

«довод» — палиндром. Срез s[::-1] перечисляет символы с шагом −1, то есть от последнего к первому, и даёт перевёрнутую строку. Сравнение с исходной строкой истинно ровно тогда, когда чтение в обе стороны совпадает, поэтому проверка корректна для любого слова. Для «машина» перевёртыш «анишам» не равен исходному, значит, слово не палиндром.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Строки в Python неизменяемы: нельзя заменить отдельный символ по индексу, поэтому присваивание s[0] вызывает TypeError. Правильно собрать новую строку из частей: s = "р" + s[1:] — новый символ склеивается с хвостом старой строки, получается «рама».

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
