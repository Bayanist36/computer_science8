### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Итерация 1: a = 1071, b = 462, остаток 1071 − 2 · 462 = 147, новая пара (462, 147). Итерация 2: 462 − 3 · 147 = 21, новая пара (147, 21). Итерация 3: 147 − 7 · 21 = 0, новая пара (21, 0). Условие b != 0 ложно, цикл завершён, ответ взят из a. НОД(1071, 462) = 21. Проверка: 1071 = 21 · 51, 462 = 21 · 22, числа 51 и 22 взаимно просты.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

В теле цикла число n не изменяется: последняя цифра каждый раз одна и та же, условие n > 0 всегда истинно, поэтому цикл бесконечен. Нужно добавить `n = n // 10` (или `n //= 10`) в тело цикла с тем же отступом. После исправления сумма цифр числа 4729 равна 22, и цикл завершается за 4 повторения.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Причина первая: условие n > 0 для нуля ложно с самого начала, тело не выполняется ни разу, поэтому сумма и количество остаются нулевыми, хотя в записи числа 0 одна цифра. Причина вторая: для отрицательного числа условие тоже ложно сразу, потому что −4729 < 0. Исправление: сначала взять модуль (n = abs(n)), а случай нуля обработать отдельно до цикла — если n == 0, то сумма 0 и количество 1, иначе выполнять цикл `while n > 0`. После правки 0 даёт 0 и 1, а −4729 даёт 22 и 4, как и 4729.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
