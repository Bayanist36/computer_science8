### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

90: первая проверка 90 >= 85 истинна — 1 проверка, оценка 5. 75: 75 >= 85 ложно, 75 >= 70 истинно — 2 проверки, оценка 4. 55: первые две ложны, 55 >= 50 истинно — 3 проверки, оценка 3. 40: три первых ложны, 40 >= 30 истинно — 4 проверки, оценка 2. *Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Условие: (y % 4 == 0 and y % 100 != 0) or y % 400 == 0. 1900: делится на 4, но делится и на 100, а на 400 — нет, значит, не високосный. 2000: делится на 400 — високосный. 2024: делится на 4 и не делится на 100 — високосный.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Схема рассуждения: если a > b, то сравниваем a и c, иначе сравниваем b и c, присваивая максимум. Для a = 5, b = 9, c = 9: первая проверка 5 > 9 ложна, идём в ветвь «иначе»; проверка 9 > 9 ложна, выполняется внутренняя ветвь «иначе» и mx = c = 9. При равных числах строгие сравнения дают ложь, поэтому выбирается последнее из равных значений — результат всё равно верный, максимум найден.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
