# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — При A = 1 дизъюнкция равна 1 независимо от B, остальные выражения при этом наборе дают 0.
2. **б** — Сначала конъюнкция: 0 ∧ 1 = 0, затем инверсия даёт 1.
3. **в** — Число наборов равно 2³ = 8, каждый набор — отдельная строка.
4. **а** — Кружок на выходе означает инверсию результата, поэтому схема И с кружком даёт ¬(A ∧ B).
5. **а** — Конъюнкция равна 1 только на наборе 11, поэтому в столбце одна единица.

### Ответы к Части Б (макс. 4 балла)

**6\.** A ∨ B = 1, инверсия даёт 0, F = 0 ∧ 1 = 0. Ответ: 0.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** Пять наборов: 001, 011, 101, 110, 111. В четырёх из них C = 1, ещё один набор 110 даёт единицу за счёт A ∧ B.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Восемь наборов. Промежуточные сигналы: ¬B и A ∨ ¬B. 000: ¬B = 1, A ∨ ¬B = 1, C = 0, F = 0. 001: 1 ∧ 1 = 1. 010: ¬B = 0, A ∨ ¬B = 0, F = 0. 011: 0 ∧ 1 = 0. 100: ¬B = 1, A ∨ ¬B = 1, C = 0, F = 0. 101: 1 ∧ 1 = 1. 110: ¬B = 0, A ∨ ¬B = 1, C = 0, F = 0. 111: 1 ∧ 1 = 1. Ответ: F = 1 на наборах 001, 101, 111.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Четыре набора. 00: A ∧ B = 0, слева 1; ¬A = 1, ¬B = 1, справа 1 ∨ 1 = 1. 01: A ∧ B = 0, слева 1; справа 1 ∨ 0 = 1. 10: A ∧ B = 0, слева 1; справа 0 ∨ 1 = 1. 11: A ∧ B = 1, слева 0; справа 0 ∨ 0 = 0. Значения совпали на всех наборах, закон выполняется.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

F = A ∧ B ∧ ¬C. Восемь наборов; F = 1 только на наборе 110, где A = 1, B = 1, C = 0. На наборе 111 перегрузка есть, поэтому ¬C = 0 и лифт не поедет. Ответ: движение начинается на одном наборе из восьми.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
