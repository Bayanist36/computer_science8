## ЧАСТЬ А. Задания с выбором одного варианта ответа (1 балл за правильный ответ)

**1\. Какая конструкция называется циклом?**
а) последовательность команд, которая выполняется один раз
б) последовательность команд, которая выполняется несколько раз
в) команда, которая проверяет условие
г) набор команд, из которого выбирается одна

**2\. Сколько раз выполнится тело конструкции «нц 12 раз … кц»?**
а) 11
б) 13
в) 12
г) зависит от условия внутри тела

**3\. Что называют телом цикла?**
а) условие, при котором цикл прекращается
б) число повторений
в) команды, которые повторяются
г) переменную, считающую шаги

**4\. Чем цикл с постусловием отличается от цикла с предусловием?**
а) в нём нельзя использовать счётчик
б) он всегда выполняется бесконечное число раз
в) его тело выполняется хотя бы один раз
г) в нём условие не проверяется вообще

**5\. Почему алгоритм «i := 1; нц пока i <= 10: s := s + i; кц» не завершается?**
а) в нём нет команды вывода
б) в нём неправильно записано условие
в) переменная i не изменяется внутри тела
г) сумма s превышает допустимое значение

# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — Цикл — конструкция повторения: его тело выполняется несколько раз подряд.
2. **в** — Число повторений задано в заголовке, условие внутри не проверяется.
3. **в** — Тело — часть цикла между заголовком и «кц», она выполняется на каждом повторении.
4. **в** — Проверка идёт после тела, поэтому первое выполнение происходит всегда.
5. **в** — Условие всегда остаётся истинным, потому что i не меняется, — получается бесконечный цикл.

### Ответы к Части Б (макс. 4 балла)

**6\.** Четыре повторения (i = 1, 3, 5, 7), s = 16.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** нц 5 раз: закрасить; вправо; кц, затем закрасить. Пять шагов между шестью клетками, последняя закрашивается без движения.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

В цикле с предусловием условие проверяется до тела: 200 меньше 100 — ложно, тело не выполняется, результат остаётся 200. В цикле с постусловием тело выполняется до первой проверки: 200 удваивается до 400, затем проверяется условие выхода, и цикл завершается. Ответы: 200 и 400.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Строки таблицы: i = 1, s = 1; i = 2, s = 5; i = 3, s = 14; i = 4, s = 30; i = 5, s = 55. Результат s = 55, тело выполнилось 5 раз.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Первая ошибка: первая клетка не закрашена, потому что тело начинается с шага. Вторая: восьмая команда «вправо» неприменима, справа стена, — отказ. Правильно: закрасить; нц 7 раз: вправо; закрасить; кц — восемь клеток закрашены, отказа нет.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
