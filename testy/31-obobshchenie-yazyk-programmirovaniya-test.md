### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Программа считает количество чисел от 1 до 100, которые делятся на 3 или на 5. Кратных 3 среди них 33, кратных 5 — 20, кратных 15 — 6, эти числа посчитаны дважды. По формуле включений и исключений: 33 + 20 − 6 = 47. На экран выводится 47.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Функция input() возвращает строку, поэтому сравнение n > 0 и операция n % 10 неприменимы к тексту — возникает TypeError. Нужно сразу преобразовать ввод в число: n = int(input()). Остальная логика верна: s накапливает цифры, n // 10 отбрасывает последнюю цифру, цикл идёт до нуля. Для n = 4729 программа выведет 22.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Выбираем цикл for по возможным делителям от 2 до корня из n и флаг is_prime, потому что количество проверок определяется самим числом. Код: n = int(input()); is_prime = True; for d in range(2, int(n ** 0.5) + 1): if n % d == 0: is_prime = False; break; затем ветвление с выводом «простое» или «составное». Для n = 91 делитель 7 найден сразу, флаг становится False, выводится «составное»; для n = 97 флаг остаётся True.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
