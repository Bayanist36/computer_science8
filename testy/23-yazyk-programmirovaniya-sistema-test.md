### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Интерпретатор переводит и выполняет команды по очереди: строки до ошибки уже выполнены, а на ошибочной он останавливается. Компилятор сначала переводит весь текст целиком, и любая ошибка обнаруживается до запуска, поэтому частичного выполнения быть не может.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Синтаксис записи верен, поэтому интерпретатор начнёт выполнение и при вызове неизвестного имени `prnt` остановится с ошибкой NameError — имя не определено. Это ошибка времени выполнения, а не синтаксическая. Исправление: написать `print("Привет")`.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Два значения в скобках должны быть разделены запятой, а слово — заключено в кавычки, иначе Python попытается прочитать `год` как имя и выдаст синтаксическую ошибку. Правильно: `print(2026, "год")`; на экране появится `2026 год`.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
