# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **в** — В алфавите шестнадцать знаков: десять цифр и шесть букв, поэтому основание равно 16.
2. **в** — 32 + 8 + 4 + 1 = 45: единицы стоят в разрядах 5, 3, 2 и 0.
3. **б** — «не A» требует A = 0, «и B» требует B = 1; оба условия выполняются только на наборе 0 и 1.
4. **в** — Результативность означает, что работа обязательно заканчивается получением результата за конечное число шагов.
5. **в** — range(1, 6) содержит числа 1, 2, 3, 4, 5 — пять значений, правая граница не входит.

### Ответы к Части Б (макс. 4 балла)

**6\.** 3751₈ и 7E9₁₆. Проверка: 3 · 512 + 7 · 64 + 5 · 8 + 1 = 2025 и 7 · 256 + 14 · 16 + 9 = 2025.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** 6. Остатки: 10 % 3 = 1, 8 % 3 = 2, 6 % 3 = 0, 4 % 3 = 1, 2 % 3 = 2; сумма 1 + 2 + 0 + 1 + 2 = 6, после шага a = 0 цикл завершается.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Сумма цифр 2 + 0 + 2 + 5 = 9, поэтому число делится на 9, а значит, и на 3 — первое простое высказывание истинно. Сумма цифр 9 больше 8 — второе истинно, их конъюнкция истинна. Число 2025 оканчивается на 5, оно нечётное, значит, высказывание «2025 — чётное» ложно. Итог: истина или ложь даёт истину. Ответ: высказывание истинно.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Условие требует одновременной кратности двум и трём, то есть кратности шести. В диапазоне от 1 до 20 это числа 6, 12 и 18. Накопитель: 6, затем 18, затем 36. Ответ: 36. Если заменить and на or, в сумму попадут все чётные и все кратные трём числа, и результат станет другим.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

45 = 32 + 8 + 4 + 1 = 101101₂, единиц четыре. Простейшая проверка: n = int(input()); print(bin(n).count('1')). Вариант без встроенной функции: k = 0; while n > 0: if n % 2 == 1: k = k + 1; n = n // 2; print(k). Для 45 цикл даёт k = 4, что совпадает с ручным подсчётом.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
