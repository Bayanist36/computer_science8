# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **в** — Старшинство задаёт приоритет: отрицание, конъюнкция, дизъюнкция.
2. **а** — Сначала 1 ∨ 0 = 1, затем отрицание даёт 0.
3. **б** — ¬A = ¬0 = 1, затем 1 ∧ 1 = 1.
4. **в** — Союз «и» даёт конъюнкцию, а «не» относится только к B.
5. **в** — 0 ∨ 0 ∨ 1 = 1; в остальных вариантах есть множитель, равный нулю.

### Ответы к Части Б (макс. 4 балла)

**6\.** 1 — а (A ∨ B в скобках), 2 — б (отрицание результата), 3 — в (конъюнкция с C).
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** а) 0 ∨ 1 = 1; б) 1 ∨ 0 = 1; в) 0 ∧ 0 = 0; г) ¬0 ∧ 1 = 1 ∧ 1 = 1. Ответы: 1, 1, 0, 1.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

1) A ∧ B = 1 ∧ 1 = 1. 2) ¬(A ∧ B) = ¬1 = 0. 3) 0 ∨ C = 0 ∨ 0 = 0. Ответ: 0. Скобки заставляют сначала вычислить конъюнкцию и лишь затем её отрицать; без скобок запись ¬A ∧ B ∨ C означала бы «(не A) и B, или C» — другое выражение с другим порядком действий.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

A — «15 чётное» (0), B — «15 делится на 4» (0). Оборот «неверно, что» отрицает всё, что идёт после него, поэтому выражение имеет вид ¬(A ∧ B), а не ¬A ∧ B. Вычисление: A ∧ B = 0 ∧ 0 = 0, затем ¬0 = 1. Высказывание истинно: 15 действительно не является чётным числом, кратным четырём.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Ошибка в границах действия отрицания: в записи ¬A ∨ B знак ¬ относится только к A, потому что отрицание старше дизъюнкции и скобок вокруг суммы нет. Ученик вычислил другое выражение ¬(A ∨ B). Верно: ¬A = ¬1 = 0, затем 0 ∨ 1 = 1. Ответ 1, а не 0.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
