# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **в** — Цикл с параметром требует известного числа повторений, а здесь оно определяется условием.
2. **б** — Незакрытая конструкция — синтаксическая ошибка: границы блока неизвестны, запуск невозможен.
3. **в** — Числа перемножаются: 4 итерации внешнего цикла по 3 итерации внутреннего дают 12.
4. **г** — Массовость означает применимость к классу однотипных задач, а не к одной обстановке.
5. **б** — В неполной форме ветви «иначе» нет, поэтому блок просто пропускается.

### Ответы к Части Б (макс. 4 балла)

**6\.** Условие истинно при i = 2 и i = 4, поэтому s = 2 + 4 = 6.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** Пять итераций: i = 1, 3, 5, 7, 9.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Цикл с параметром требует заранее известного числа повторений: параметр должен менять значения от начального до конечного. Если длина коридора неизвестна, число шагов нельзя указать в заголовке цикла. Подходит цикл с предусловием «нц пока справа свободно»: он проверяет обстановку перед каждой итерацией и завершается ровно тогда, когда справа появляется стена, независимо от длины коридора.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Будут закрашены клетки 2 и 5 — всего 2 клетки. Цикл выполнит 5 итераций, потому что в коридоре из 6 клеток 5 переходов вправо; последняя команда после цикла обрабатывает шестую клетку. Проверок условия «справа свободно» будет 6: пять истинных и одна ложная, завершающая цикл.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Внутренний цикл выполнится 9 раз (3 · 3). Условие i = j истинно только при i = j, то есть в трёх случаях: (1,1), (2,2), (3,3). В каждом таком случае s увеличивается на 1, значит, s = 3. Алгоритм подсчитывает число совпадений значений двух счётчиков, то есть размер «диагонали» таблицы 3 на 3.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
