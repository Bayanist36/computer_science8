# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **в** — Основание равно числу различных цифр алфавита: 0–9 и A–F дают ровно 16 знаков.
2. **в** — Буквы G в алфавите нет: используются только A, B, C, D, E, F.
3. **в** — 1 · 16 + 15 = 31, так как F означает пятнадцать.
4. **в** — 16 = 2⁴, поэтому одна цифра заменяет ровно четыре бита — тетраду.
5. **а** — 255 = 15 · 16 + 15, а цифра 15 записывается буквой F.

### Ответы к Части Б (макс. 4 балла)

**6\.** 2A₁₆ = 2 · 16 + 10 = 42. 10111110₂ = 1011 1110 = BE₁₆.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** 4096 = 1000₁₆, потому что 16³ = 4096. В двоичной системе 4096 = 2¹² = 1000000000000₂ (единица и двенадцать нулей).
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

2023 : 16 = 126, остаток 7. 126 : 16 = 7, остаток 14 — это E. 7 : 16 = 0, остаток 7. Читаем остатки снизу вверх: 7E7. Проверка: 7 · 256 + 14 · 16 + 7 = 1792 + 224 + 7 = 2023. Ответ: 2023₁₀ = 7E7₁₆.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

3E₁₆ = 3 · 16 + 14 = 48 + 14 = 62. 76₈ = 7 · 8 + 6 = 56 + 6 = 62. Числа равны: 3E₁₆ = 76₈ = 62₁₀. Через двоичную запись это видно сразу: 3E → 0011 1110, 76₈ → 111 110, то есть та же последовательность бит без незначащих нулей.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Пары: 00, CC, FF. 00₁₆ = 0; CC₁₆ = 12 · 16 + 12 = 204; FF₁₆ = 15 · 16 + 15 = 255. Значения составляющих: R = 0, G = 204, B = 255. Каждая пара — один байт, три байта — 24 бита. В двоичной записи: 00000000 11001100 11111111.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
