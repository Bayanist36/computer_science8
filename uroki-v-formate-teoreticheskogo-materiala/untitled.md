## 1. Введение: зачем информатике логика?

Каждый раз, когда вы пользуетесь смартфоном, играете в компьютерную игру или просто включаете свет, вы имеете дело с **логикой** — но не той, о которой говорят в быту («это нелогично»), а с **математической логикой**, строгой формальной системой.

Процессор компьютера каждую секунду выполняет миллиарды элементарных операций, каждая из которых сводится к простому выбору: **да или нет**, **есть сигнал или нет сигнала**, **1 или 0**. Именно математическая логика описывает правила, по которым эти «да» и «нет» комбинируются и превращаются в сложные вычисления.

> **Математическая логика** — раздел математики, изучающий формы и законы правильного рассуждения с помощью формальных (символических) методов.

В информатике математическая логика применяется:
- при проектировании электронных схем процессоров и памяти;
- при написании программ (условия в операторах `if`, циклах `while`);
- при построении запросов к базам данных;
- при работе поисковых систем;
- при анализе и верификации алгоритмов.

## 2. Понятие логического высказывания

### 2.1. Определение

> **Логическое высказывание (высказывание)** — это повествовательное предложение, относительно которого можно однозначно определить, истинно оно или ложно.

Ключевые признаки высказывания:

1. **Повествовательность.** Предложение должно быть утвердительным или отрицательным сообщением, а не вопросом, приказом, просьбой или восклицанием.
2. **Однозначная определимость.** Для данного предложения должно быть возможно установить его истинностное значение: либо оно **истинно**, либо **ложно**. Третьего не дано.

### 2.2. Логические значения высказываний

Каждое высказывание принимает ровно одно из двух значений:

| Название | Обозначения | Числовой эквивалент |
|----------|-------------|---------------------|
| **Истина** | И, True, T, 1 | **1** |
| **Ложь** | Л, False, F, 0 | **0** |

> **Принцип двузначности (бинарности):** в классической математической логике высказывание не может быть одновременно истинным и ложным и не может принимать никакого третьего значения.

Именно этот принцип лежит в основе работы цифровых устройств: транзистор либо проводит ток (1), либо не проводит (0).

### 2.3. Примеры высказываний

| Предложение | Высказывание? | Значение | Пояснение |
|---|---|---|---|
| «Земля вращается вокруг Солнца» | ✅ Да | Истина (1) | Установленный научный факт |
| «2 + 2 = 5» | ✅ Да | Ложь (0) | Арифметически неверно |
| «Москва — столица России» | ✅ Да | Истина (1) | Факт |
| «Число 15 делится на 3» | ✅ Да | Истина (1) | 15 : 3 = 5 |
| «Все птицы умеют летать» | ✅ Да | Ложь (0) | Пингвины, страусы не летают |
| «В одном килограмме 1000 граммов» | ✅ Да | Истина (1) | Определение единицы измерения |

### 2.4. Примеры предложений, НЕ являющихся высказываниями

| Предложение | Почему не высказывание? |
|---|---|
| «Который час?» | Вопросительное предложение |
| «Закройте, пожалуйста, окно!» | Побудительное предложение (приказ/просьба) |
| «Какая красивая картина!» | Восклицательное предложение, выражает эмоцию |
| «Завтра будет дождь» | На момент произнесения невозможно определить истинность |
| «x > 5» | Содержит переменную; значение зависит от x |
| «Информатика — интересный предмет» | Субъективная оценка; нельзя объективно установить истинность |
| «Это предложение ложно» | Парадокс (парадокс лжеца): если оно истинно, то ложно, и наоборот |

> **Важно!** Выражения с переменными (например, «x > 5», «n делится на 3») называются **высказывательными формами (предикатами)**. Они становятся высказываниями только после подстановки конкретного значения вместо переменной.

## 3. Элементарные и составные высказывания

### 3.1. Элементарные (простые) высказывания

> **Элементарное (простое) высказывание** — высказывание, которое не содержит в качестве своей части другого высказывания.

Элементарные высказывания обозначают **одной буквой** латинского алфавита (обычно заглавной):

- *A*: «Число 7 — нечётное» → *A* = 1 (истина)
- *B*: «Треугольник имеет четыре стороны» → *B* = 0 (ложь)
- *C*: «2 × 3 = 6» → *C* = 1 (истина)
- *D*: «Солнце вращается вокруг Земли» → *D* = 0 (ложь)

### 3.2. Составные (сложные) высказывания

> **Составное (сложное) высказывание** — высказывание, полученное из элементарных высказываний с помощью **логических связок** (логических операций).

Примеры составных высказываний:

| Составное высказывание | Из каких элементарных построено |
|---|---|
| «Число 7 — нечётное **и** делится на 5» | *A* и *B*, связаны союзом «и» |
| «Идёт дождь **или** светит солнце» | Два высказывания, связаны союзом «или» |
| «**Не** верно, что 2 × 2 = 5» | Одно высказывание с частицей «не» |
| «Если число делится на 4, **то** оно делится на 2» | Два высказывания, связаны «если… то…» |

### 3.3. Как отличить элементарное высказывание от составного?

Чтобы определить, является ли высказывание элементарным или составным, задайте себе вопрос:

> *Можно ли выделить внутри этого высказывания более мелкие высказывания, каждое из которых само по себе является законченным утверждением?*

- Если **нельзя** → высказывание **элементарное**.
- Если **можно** → высказывание **составное**.

**Пример анализа:**

Предложение: *«Число 12 делится на 3 и на 4».*

Разбиваем:
- Высказывание 1: «Число 12 делится на 3» → истинно.
- Высказывание 2: «Число 12 делится на 4» → истинно.
- Связка: «и».

Вывод: это **составное** высказывание.

## 4. Обозначения и формальная запись

В математической логике высказывания принято обозначать буквами, а их значения записывать в виде равенств:

$$A = 1 \quad (\text{высказывание } A \text{ истинно})$$
$$B = 0 \quad (\text{высказывание } B \text{ ложно})$$

Для составных высказываний используют специальные символы логических операций (подробно — на следующем уроке):

| Операция | Символ | Название | Пример записи |
|---|---|---|---|
| «и» | ∧ | Конъюнкция (логическое умножение) | *A* ∧ *B* |
| «или» | ∨ | Дизъюнкция (логическое сложение) | *A* ∨ *B* |
| «не» | ¬ | Отрицание | ¬*A* |

На данном уроке достаточно запомнить, что такие обозначения существуют. Подробное изучение операций — тема урока 8.

## 5. Связь высказываний с информатикой

### 5.1. Высказывания в программировании

В любом языке программирования (Python, C++, Паскаль и др.) условия в операторах ветвления и циклах представляют собой **логические высказывания**:

```python
# Python
x = 10
if x > 5:          # «x > 5» — высказывание; при x = 10 оно истинно (1)
    print("Да")
```

```python
a = 3
b = 7
if (a > 0) and (b > 0):   # составное высказывание: оба условия истинны
    print("Оба числа положительные")
```

Компьютер вычисляет значение высказывания (1 или 0) и в зависимости от результата выбирает ветвь выполнения программы.

### 5.2. Высказывания в аппаратном обеспечении

На физическом уровне процессор состоит из **логических элементов** (вентилей): И, ИЛИ, НЕ. Каждый такой элемент реализует соответствующую логическую операцию над двоичными сигналами (0 или 1). Миллиарды таких элементов, соединённых определённым образом, образуют процессор, память и другие узлы компьютера. Подробнее — на уроке 11 «Логические элементы».

### 5.3. Высказывания в поисковых запросах

Когда вы вводите в поисковую систему запрос:

> `информатика И логика`

вы фактически строите **составное высказывание**: «Страница содержит слово "информатика" **И** страница содержит слово "логика"». Поисковая система возвращает только те страницы, для которых это высказывание истинно.

## 6. Основные определения урока (конспект)

| Термин | Определение |
|---|---|
| **Высказывание** | Повествовательное предложение, о котором можно однозначно сказать, истинно оно или ложно |
| **Логическое значение** | Истина (1) или Ложь (0) — единственные возможные значения высказывания |
| **Принцип двузначности** | Каждое высказывание принимает ровно одно из двух значений: 1 или 0 |
| **Элементарное высказывание** | Высказывание, не содержащее других высказываний; обозначается одной буквой |
| **Составное высказывание** | Высказывание, полученное из элементарных с помощью логических операций |
| **Логическая операция** | Правило, по которому из одного или нескольких высказываний строится новое высказывание |
| **Высказывательная форма (предикат)** | Выражение с переменной, становящееся высказыванием при подстановке конкретного значения |
