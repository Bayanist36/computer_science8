## 1\. Главное о теме

Если число повторений заранее неизвестно, программа должна повторять действия, пока выполняется условие. Цикл `while` — это «пока», и его главная опасность в том, что условие может никогда не стать ложным.

Дальше разберём по шагам: зачем программе цикл; как работает while; вечный цикл и ошибки счётчика; алгоритм евклида; разбор цифр числа.

## 2\. Зачем программе цикл

> **Определение.** Цикл с условием — алгоритмическая конструкция, в которой группа команд повторяется, пока проверяемое перед каждым повторением условие остаётся истинным.

Цикл — это конструкция, которая заставляет программу вернуться назад и выполнить те же команды снова. Если число повторений известно, его можно посчитать заранее; если неизвестно — повторяют до тех пор, пока выполняется некоторое условие. Второй случай и называется циклом с условием.

В Python такой цикл записывается словом `while` («пока»). После него, как и у `if`, ставится условие и двоеточие, а тело цикла выделяется отступом. Отличие в том, что после выполнения тела управление возвращается к проверке условия, а не идёт дальше.

> Условие цикла формулируют как условие продолжения: «пока i не больше пяти», а не «пока i меньше или равно пяти — стоп». Ошибка в формулировке даёт либо лишнее повторение, либо ни одного.

```text
Схема цикла while:

        (начало)
           |
      [ i <= 5 ? ] --нет--> (выход из цикла)
           | да
     [ тело цикла ]
     [ i = i + 1  ]
           |
           +------ обратно к проверке
```

---

## 3\. Как работает while

> **Определение.** Счётчик цикла — переменная, которая изменяется на каждом повторении и входит в условие продолжения цикла.

Порядок работы `while` всегда одинаков: проверить условие, если истинно — выполнить тело, вернуться к проверке, и так до первого ложного результата. Если условие ложно с самого начала, тело не выполнится ни разу — это не ошибка, а нормальное поведение.

Программа выведет `1 2 3 4 5 готово`. Переменная `i` здесь — счётчик: она хранит номер текущего повторения. Без строки `i += 1` счётчик не меняется, условие `i <= 5` остаётся истинным навсегда, и цикл никогда не закончится.

> Тело цикла должно влиять на условие. Если внутри цикла ни одна переменная из условия не меняется, программа зацикливается: она не падает с ошибкой, а просто работает бесконечно, и её приходится останавливать вручную.

```python
i = 1
while i <= 5:
    print(i, end=" ")
    i += 1
print("готово")
```

## 4\. Вечный цикл и ошибки счётчика

Зацикливание — самая частая ошибка в теме. Программа при этом выглядит безобидно: она что-то печатает или считает, просто никогда не останавливается. В среде Python это видно по бесконечному потоку вывода и «зависшему» окну; остановить программу можно прерыванием выполнения (Ctrl+C в консоли или кнопка остановки в среде).

Второй по частоте источник проблем — граница. Цикл `while i < 5` при `i = 1` и шаге 1 выполнит тело четыре раза, а `while i <= 5` — пять. Прежде чем запускать программу, полезно вручную проверить два значения: начальное и то, на котором цикл должен остановиться.

| Ошибка | Как выглядит | Что произойдёт |
|:---|:---|:---|
| Счётчик не меняется | while i <= 5: print(i) | бесконечный цикл |
| Шаг больше нужного | while i <= 5: ... i += 2 | обработаны не все значения |
| Неверное направление | i = 5, затем i += 1 | тело не выполнится ни разу |
| Условие с >= вместо > | while i < 5 ... i >= 5 | лишнее или недостающее повторение |

> Цикл, который не выполнился ни разу, — тоже повод для проверки, а не для радости. Если программа «ничего не сделала», чаще всего начальное значение уже нарушает условие: например, i = 10 при условии i < 5.

## 5\. Алгоритм Евклида

Алгоритм Евклида — древний способ найти наибольший общий делитель двух чисел, и он идеально ложится на цикл с условием. Правило такое: пока второе число не равно нулю, заменяем пару (a, b) парой (b, остаток от деления a на b). Когда второе число стало нулём, первое и есть НОД.

Строка `a, b = b, a % b` в Python выполняется особым образом: сначала вычисляются оба значения справа, и только потом они присваиваются. Поэтому обмен не портит данные — в других языках для этого понадобилась бы временная переменная.

> Условие `b != 0` проверяется до тела, поэтому при вводе второго числа, равного нулю, цикл не выполнится ни разу, и программа сразу выведет НОД, равный первому числу. Это математически верно.

```python
a = int(input("Первое число: "))
b = int(input("Второе число: "))
while b != 0:
    a, b = b, a % b
print("НОД =", a)
```

## 6\. Разбор цифр числа

Пока число больше нуля, у него есть хотя бы одна цифра, и с ней можно что-то сделать. Последняя цифра получается остатком от деления на 10, а чтобы перейти к следующей, число делят нацело на 10. Эти два действия в цикле позволяют обработать все цифры без знания длины числа.

Программа выведет `сумма цифр: 22 количество: 4`. Заметим, что переменная `n` уничтожается по ходу работы: после цикла она равна нулю. Если исходное число ещё понадобится, его сохраняют в отдельной переменной до цикла.

> Для n = 0 цикл не выполнится ни разу, и количество цифр получится 0, хотя в числе 0 одна цифра. Это крайний случай, который нужно обрабатывать отдельно: проверять `if n == 0` до цикла. Для отрицательных чисел предварительно берут модуль.

```python
n = 4729
s = 0
k = 0
while n > 0:
    s += n % 10
    k += 1
    n //= 10
print("сумма цифр:", s, "количество:", k)
```

## 7\. Разобранные примеры

### Пример 1. Сумма чисел от 1 до 100

**Условие.** Найти сумму всех целых чисел от 1 до 100, используя цикл с условием.

**Решение.** Заводим счётчик `i = 1` и накопитель `s = 0`. Пока счётчик не больше 100, прибавляем его к накопителю и увеличиваем на единицу. После 100-го повторения счётчик станет равен 101, условие `i <= 100` окажется ложным, и цикл завершится.

Программа записывается так: `i = 1`, `s = 0`, затем цикл `while i <= 100` с телом из двух строк — `s += i` и `i += 1`; после цикла выводится `s`. Число повторений здесь известно заранее — 100, но конструкция та же, что и в задачах с неизвестным числом шагов. Проверка вручную: после первого повторения s = 1, i = 2; после второго s = 3, i = 3; после третьего s = 6, i = 4.

**Ответ:** 5050.

### Пример 2. НОД по алгоритму Евклида

**Условие.** Найти наибольший общий делитель чисел 48 и 18, показав все шаги.

**Решение.** Работаем парой (a, b) = (48, 18). На каждом шаге новое a равно старому b, новое b — остатку от деления старого a на старое b.

Итерация 1: a = 48, b = 18, остаток 48 % 18 = 12, новая пара (18, 12). Итерация 2: 18 % 12 = 6, новая пара (12, 6). Итерация 3: 12 % 6 = 0, новая пара (6, 0). На третьей итерации остаток стал нулём. Условие `b != 0` оказалось ложным, цикл завершился, и в переменной a осталось 6.

**Ответ:** НОД(48, 18) = 6.

### Пример 3. Сумма и количество цифр числа

**Условие.** Для числа 4729 найти сумму цифр и их количество.

**Решение.** На каждом повторении берём последнюю цифру `n % 10`, добавляем к сумме, увеличиваем счётчик и убираем цифру делением нацело на 10.

Шаг 1: n = 4729, цифра 9, s = 9, k = 1, новое n = 472. Шаг 2: цифра 2, s = 11, k = 2, n = 47. Шаг 3: цифра 7, s = 18, k = 3, n = 4. Шаг 4: цифра 4, s = 22, k = 4, n = 0. После четвёртого шага n стало равным нулю, условие `n > 0` ложно, цикл заканчивается. Сумма цифр — 22, количество — 4.

**Ответ:** сумма 22, количество 4.
