# Урок 9. Определение истинности составного высказывания

**Раздел:** Теоретические основы информатики

## 1\. Главное о теме

Составное высказывание вычисляют, а не «понимают»: значение каждой части подставляют в выражение и последовательно заменяют операции их результатами. Порядок замен задаёт приоритет, а скобки могут его изменить.

Дальше разберём по шагам: что значит вычислить составное высказывание; приоритет логических операций; скобки меняют порядок; как оформить решение по шагам; от фразы к значению.

---

## 2\. Что значит вычислить составное высказывание

> **Определение.** Истинность составного высказывания — его значение (0 или 1), которое оно принимает при данных значениях входящих в него элементарных высказываний.

Составное высказывание отличается от элементарного тем, что содержит другие высказывания внутри себя. Если известны значения всех внутренних частей, значение целого определяется однозначно: его можно получить механически, не вдумываясь в смысл фразы. В этом и сила логики — она позволяет заменить понимание вычислением.

Вычисление всегда идёт одинаково: выписываем выражение, подставляем вместо букв нули и единицы, затем заменяем операции их результатами, пока не останется одно число. Каждая замена уменьшает число операций на одну, поэтому процесс обязательно заканчивается. Для выражения с четырьмя операциями понадобится ровно четыре шага.

Полезно сразу договориться о форме ответа: число 0 или 1 плюс словесная расшифровка «ложно» или «истинно». Запись «получилось примерно истинно» недопустима, потому что в логике нет степеней истинности — есть только два значения.

| Шаг | Что делаем | Пример для F = A ∧ (B ∨ ¬C) при A = 1, B = 0, C = 1 |
|:---|:---|:---|
| 1 | Записываем выражение и значения переменных | A ∧ (B ∨ ¬C) |
| 2 | Вычисляем действие во внутренних скобках | ¬C = ¬1 = 0 |
| 3 | Продолжаем по приоритету внутри скобок | B ∨ 0 = 0 |
| 4 | Выполняем последнюю операцию и записываем ответ | 1 ∧ 0 = 0 |

> Значения переменных в задаче задаются один раз и не меняются по ходу решения. Если в выражении A ∧ (B ∨ ¬A) буква A встретилась дважды, она принимает одно и то же значение в обоих местах, поэтому отрицание ¬A вычисляют сразу для всех вхождений.

## 3\. Приоритет логических операций

Если в выражении несколько разных операций, они выполняются не слева направо, а по старшинству. Старшая операция — отрицание: оно применяется к ближайшему высказыванию раньше всех. Следующая по старшинству — конъюнкция, самая младшая — дизъюнкция. Мнемоническое правило короткое: **НЕ, И, ИЛИ**, от старшего к младшему.

Аналогия с арифметикой здесь почти полная: в выражении 2 + 3 · 4 сначала умножают, потому что умножение старше сложения, и лишь потом складывают. Так же в A ∨ B ∧ C сначала вычисляют B ∧ C, а результат присоединяют к A. Разница только в том, что «умножением» здесь служит конъюнкция, а «сложением» — дизъюнкция.

Отрицание старше всех, но его действие ограничено ближайшим операндом: в записи ¬A ∧ B отрицается только A. Если нужно отрицать всё выражение, его заключают в скобки: ¬(A ∧ B). Это различие — источник самой частой ошибки в теме, и на нём стоит задержаться.

| Приоритет | Операция | Знак | Пример записи |
|:---|:---|:---|:---|
| 1 (старшая) | отрицание | ¬ | ¬C |
| 2 | конъюнкция | ∧ | B ∧ ¬C |
| 3 (младшая) | дизъюнкция | ∨ | A ∨ B ∧ ¬C |

> Приоритет — это соглашение о записи, а не свойство самой фразы. Поэтому одну и ту же мысль можно записать по-разному, и ответственность за однозначность лежит на том, кто составил выражение. Если сомневаетесь, как вас поймут, ставьте скобки.

## 4\. Скобки меняют порядок

Скобки работают как в арифметике: всё, что внутри, вычисляется до операций снаружи. При вложенных скобках движение идёт изнутри наружу — сначала самая внутренняя пара, затем следующая. В выражении ¬((A ∨ B) ∧ C) порядок такой: A ∨ B, затем конъюнкция с C, и только потом отрицание результата.

Разница между выражениями A ∨ B ∧ C и (A ∨ B) ∧ C не косметическая. Возьмём A = 1, B = 1, C = 1. В первом случае сначала B ∧ C = 1 ∧ 1 = 1, затем 1 ∨ 1 = 1. Во втором сначала A ∨ B = 1, затем 1 ∧ C = 1 ∧ 1 = 1 — здесь значения совпали. А при C = 0 первый вариант даст 1 ∨ 0 = 1, второй — 1 ∧ 0 = 0. Один и тот же набор значений приводит к разным ответам, и виноваты только скобки.

Практическое правило оформления: ставьте скобки всюду, где порядок может быть понят двояко. Лишняя пара скобок не меняет значения, недостающая — меняет. Единственное исключение — внешние скобки вокруг всего выражения: запись (A ∨ B) и A ∨ B означают одно и то же, и в ответах их обычно опускают.

```text
Сравним при A = 1, B = 1, C = 0

A ∨ B ∧ C   = 1 ∨ (1 ∧ 0) = 1 ∨ 0 = 1
(A ∨ B) ∧ C = (1 ∨ 1) ∧ 0 = 1 ∧ 0 = 0
```

---

## 5\. Как оформить решение по шагам

Аккуратная запись решения экономит время на проверке. На каждом шаге выписывайте выражение целиком, заменяя только одну операцию её значением; остальные части переписывайте без изменений. Так видно, что именно изменилось, и ошибку легко найти, вернувшись на шаг назад.

Типичная ошибка — считать слева направо, «как читается». В выражении A ∨ B ∧ ¬C такой счётчик сначала сложит A и B, и результат окажется другим. Второй источник ошибок — потеря отрицания при переносе: ученик записывает ¬C = 0, а дальше подставляет C = 1. Поэтому промежуточные значения лучше подписывать: рядом с шагом писать, что именно вычислено.

Последний шаг — смысловая проверка. Переведите результат обратно на русский язык и спросите себя, согласуется ли он со здравым смыслом. Если выражение описывает реальную ситуацию, а ответ ей противоречит, вероятнее всего, ошибка в расстановке скобок или в значениях элементарных высказываний.

```text
Дано: A = 1, B = 0, C = 1.  Найти F = A ∧ (B ∨ ¬C).

1) ¬C = ¬1 = 0
2) B ∨ ¬C = 0 ∨ 0 = 0
3) A ∧ (B ∨ ¬C) = 1 ∧ 0 = 0

Ответ: F = 0, высказывание ложно.
```

## 6\. От фразы к значению

Многие задачи начинаются не с выражения, а с фразы на русском языке. Порядок перевода всегда один: выделить элементарные высказывания и обозначить их буквами, определить связки, записать выражение знаками и расставить скобки по смыслу. Только после этого подставляют значения и вычисляют.

Союз «но» почти всегда означает конъюнкцию: «дорого, но надёжно» значит «дорого и надёжно». Оборот «неверно, что» ставит отрицание перед всей следующей за ним частью, поэтому такую часть нужно закрывать скобками: «Неверно, что A и B» — это ¬(A ∧ B), а не ¬A ∧ B.

Программа полезна как проверка: в Python действует тот же приоритет `not`, `and`, `or`, поэтому записанное выражение можно вычислить и сверить со своим решением. Совпадение не гарантирует правильности перевода фразы, но расхождение всегда означает ошибку — либо в переводе, либо в арифметике нулей и единиц.

| Слова в фразе | Знак в выражении |
|:---|:---|
| «и», «а также», «но», «при этом» | ∧ |
| «или», «либо» в перечислительном смысле | ∨ |
| «не», «неверно, что» | ¬ |
| «если …, то …» | в базовый набор не входит |

```python
A, B, C = True, False, True          # значения высказываний
print(A and (B or not C))            # False
print((A or B) and not C)            # False
print(not (A and B) or C)            # True
```

## 7\. Разобранные примеры

### Пример 1. Вычисление с вложенными скобками

**Условие.** Найдите значение выражения F = A ∧ (B ∨ ¬C) при A = 1, B = 0, C = 1.

**Решение.** Действуем от внутренних скобок. Отрицание старше остальных операций, поэтому сначала ¬C = ¬1 = 0. Внутри скобок остаётся B ∨ 0 = 0 ∨ 0 = 0; дизъюнкция ложна, потому что оба её операнда нулевые. Теперь подставляем результат в оставшуюся конъюнкцию: A ∧ 0 = 1 ∧ 0 = 0.

**Ответ:** F = 0, высказывание ложно. Проверка: ложь получилась из-за второго множителя, а он ложен, потому что B = 0 и C ≠ 0.

### Пример 2. Отрицание всей конъюнкции

**Условие.** Найдите значение выражения G = ¬(A ∧ B) ∨ C при A = 1, B = 1, C = 0.

**Решение.** Сначала то, что в скобках: A ∧ B = 1 ∧ 1 = 1. Затем отрицание результата: ¬1 = 0. Наконец дизъюнкция: 0 ∨ C = 0 ∨ 0 = 0. Обратите внимание: если бы скобок не было, выражение ¬A ∧ B ∨ C дало бы ¬1 ∧ 1 ∨ 0 = 0 ∧ 1 ∨ 0 = 0 — совпадение случайное, и полагаться на него нельзя.

**Ответ:** G = 0, высказывание ложно.

### Пример 3. Фраза, выражение и значение

**Условие.** Определите истинность высказывания «Число 18 делится на 3 или на 5, но не делится на 9».

**Решение.** Обозначим A — «18 делится на 3», B — «18 делится на 5», C — «18 делится на 9». Союз «но» соединяет две части, поэтому выражение имеет вид (A ∨ B) ∧ ¬C. Значения: A = 1 (18 = 3 · 6), B = 0 (18 на 5 не делится), C = 1 (18 = 9 · 2).

Вычисляем: A ∨ B = 1 ∨ 0 = 1, затем ¬C = ¬1 = 0, и наконец 1 ∧ 0 = 0.

**Ответ:** высказывание ложно: первая часть верна, но вторая («не делится на 9») неверна, а «но» требует истинности обеих частей.

### Задание 4. Переведите и вычислите

### Задание 6. Практическая работа на компьютере

## 10\. Итоги урока

На этом уроке вы узнали:

✅ **Что значит вычислить составное высказывание.** Составное высказывание — запись из элементарных и операций; его значение зависит только от значений частей.

✅ **Приоритет логических операций.** Сначала отрицание, потом конъюнкция, потом дизъюнкция; мнемоника: НЕ, затем И, затем ИЛИ.

✅ **Скобки меняют порядок.** Скобки вычисляются первыми, изнутри наружу; одна пара скобок может изменить ответ.

✅ **Как оформить решение по шагам.** Один шаг — одна операция, остальное переписываем; промежуточные значения записываем, не держим в голове.

✅ **От фразы к значению.** Сначала выделяем элементарные высказывания; потом расставляем связки и скобки.
