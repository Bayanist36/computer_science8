## 1\. Главное о теме

Переменная — это имя ячейки памяти, в которой хранится значение. Оператор присваивания не сравнивает, а запоминает: сначала вычисляется правая часть, потом результат кладётся в переменную слева, и прежнее значение исчезает.

Дальше разберём по шагам: зачем программе переменные; типы данных; оператор присваивания; ввод и вывод данных; имена переменных и отладка.

---

## 2\. Зачем программе переменные

> **Определение.** Переменная — именованная область памяти, в которой хранится значение определённого типа и которую можно изменить во время выполнения программы.

Программа считает в несколько шагов, и промежуточный результат нельзя «подержать в голове»: у компьютера нет головы, есть память. Место в памяти, которому дали имя, и называется переменной. Программист придумывает имя, а компьютер выделяет ячейку и связывает её с этим именем.

У переменной три составляющие. **Имя** — то, как мы к ней обращаемся в тексте программы. **Значение** — то, что сейчас лежит в ячейке. **Тип** — вид данных, который определяет, какие действия с ними допустимы: числа можно складывать, а строку и число складывать нельзя.

Переменную удобно представлять как подписанную коробку. В коробку `age` положили число 14. Пока мы не заменим содержимое, любое обращение к `age` даёт 14. Если положить туда 15, прежнее значение пропадёт безвозвратно — в одной коробке лежит только одна вещь.

---

## 3\. Типы данных

Тип значения Python определяет автоматически по самой записи. Запись без кавычек и без точки — целое число (`int`). С точкой — вещественное (`float`). В кавычках — строка (`str`), даже если внутри только цифры. Отдельно стоят логические значения (`bool`): их всего два, `True` и `False`.

Различие между `42` и `"42"` принципиально. Первое можно умножить на два и получить 84, второе при умножении на 2 даст строку `"4242"`, а при попытке сложить с числом программа остановится с ошибкой. Тип — это не формальность, а правило допустимых операций.

| Тип | Примеры | Что хранит | Операции |
|:---|:---|:---|:---|
| int | 42, −7, 0 | целые числа | + − * // % ** |
| float | 3.14, 0.5, 2.0 | числа с дробной частью | + − * / ** |
| str | "42", "привет" | текст | + (склейка) |
| bool | True, False | истина или ложь | and, or, not |

> `print(type(x))` показывает тип значения переменной. Если в ответ пришло `<class 'str'>`, значит, в переменной текст, а не число, — это первая причина ошибок при вводе данных.

## 4\. Оператор присваивания

> **Определение.** Оператор присваивания — команда, которая вычисляет значение выражения справа от знака = и записывает результат в переменную, указанную слева.

Запись `a = 5` читается не «а равно пяти», а «переменной a присвоить значение 5». Справа может стоять не только число, но и выражение: `b = a + 1`. Порядок действий всегда один и тот же: сначала вычисляется правая часть, затем результат записывается в переменную, имя которой стоит слева.

Проследим по шагам. После первой строки `a = 5`. Во второй вычисляется `5 + 1 = 6`, и это значение получает `b`. В третьей вычисляется `6 * 2 = 12`, и результат записывается обратно в `a`, затирая прежнюю пятёрку. На экран выйдет `12 6`.

Особый случай — обмен значений двух переменных. Если написать `a = b`, а потом `b = a`, обмен не получится: после первой команды в `a` уже лежит значение `b`, и старое значение `a` потеряно. Нужна третья, временная переменная — либо короткая запись Python `a, b = b, a`, которая вычисляет правую часть целиком до присваивания.

> Запись `x = x + 1` в математике невозможна, а в программе означает «взять текущее значение x, прибавить единицу и положить обратно». Так переменная-счётчик увеличивается на единицу.

```python
a = 5
b = a + 1
a = b * 2
print(a, b)
```

## 5\. Ввод и вывод данных

Команда `input` показывает приглашение и ждёт, пока человек наберёт ответ. Возвращает она всегда строку — даже если ввели цифры. Поэтому перед вычислениями строку нужно превратить в число: `int(...)` для целых, `float(...)` для дробных. Пропущенное преобразование — самая частая причина ошибки `TypeError`.

Здесь `name` получает строку, `age` — целое число. Команда `print` перечисляет значения через запятую и разделяет их пробелом, поэтому при вводе `Аня` и `14` на экране появится `Аня будет 15`. Обратите внимание: `print(name + " будет 15")` дал бы тот же текст, но вычисление возраста требует именно числа.

> Если в ответ на `int(input())` ввести слово, программа остановится с ошибкой `ValueError`: строку «привет» нельзя превратить в число. Проверка корректности ввода — отдельная задача, которой мы займёмся позже.

```python
name = input("Как тебя зовут? ")
age = int(input("Сколько тебе лет? "))
print(name, "будет", age + 1)
```

## 6\. Имена переменных и отладка

Имя переменной придумывает программист, но не свободно. Используются латинские буквы, цифры и знак подчёркивания; начинаться имя не может с цифры; пробелы и знаки вроде минуса запрещены. Регистр имеет значение: `summa`, `Summa` и `SUMMA` — три разные переменные. Нельзя занимать имена, зарезервированные языком: `if`, `for`, `class`, `print`.

Хорошее имя объясняет смысл: `cena`, `kolichestvo`, `itog` понятнее, чем `a`, `b`, `c`. Когда программа перестаёт работать, применяют два приёма отладки. Первый — вставить `print` в нужном месте и посмотреть, что реально лежит в переменной. Второй — трассировка: вручную выполнить программу по строкам и записать значения в таблицу.

| Имя | Допустимо | Причина |
|:---|:---|:---|
| a1 | да | буква, затем цифра |
| _summa | да | подчёркивание разрешено |
| 1a | нет | начинается с цифры |
| my name | нет | содержит пробел |
| class | нет | зарезервированное слово |

> Проверять программу нужно на конкретных числах, а не «на глаз». Таблица из трёх столбцов — строка, команда, значения переменных — показывает, на каком именно шаге результат разошёлся с ожидаемым.

## 7\. Разобранные примеры

### Пример 1. Обмен значений двух переменных

**Условие.** В переменных `a = 3` и `b = 8`. Нужно поменять их значения местами, чтобы стало `a = 8`, `b = 3`.

**Решение.** Прямая запись `a = b`, затем `b = a` не работает: после первой команды `a` станет равно 8, и старое значение 3 потеряется. Введём третью переменную: `t = a` (в `t` теперь 3), `a = b` (в `a` теперь 8), `b = t` (в `b` теперь 3). В Python есть короткая равносильная запись `a, b = b, a`: правая часть вычисляется целиком, а потом значения распределяются.

**Ответ:** `t = a; a = b; b = t` или `a, b = b, a`. Результат: `a = 8`, `b = 3`.

### Пример 2. Трассировка программы с переприсваиванием

**Условие.** Что выведет программа?
`x = 7`
`y = x`
`x = 20`
`print(x, y)`

**Решение.** Строка 1: `x = 7`. Строка 2: в `y` копируется текущее значение `x`, то есть 7; связь между переменными не возникает — это две независимые ячейки. Строка 3: в `x` записывается 20, значение `y` не меняется. Строка 4: выводятся текущие значения — 20 и 7.

**Ответ:** `20 7`.

### Пример 3. Программа с вводом и вычислением

**Условие.** Составьте программу: запросить имя и возраст, вывести фразу «Имя, через год тебе будет N лет». Проверьте на данных «Аня», 14.

**Решение.** Первая строка — `name = input("Имя: ")`, получаем строку. Вторая — `age = int(input("Возраст: "))`, преобразуем ввод в целое число, иначе сложение с единицей вызовет ошибку. Третья — `print(name + ", через год тебе будет", age + 1, "лет")`. При вводе `Аня` и `14` вычисляется `14 + 1 = 15`.

**Ответ:** `Аня, через год тебе будет 15 лет`. Если убрать `int`, программа остановится с ошибкой `TypeError`, потому что строку и число складывать нельзя.
