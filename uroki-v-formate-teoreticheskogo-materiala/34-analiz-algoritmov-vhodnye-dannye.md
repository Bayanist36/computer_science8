# Урок 34. Анализ алгоритмов. Определение возможных входных данных, приводящих к данному результату

**Раздел:** Алгоритмы и программирование
**Тема:** Анализ алгоритмов
**Класс:** 8

---

## 1\. Главное о теме

Обратная задача анализа алгоритма: известен результат — нужно восстановить вход. Обратный ход превращает программу в цепочку уравнений, но деление нацело и ветвление стирают часть информации, поэтому ответом часто становится не одно число, а целое множество.

Дальше разберём по шагам: прямая и обратная задача; обратный ход по присваиваниям; ветвление: одно уравнение на каждую ветвь; циклы и потеря информации; подбор с проверкой и оформление ответа.

---

## 2\. Прямая и обратная задача

> **Определение.** Обратная задача анализа алгоритма — задача, в которой по известному результату работы алгоритма требуется найти входные данные, при которых этот результат получается.

Прямая задача анализа алгоритма решается исполнением: подставили вход, прошли по шагам, прочитали выход. Обратная задача ставит вопрос наоборот: известен выход, найти вход. Формально это поиск всех значений, при которых алгоритм даёт заданный результат, и именно слово «всех» делает задачу содержательной.

Ответов может быть три типа. Первый: решение единственное — так бывает, когда все операции обратимы однозначно. Второй: решений несколько — типичный случай, когда в программе есть ветвление или деление нацело. Третий: решений нет — программа в принципе не может выдать такое значение, и это нужно доказать, а не просто не найти ответ.

Разница между операциями видна сразу. Прибавление константы обратимо: из результата вычитаем ту же константу. Умножение на ненулевое число обратимо, но только если результат делится нацело. Деление нацело и остаток от деления информацию теряют: из результата 5 после n // 2 нельзя узнать, было ли n равно 10 или 11.

| Операция | Обратное действие | Сколько решений |
|:---|:---|:---|
| a = a + 7 | вычесть 7 | одно |
| a = a * 3 | разделить на 3 | одно, если делится нацело |
| a = a // 2 | взять 2a и 2a + 1 | два |
| a = a % 10 | восстановить нельзя | бесконечно много |
| a = -a | взять противоположное | одно |

> Обратный ход работает только для операций, которые действительно выполнялись. Если ветвь не была выбрана, её уравнение не имеет отношения к делу — решение из «чужой» ветви нужно отбросить проверкой условия.

## 3\. Обратный ход по присваиваниям

Обратный ход — это решение цепочки уравнений с конца. Пусть программа состоит из присваиваний a = a * 3, затем a = a + 4, затем a = a // 2, и вывела 20. Обозначим значение перед каждым шагом новой буквой: перед делением было b, перед прибавлением c, на входе a. Тогда b // 2 = 20, c + 4 = b, a * 3 = c.

Первое уравнение даёт не одно значение, а два: b равно 40 или 41, потому что и 40 // 2, и 41 // 2 равны 20. Второе уравнение: c = b − 4, то есть 36 или 37. Третье: a * 3 равно 36 или 37, но 37 на 3 не делится, значит, остаётся только c = 36 и a = 12.

Ключевой приём — отсечение вариантов по делимости и по типу данных. Промежуточные значения в программе с целочисленными операциями тоже целые, поэтому вариант, при котором a * 3 = 37, невозможен: он требует дробного a. Такое отсечение и делает обратный ход конечным.

> Не путайте деление нацело с обычным: уравнение b // 2 = 20 имеет два целых решения, а уравнение b / 2 = 20 — только одно. Именно поэтому в обратных задачах с // ответом часто оказывается промежуток.

```text
Вывод:                         a // 2 = 20
Шаг назад:                     a = 40 или 41
Предыдущий шаг:                a + 4 = 40 или 41  ->  a = 36 или 37
Первый шаг:                    a * 3 = 36 или 37  ->  a = 12

Проверка: 12 * 3 = 36, 36 + 4 = 40, 40 // 2 = 20
```

## 4\. Ветвление: одно уравнение на каждую ветвь

Ветвление размножает решения: если программа может пойти по двум разным путям, то для каждого пути получается своё уравнение, и каждое даёт свой вход. Главное правило — решение, найденное для ветви, должно удовлетворять её условию. Иначе оно не относится к этой ветви и должно быть отброшено.

Пусть программа вывела 8. Для первой ветви уравнение 2x = 8 даёт x = 4; проверяем условие: 4 >= 0 истинно, решение подходит. Для второй ветви уравнение −x = 8 даёт x = −8; проверяем: −8 >= 0 ложно, значит, ветвь else действительно выбрана, и решение подходит. Итого два ответа.

| Ветвь | Условие ветви | Уравнение | Кандидат | Проверка условия |
|:---|:---|:---|:---|:---|
| первая | x >= 0 | 2x = 8 | 4 | подходит |
| вторая | x < 0 | −x = 8 | −8 | подходит |

> Если поменять условие на x > 0, число 0 перестанет попадать в первую ветвь: для результата 0 решение x = 0 найдётся уже во второй ветви, а не в первой. Поэтому проверять условие ветви нужно для каждого кандидата отдельно.

```python
x = int(input())
if x >= 0:
    y = x * 2
else:
    y = -x
print(y)
```

## 5\. Циклы и потеря информации

Цикл с известным числом повторений разворачивается в цепочку одинаковых операций, и обратный ход выполняется столько же раз, сколько было итераций. Если тело цикла делит число нацело на 2, то один обратный шаг превращает значение v в промежуток от 2v до 2v + 1, а каждый следующий шаг удваивает ширину промежутка.

Восстанавливаем вход. Перед последним делением n было 10 или 11. Перед вторым — от 20 до 23. Перед первым — от 40 до 47. Все восемь значений дают на выходе 5, и ни одно другое число этого не даёт: 39 после трёх делений даёт 4, а 48 даёт 6.

С остатком от деления дело хуже: уравнение n % 10 = 7 имеет бесконечно много решений — все числа, оканчивающиеся на 7. Если таких условий в программе несколько, восстановить вход можно только в пределах известного диапазона, например «двузначное число».

| Сколько делений прошло | Промежуток значений | Ширина |
|:---|:---|:---|
| 1 | от 10 до 11 | 2 |
| 2 | от 20 до 23 | 4 |
| 3 | от 40 до 47 | 8 |

> Ширина промежутка после k делений нацело на 2 равна 2 в степени k. Это удобно помнить: три деления дают 8 вариантов, четыре — 16, десять — больше тысячи, и тогда обратную задачу решают подбором с проверкой.

```python
n = int(input())
for i in range(3):
    n = n // 2
print(n)                # 5
```

## 6\. Подбор с проверкой и оформление ответа

Когда промежуток решений широкий, а уравнение с остатком не решается в общем виде, используют подбор с проверкой: перебирают допустимые входы и оставляют те, при которых программа даёт нужный результат. Подбор не отменяет рассуждения — он его дополняет: диапазон перебора берут из условия задачи, а полноту ответа обеспечивает полный проход по диапазону.

Порядок действий при решении обратной задачи одинаков. Сначала выписываем цепочку действий программы и отмечаем, какие из них обратимы однозначно. Затем идём с конца, получая на каждом шаге уравнение или промежуток. Потом отсекаем кандидатов по ограничениям: тип данных, знак, разрядность, условие ветви. В конце подставляем каждое решение в программу и убеждаемся, что оно даёт заданный результат.

Эта программа подтверждает результат обратного хода: перебор всех чисел от 1 до 99 оставляет ровно восемь значений — от 40 до 47. Такой перебор полезен и как проверка, и как способ решить задачу, когда аналитический путь слишком громоздок.

> Ответ «x = 12» без пояснения, почему нет других решений, на проверке считается неполным. Обратная задача почти всегда требует либо перечисления всех значений, либо доказательства единственности.

```python
res = []
for x in range(1, 100):
    y = x
    for i in range(3):
        y = y // 2
    if y == 5:
        res.append(x)
print(res)              # 40..47
```

## 7\. Разобранные примеры

### Пример 1. Обратный ход через деление нацело

**Условие.** Программа
a = int(input())
a = a * 3
a = a + 4
a = a // 2
print(a)
вывела 20. Найдите все значения, которые могли быть введены.

**Решение.** Идём с конца. Перед последним шагом значение b удовлетворяло условию b // 2 = 20, значит, b равно 40 или 41. Перед прибавлением четвёрки c = b − 4, то есть 36 или 37. Перед умножением на 3 верно a * 3 = c. Проверяем оба варианта: 36 делится на 3, значит, a = 12; 37 не делится на 3 нацело, а переменная целая, поэтому вариант отпадает. Подстановка: 12 · 3 = 36, 36 + 4 = 40, 40 // 2 = 20.

**Ответ:** единственное значение a = 12.

### Пример 2. Ветвление даёт два решения

**Условие.** Программа
x = int(input())
if x >= 0:
    y = x * 2
else:
    y = -x
print(y)
вывела 8. Найдите все возможные значения x.

**Решение.** Первая ветвь: 2x = 8, откуда x = 4; условие 4 >= 0 истинно, решение подходит. Вторая ветвь: −x = 8, откуда x = −8; условие −8 >= 0 ложно, значит, ветвь else действительно была выбрана, решение подходит. Других ветвей в программе нет, поэтому список решений исчерпан.

**Ответ:** x = 4 или x = −8; ровно два решения.

### Пример 3. Цикл: ответ — промежуток

**Условие.** Программа
n = int(input())
for i in range(3):
    n = n // 2
print(n)
вывела 5. Найдите все натуральные n, при которых это возможно.

**Решение.** Один обратный шаг: перед делением значение лежало в промежутке от 10 до 11. Два шага назад: от 20 до 23. Три шага назад: от 40 до 47. Проверяем границы: 40 → 20 → 10 → 5, верно; 47 → 23 → 11 → 5, тоже верно. Проверяем соседей за границами: 39 → 19 → 9 → 4, а 48 → 24 → 12 → 6, значит, промежуток точный. Внутри него восемь значений, и каждое даёт 5.

**Ответ:** n принимает любое значение от 40 до 47, всего восемь решений.
