# Урок 16. Алгоритмическая конструкция «ветвление»: полная и неполная формы

**Раздел:** Алгоритмы и программирование
**Тема:** Исполнители и алгоритмы
**Класс:** 8

## 1\. Главное о теме

Ветвление превращает линейный алгоритм в алгоритм с выбором: исполнитель проверяет условие и идёт по одной из двух дорог. В полной форме действие предусмотрено для обоих исходов проверки, в неполной — только для одного, и путать эти формы нельзя.

Дальше разберём по шагам: условие — вопрос с двумя ответами; полная форма ветвления; неполная форма ветвления; составные условия; вложенные ветвления и выбор из нескольких случаев.

---

## 2\. Условие — вопрос с двумя ответами

> **Определение.** Условие — утверждение, которое может быть истинным или ложным; в алгоритме оно записывается с помощью операции сравнения.

Ветвление начинается с условия. Условие — это утверждение, про которое можно сказать только одно из двух: оно истинно или ложно. «Число 7 больше числа 3» — истинно, «число 7 чётное» — ложно, а «число 7 красивое» условием не является, потому что проверить его нельзя.

Простое условие содержит одно сравнение. В математике используют знаки <, >, ≤, ≥, =, ≠, а в программах на Python — свои обозначения. Важно запомнить разницу между знаком присваивания и знаком сравнения: одиночное «равно» кладёт значение в переменную, двойное — сравнивает два значения и даёт истину или ложь.

Условие не выполняется, а проверяется: исполнитель вычисляет его значение и получает «да» или «нет». После этого он выбирает, по какой ветви идти. Именно поэтому условие изображают ромбом с двумя выходами, а не прямоугольником действия.

| Сравнение | Математика | Python | Истинно при |
|:---|:---|:---|:---|
| больше | a > b | a > b | a = 7, b = 3 |
| меньше | a < b | a < b | a = 3, b = 7 |
| не меньше | a ≥ b | a >= b | a = 7, b = 7 |
| равно | a = b | a == b | a = 5, b = 5 |
| не равно | a ≠ b | a != b | a = 5, b = 4 |

> Классическая ошибка новичка — написать в условии `if x = 5` вместо `if x == 5`. В Python такое выражение вызовет сообщение об ошибке, а в некоторых других языках молча изменит значение переменной, и алгоритм будет работать совсем не так, как задумано.

## 3\. Полная форма ветвления

> **Определение.** Ветвление — алгоритмическая конструкция, в которой выполнение той или иной группы команд зависит от истинности условия.

**Ветвление** — конструкция, в которой порядок выполнения команд зависит от истинности условия. В полной форме предусмотрены действия для обоих исходов: одна группа команд выполняется, если условие истинно, другая — если ложно.

На блок-схеме полное ветвление выглядит так: ромб с условием, из него две стрелки с подписями «да» и «нет», каждая ведёт к своему блоку действий, а затем обе дороги сходятся в одну и алгоритм продолжается. В записи на алгоритмическом языке используют слова «если — то — иначе».

В программе на Python та же конструкция записывается через `if` и `else`, а принадлежность команд к ветви показывают отступы. Отступ — не украшение: именно он говорит компьютеру, какие строки относятся к ветви «то», а какие — к ветви «иначе».

> Обе ветви одновременно не выполняются никогда. После завершения выбранной ветви управление переходит к первой команде после ветвления — на схеме это место, где две стрелки снова соединяются.

```text
если a > b
  то max := a
  иначе max := b
всё
```

```python
if a > b:
    max = a
else:
    max = b
```

## 4\. Неполная форма ветвления

> **Определение.** Неполное ветвление — ветвление, в котором группа команд выполняется только при истинном условии, а при ложном не выполняется ни одна команда.

В неполной форме ветвь «иначе» отсутствует: команды выполняются только тогда, когда условие истинно, а при ложном условии исполнитель просто переходит к следующей команде. Так поступают, когда при одном исходе делать ничего не нужно.

Классический пример — вычисление модуля: если число отрицательное, его нужно заменить противоположным; если положительное или нулевое, менять нечего. Записывается это одной ветвью без «иначе».

Различать формы полезно по вопросу: «Что должно произойти, если условие ложно?» Если есть конкретное действие — нужна полная форма, если действия нет — неполная. Этот вопрос стоит задавать себе до того, как рисовать схему.

> Неполная форма — не «урезанная» полная, а самостоятельная конструкция. Добавлять пустую ветвь «иначе» с единственной командой «ничего не делать» не нужно: такая запись только запутывает читателя.

```python
if x < 0:
    x = -x
print(x)
```

## 5\. Составные условия

> **Определение.** Составное условие — условие, образованное из простых условий с помощью логических связок И, ИЛИ, НЕ.

Одного сравнения хватает не всегда. «Число двузначное» — это сразу два требования: оно не меньше 10 и не больше 99. Такое условие называют составным, а его части соединяют логическими связками.

Связка `and` требует, чтобы оба простых условия были истинны одновременно; `or` достаточно одного истинного; `not` меняет истину на ложь и наоборот. При вычислении действует порядок: сначала `not`, затем `and`, затем `or`, но надёжнее ставить скобки — тогда условие читается однозначно и без знания приоритетов.

| Связка | Смысл | Пример записи | Истинно при |
|:---|:---|:---|:---|
| and | И, оба сразу | x > 0 and x < 10 | x = 5 |
| or | ИЛИ, хотя бы одно | x < 0 or x > 100 | x = 150 |
| not | НЕ, отрицание | not (x == 0) | x = 7 |

> Двойное неравенство 0 < x < 10 в Python работает как составное условие, но в большинстве школьных языков (Паскаль, КуМир) его записывают через and: x > 0 and x < 10. Если перенести python-запись в такую среду, программа будет работать неверно.

## 6\. Вложенные ветвления и выбор из нескольких случаев

Ветвь может содержать любое число команд, в том числе ещё одно ветвление. Такая конструкция называется вложенной: сначала проверяется одно условие, и только внутри выбранной ветви — второе. В Python вложенность видна по отступам: каждая следующая ступень сдвинута вправо.

Когда случаев больше двух, удобнее не вкладывать ветвления друг в друга, а построить цепочку «иначе если». В Python для этого есть `elif`: условия проверяются сверху вниз, и выполняется ветвь первого истинного условия, а остальные даже не рассматриваются.

Из-за такого порядка условия нельзя расставлять как попало. Если первым поставить `mark >= 30`, то ученик с 90 баллами получит 2: проверка остановится на первом истинном условии, и до более точных условий дело не дойдёт.

> В цепочке elif условия принято располагать от самого строгого к самому мягкому. Проверяйте алгоритм на границах: 85, 70, 50 и 30 баллов должны давать тот результат, который задуман.

```python
if mark >= 85:
    print(5)
elif mark >= 70:
    print(4)
elif mark >= 50:
    print(3)
elif mark >= 30:
    print(2)
else:
    print(1)
```

## 7\. Разобранные примеры

### Пример 1. Полная форма: скидка в магазине

**Условие.** Магазин даёт скидку 10 % при сумме покупки больше 1000 рублей. Составьте алгоритм расчёта суммы к оплате и найдите её для покупок 1450 и 800 рублей.

**Решение.** Условие: sum > 1000. Если оно истинно, к оплате идёт 90 % суммы, иначе — вся сумма. Форма полная, потому что действие есть для обоих исходов.

Для 1450 рублей условие 1450 > 1000 истинно, поэтому pay = 1450 · 0,9 = 1305. Для 800 рублей условие ложно, выполняется ветвь «иначе»: pay = 800.

**Ответ:** 1305 рублей и 800 рублей.

### Пример 2. Неполная форма: модуль числа

**Условие.** Заменить число его модулем, если оно отрицательное. Проверьте алгоритм для x = −7 и x = 12.

**Решение.** При неотрицательном числе менять нечего, поэтому ветвь «иначе» не нужна — форма неполная.

Для x = −7 условие −7 < 0 истинно, выполняется x = −(−7) = 7, вывод даёт 7. Для x = 12 условие 12 < 0 ложно, команда внутри ветви пропускается, и сразу выполняется вывод: 12.

**Ответ:** 7 и 12; при ложном условии значение не меняется.

### Пример 3. Вложенное ветвление: наибольшее из трёх чисел

**Условие.** Найти наибольшее из чисел a = 8, b = 3, c = 11, используя вложенные ветвления.

**Решение.** Сначала сравним a и b. Если a больше, то наибольшим может быть только a или c — сравниваем их. Если a не больше b, то наибольшим может быть b или c.

Подставляем числа. Первая проверка: 8 > 3 — истина, идём во внешнюю ветвь «то». Вторая проверка: 8 > 11 — ложь, значит, выполняется внутренняя ветвь «иначе»: mx = c = 11. Внешняя ветвь «иначе» при этом не выполняется вовсе.

**Ответ:** 11.
