## 1\. Главное о теме

Линейная программа выполняется сверху вниз, без пропусков и повторов, поэтому вся её логика — в правильной записи выражений. Один неверный приоритет операции или лишний знак деления превращает верный алгоритм в неверный ответ.

Дальше разберём по шагам: линейный алгоритм; арифметические выражения и приоритет операций; целочисленное деление и остаток; тип результата и округление; типичные ошибки в записи выражений.

---

## 2\. Линейный алгоритм

> **Определение.** Линейный алгоритм — алгоритм, в котором все команды выполняются последовательно, в порядке записи, и каждая ровно один раз.

**Линейным** называют алгоритм, в котором команды выполняются последовательно, в порядке записи, и каждая ровно один раз. В нём нет условий и повторений: программа не выбирает путь и не возвращается назад. Именно такие алгоритмы решают большинство расчётных задач — от пересчёта валюты до вычисления площади.

На блок-схеме линейный алгоритм выглядит как вертикальная цепочка: овал «начало», затем прямоугольники действий и параллелограммы ввода-вывода, в конце овал «конец». Стрелка всегда одна и идёт вниз — ветвлений нет. Такая схема читается сверху вниз, как и сама программа.

По линейному принципу устроены и бытовые инструкции: «достань ключ, вставь в замок, поверни два раза, открой дверь». Если переставить шаги, результат изменится. В программе так же: порядок строк — часть алгоритма, а не оформление.

## 3\. Арифметические выражения и приоритет операций

> **Определение.** Арифметическое выражение — запись из чисел, переменных и знаков арифметических операций, значение которой вычисляется по правилам приоритета.

Выражение в программе записывается в одну строку, без дробной черты и без «двухэтажных» формул. Поэтому важно, где поставить скобки. Знаки операций в Python те же, что в математике, плюс три особых: `//` — целочисленное деление, `%` — остаток, `**` — возведение в степень.

Порядок действий определяется приоритетом. Сначала выполняется возведение в степень, затем умножение, деление, целочисленное деление и остаток (они равноправны и выполняются слева направо), в последнюю очередь — сложение и вычитание. Скобки отменяют этот порядок: всё, что внутри, вычисляется первым.

В первой строке: `4 ** 2 = 16`, затем `3 * 16 = 48`, затем `48 // 8 = 6`, затем `2 + 6 − 1 = 7`. В третьей строке видно, что унарный минус слабее степени: `-2 ** 2` равно −4, а `(-2) ** 2` равно 4. Степень выполняется справа налево, поэтому `2 ** 3 ** 2` — это `2 ** 9 = 512`, а не `8 ** 2`.

| Операция | Знак | Пример | Результат |
|:---|:---|:---|:---|
| сложение | + | 7 + 2 | 9 |
| вычитание | − | 7 − 2 | 5 |
| умножение | * | 7 * 2 | 14 |
| деление | / | 7 / 2 | 3.5 |
| целочисленное деление | // | 7 // 2 | 3 |
| остаток | % | 7 % 2 | 1 |
| степень | ** | 7 ** 2 | 49 |

> Знак `^` в Python не возводит в степень, а выполняет другую операцию: `2 ^ 3` даёт 1, а не 8. Для степени используется только `**`, поэтому запись `x ^ 2` — типичная ошибка переноса из математики.

```python
print(2 + 3 * 4 ** 2 // 8 - 1)
print((2 + 3) * 4)
print(-2 ** 2, (-2) ** 2)
print(2 ** 3 ** 2)
```

## 4\. Целочисленное деление и остаток

Обычное деление `/` в Python всегда даёт вещественное число: `8 / 2` равно `4.0`, а не `4`. Если нужна только целая часть, применяют `//`: `7 // 2 = 3`. Остаток от деления даёт `%`: `7 % 2 = 1`. Эти две операции всегда работают в паре и связаны равенством `a = (a // b) * b + a % b`.

Целочисленное деление и остаток незаменимы, когда целое нужно разложить на части. Секунды раскладываются на часы, минуты и секунды; конфеты — на полные пакеты и остаток; число — на чётность (остаток от деления на 2). Во всех случаях важен именно целый результат, а не дробь.

Первая строка даёт число полных часов: `3725 // 3600 = 1`. Вторая — число полных минут в остатке: `3725 % 3600 = 125`, затем `125 // 60 = 2`. Третья — оставшиеся секунды: `3725 % 60 = 5`. Вместе: 1 час 2 минуты 5 секунд.

> Для отрицательных чисел Python округляет вниз, а не к нулю: `-7 // 2 = -4`, `-7 % 2 = 1`. В школьных задачах мы работаем с неотрицательными числами, где результат совпадает с привычным делением с остатком.

```python
sec = 3725
print(sec // 3600)
print(sec % 3600 // 60)
print(sec % 60)
```

## 5\. Тип результата и округление

Тип результата зависит от операции: `+`, `−`, `*` над целыми дают целое, а `/` — всегда `float`. Поэтому `10 / 2` на экране выглядит как `5.0`. Если нужен целый вид, применяют преобразование `int(...)`, но оно именно **отбрасывает** дробную часть: `int(3.9) = 3`, `int(-3.9) = -3`.

Для настоящего округления есть функция `round`. С одним аргументом она округляет до целого, со вторым — до указанного числа знаков после запятой: `round(3.14159, 2) = 3.14`. При ровно половине Python округляет к чётному: `round(2.5) = 2`, `round(3.5) = 4`.

Последняя строка показывает особенность вещественных чисел: `0.1 + 0.2` даёт `0.30000000000000004`. Причина в том, что в двоичной памяти дробь хранится приближённо. Для школьных задач это не мешает, но результат сравнения дробей и вывода денежных сумм требует округления: `round(0.1 + 0.2, 2)` вернёт `0.3`.

> `int(2.99)` равно 2, а не 3. Если требуется округление, а не отбрасывание, используйте `round`, иначе ошибка в ответе появится незаметно.

```python
print(10 / 2, int(10 / 2))
print(7 / 2, round(7 / 2))
print(round(2.5), round(3.5))
print(0.1 + 0.2)
```

## 6\. Типичные ошибки в записи выражений

Первая группа ошибок — потерянный знак умножения. В математике `2x` означает «два умножить на x», в Python такая запись вызовет синтаксическую ошибку: между числом и переменной нужен `*`. Вторая группа — неверный приоритет: среднее арифметическое `(a + b) / 2` без скобок превращается в `a + b / 2`, и при `a = 5`, `b = 4` вместо 4.5 получается 7.

Третья группа связана с типами: там, где ожидается дробный ответ, случайно применённое `//` даёт целое и молча теряет остаток. Четвёртая — деление на ноль: оно останавливает программу с ошибкой `ZeroDivisionError`, и никакого «бесконечно большого числа» не появляется.

| Ошибка | Как записано | Как правильно |
|:---|:---|:---|
| нет знака умножения | 2x | 2 * x |
| степень через ^ | x ^ 2 | x ** 2 |
| потеряны скобки | a + b / 2 | (a + b) / 2 |
| целое вместо дроби | 7 // 2 | 7 / 2 |
| деление на ноль | 10 / 0 | проверить делитель |

> Проверяйте формулу на простых числах, где ответ считается устно. Если выражение верно для 2 и 3, оно, скорее всего, верно и для больших значений; если расходится — ошибка в скобках или в знаке операции.

## 7\. Разобранные примеры

### Пример 1. Вычисление выражения по шагам

**Условие.** Вычислите значение выражения `2 + 3 * 4 ** 2 // 8 - 1`, не запуская программу.

**Решение.** Расставим порядок действий по приоритету. Сначала степень: `4 ** 2 = 16`. Затем умножение и целочисленное деление слева направо: `3 * 16 = 48`, `48 // 8 = 6`. Теперь сложение и вычитание слева направо: `2 + 6 = 8`, `8 - 1 = 7`.

**Ответ:** 7.

### Пример 2. Секунды в часы, минуты и секунды

**Условие.** Дано число секунд 3725. Получите количество полных часов, минут и оставшихся секунд.

**Решение.** Полные часы: `3725 // 3600 = 1`, так как в часе 3600 секунд. Остаток после часов: `3725 % 3600 = 125`. Полные минуты в остатке: `125 // 60 = 2`. Оставшиеся секунды: `3725 % 60 = 5`. Проверка: `1 * 3600 + 2 * 60 + 5 = 3725` — сходится.

**Ответ:** 1 час 2 минуты 5 секунд.

### Пример 3. Среднее арифметическое и потерянные скобки

**Условие.** Программа должна находить среднее двух чисел. Ученик написал `s = a + b / 2` и при `a = 5`, `b = 4` получил 7 вместо 4.5. Найдите ошибку и исправьте программу.

**Решение.** Приоритет деления выше сложения, поэтому сначала вычисляется `b / 2 = 2`, а затем `5 + 2 = 7`. Складывать нужно до деления, значит, сумму требуется заключить в скобки: `s = (a + b) / 2`. Тогда `(5 + 4) / 2 = 9 / 2 = 4.5`.

**Ответ:** `s = (a + b) / 2`; при указанных данных результат 4.5.
