## 1\. Главное о теме

Линейная программа выполняет команды строго по порядку и не умеет выбирать. Оператор ветвления даёт ей второе измерение: теперь ход работы зависит от условия, а условие записывается как логическое выражение.

Дальше разберём по шагам: почему линейной программы недостаточно; оператор if: как python записывает выбор; полная форма, неполная форма и цепочка elif; составные условия: and, or, not; граничные случаи и типичные ошибки.

---

## 2\. Почему линейной программы недостаточно

> **Определение.** Ветвление — форма организации действий, при которой выполнение одной или другой последовательности команд зависит от истинности некоторого условия.

Линейная программа похожа на рецепт, в котором нет ни одного «если»: сделай это, потом это, потом это. Так решается задача «найти площадь прямоугольника по двум сторонам». Но стоит спросить у программы «а число-то положительное?» — и линейная схема ломается: ответ зависит от того, что ввели.

Ветвление позволяет выполнять разные действия при разных исходных данных. Условие в нём — это выражение, которое может быть истинным или ложным: `x > 0`, `x % 2 == 0`, `a != b`. Программа проверяет условие и идёт по той ветке, которая соответствует результату проверки.

> Условие в ветвлении — не вопрос «какое число больше», а проверка, у которой ровно два исхода: истина или ложь. Формулируйте условие так, чтобы на него можно было ответить «да» или «нет».

```text
Схема ветвления:

        (начало)
           |
      [ x > 0 ? ]
      да /     \ нет
        /       \
  [ "плюс" ]  [ "не плюс" ]
        \       /
         \     /
         (конец)

Ромб — проверка условия, прямоугольники — действия.
```

## 3\. Оператор if: как Python записывает выбор

> **Определение.** Условный оператор — команда языка программирования, которая выполняет группу действий только при истинности указанного условия.

В Python выбор записывается оператором `if`. После слова `if` идёт условие, после условия — двоеточие, а с новой строки, с отступом, — команды, которые выполняются только при истинном условии. Отступ в четыре пробела и есть граница ветки: всё, что написано с отступом, принадлежит ей.

Во фрагменте выше от программы зависит только одна строка. Строка `print("Работа завершена")` написана без отступа, поэтому выполняется всегда — и при положительном числе, и при отрицательном. Это самый частый источник недоразумений: ученик ставит отступ «для красоты» или, наоборот, забывает его, и программа ведёт себя не так, как задумано.

> Отступ нельзя смешивать: если начали блок четырьмя пробелами, не используйте табуляцию. Python сообщит об ошибке `IndentationError` или `TabError` ещё до запуска программы.

```python
x = int(input("Введите число: "))
if x > 0:
    print("Число положительное")
print("Работа завершена")
```

## 4\. Полная форма, неполная форма и цепочка elif

Если после «сделать» нужно ещё и «иначе сделать другое», применяют полную форму с `else`. `else` пишется без условия и без двоеточия после условия — только с двоеточием. Ветка `else` выполняется тогда, когда условие `if` оказалось ложным.

Когда вариантов больше двух, удобна цепочка `elif` (сокращение от else if). Проверка идёт сверху вниз: как только одно условие оказалось истинным, выполняется его ветка, а остальные условия уже не проверяются.

При `ball = 50` первое условие ложно, второе истинно — выводится «средний уровень». При `ball = 80` истинно уже первое условие, и до проверки `>= 50` дело не доходит.

| Форма записи | Как выглядит | Сколько веток |
|:---|:---|:---|
| Неполная | if условие: | одна, может не выполниться |
| Полная | if условие: else: | две, выполняется ровно одна |
| Цепочка | if, затем elif, затем else | столько, сколько условий, плюс else |

> Порядок условий — часть алгоритма. Если в примере выше поставить `ball >= 50` первым, то для 95 баллов программа скажет «средний уровень»: до более строгого условия очередь не дойдёт.

```python
ball = int(input("Баллы: "))
if ball >= 80:
    print("высокий уровень")
elif ball >= 50:
    print("средний уровень")
else:
    print("низкий уровень")
```

## 5\. Составные условия: and, or, not

> **Определение.** Составное условие — условие, образованное из простых условий с помощью логических операций and, or и not.

Одного сравнения часто мало. «Число двузначное и чётное» — это два простых условия, соединённых логической операцией `and`. «Число отрицательное или больше ста» — два условия, соединённых `or`. Логическая операция `not` отрицает условие: `not (x > 0)` истинно ровно тогда, когда ложно `x > 0`.

Приоритет операций такой: сначала `not`, потом `and`, потом `or`. Скобки меняют порядок, поэтому сложное условие всегда полезно заключать в скобки — так его проще читать и проверять.

В Python двойное сравнение `10 <= x <= 99` записывается так же естественно, как в математике. Оно истинно, когда выполняются оба неравенства; то же самое можно записать через `and`, но короче читается именно двойное сравнение.

| a | b | a and b | a or b |
|:---|:---|:---|:---|
| истина | истина | истина | истина |
| истина | ложь | ложь | истина |
| ложь | истина | ложь | истина |
| ложь | ложь | ложь | ложь |

> `and` требует выполнения обоих условий, `or` — хотя бы одного. Условие `x > 0 or x < 10` истинно всегда: любое число либо больше нуля, либо меньше десяти. Такие условия — типичная логическая ошибка.

```python
x = int(input("Введите число: "))
if 10 <= x <= 99 and x % 2 == 0:
    print("двузначное чётное")
else:
    print("не подходит")
```

## 6\. Граничные случаи и типичные ошибки

Ветвление легко написать, но трудно написать правильно: ошибки прячутся не в синтаксисе, а в границах. Сравнение `x > 10` и `x >= 10` отличается ровно одним входным значением — и именно оно чаще всего встречается в проверочной работе. То же с чётностью: `x % 2 == 0` истинно для чётных, включая ноль и отрицательные чётные числа.

Отдельная ловушка — сравнение вещественных чисел. Результат вычисления `0.1 + 0.2` в Python равен не ровно `0.3`, а `0.30000000000000004`, поэтому условие `D == 0` для дискриминанта может не сработать там, где математически ноль и есть. В таких задачах сравнивают с малой величиной: `abs(D) < 1e-9`.

| Ошибка | Как написано | Как надо |
|:---|:---|:---|
| Путаница присваивания и сравнения | if x = 5: | if x == 5: |
| Нет отступа у тела ветки | if x > 0: print(x) | тело с отступом в 4 пробела |
| Ветка else перед elif | else: ... elif ... | elif идёт до else |
| Потерян двоеточие | if x > 0 | if x > 0: |

> Хороший тест проверяет не только «типичное» значение. Для задачи «больше ли число десяти» нужны как минимум три проверки: 25 (истина), 3 (ложь) и 10 (граница, ответ «нет», если сравнение строгое).

## 7\. Разобранные примеры

### Пример 1. Наибольшее из трёх чисел без функции max

**Условие.** Даны три целых числа: 17, 42 и 31. Найти наибольшее, не используя встроенную функцию `max()`.

**Решение.** Сначала находим победителя среди первых двух чисел и запоминаем его в переменной `mx`. Затем сравниваем `mx` с третьим числом: если третье больше, оно становится новым победителем. Получается два независимых ветвления.

По шагам: `mx = 17`; проверка `42 > 17` истинна, значит `mx = 42`; проверка `31 > 42` ложна, `mx` остаётся прежним. В программе это записывается так: `mx = a`, затем `if b > mx: mx = b` и `if c > mx: mx = c`. Оба сравнения — отдельные операторы `if`, а не `elif`: проверки независимы, и вторая выполняется даже после того, как первая оказалась истинной.

**Ответ:** 42.

### Пример 2. Квадратное уравнение с проверкой дискриминанта

**Условие.** Решить уравнение x² − 5x + 6 = 0, выведя число корней и сами корни.

**Решение.** Коэффициенты: a = 1, b = −5, c = 6. Дискриминант D = b² − 4ac = (−5)² − 4·1·6 = 25 − 24 = 1. Так как D > 0, корней два: x₁ = (5 + 1) / 2 = 3, x₂ = (5 − 1) / 2 = 2. В программе три случая разбирает цепочка `if — elif — else`.

Записывается это так: `a, b, c = 1, -5, 6`, затем `D = b * b - 4 * a * c`, а дальше цепочка `if D > 0` с корнями `x1 = (-b + D ** 0.5) / (2 * a)` и `x2 = (-b - D ** 0.5) / (2 * a)`, `elif D == 0` с выводом `-b / (2 * a)` и `else` с сообщением «Корней нет».

При D = 0 корень один, и формула x = −b / (2a) даёт его без вычисления квадратного корня. При D < 0 ветка `else` сообщает, что действительных корней нет.

**Ответ:** два корня: 3 и 2.

### Пример 3. Составное условие: високосный год

**Условие.** Определить, является ли год високосным. Год високосный, если он делится на 4, но не делится на 100, либо делится на 400. Проверить 1900, 2000, 2023 и 2024.

**Решение.** Условие распадается на две части, соединённые `or`: `(год % 4 == 0 and год % 100 != 0) or год % 400 == 0`. Скобки обязательны по смыслу: без них `and` «прилипнет» только к последнему сравнению.

Условие записывается одной строкой: `if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:` — при истине выводится «Високосный», иначе «Не високосный».

Проверяем: 1900 делится на 4, но делится и на 100, значит первая часть ложна; на 400 не делится — итог «не високосный». 2000 делится на 400 — «високосный». 2023 на 4 не делится — «не високосный». 2024 делится на 4 и не делится на 100 — «високосный».

**Ответ:** 1900 — нет, 2000 — да, 2023 — нет, 2024 — да.
