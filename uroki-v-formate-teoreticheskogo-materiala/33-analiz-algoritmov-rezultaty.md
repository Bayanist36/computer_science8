## 1\. Главное о теме

Алгоритм — это функция: каждому входу соответствует ровно один выход. Значит, результат можно получить без запуска программы — пройти по шагам, записать значения в таблицу и прочитать последнюю строку.

Дальше разберём по шагам: результат как следствие входных данных; таблица трассировки: как её вести; ветвление: разбор по ветвям; циклы: число повторений и накопители; возможные результаты: перебор вариантов.

---

## 2\. Результат как следствие входных данных

> **Определение.** Анализ алгоритма — исследование его работы без запуска: определение результата при заданных входных данных и выяснение того, какие результаты возможны вообще.

У детерминированного алгоритма нет свободы выбора: при одном и том же входе и одной и той же среде он всегда даёт один и тот же результат. Это свойство превращает алгоритм в функцию — правило, которое каждому допустимому входу ставит в соответствие выход. Именно поэтому результат можно вычислить карандашом на бумаге: никакой скрытой случайности в изученных конструкциях нет.

Различайте два вопроса, которые звучат похоже. Первый: «что выведет программа при n = 42?» — здесь ответ единственный, и его даёт трассировка. Второй: «какие значения вообще может вывести эта программа?» — здесь ответом служит множество, и его получают перебором классов входов: по ветвям, по чётности, по количеству цифр. Второй вопрос сложнее, но именно он проверяет, понимаете ли вы алгоритм, а не умеете ли считать.

Обратное утверждение неверно: одинаковый результат могут дать разные входы. Программа, печатающая остаток от деления на 3, выдаст 1 и для 4, и для 7, и для 100. Поэтому «возможные результаты» — это множество выходов, а не список входов; сколько входов приходится на каждый выход, мы разберём на следующем уроке.

> Детерминированность не означает предсказуемость «на глаз». Программа из пяти строк с двумя переменными и циклом может дать результат, который интуиция не угадывает: именно поэтому нужна таблица, а не прикидка.

## 3\. Таблица трассировки: как её вести

> **Определение.** Таблица трассировки — таблица, в которой каждая строка фиксирует значения переменных после очередного шага алгоритма.

Трассировка — это запись исполнения. Порядок работы такой: сначала выписываем переменные и их начальные значения, затем выполняем команды строго по порядку и после каждой записываем новое состояние. Строка таблицы соответствует одному шагу, столбец — одной переменной. Если переменная на этом шаге не менялась, её значение просто переносится в новую строку.

Для цикла удобнее считать шагом не строку кода, а одну итерацию: тогда видно, сколько раз тело выполнилось и на каком значении условие стало ложным. Для ветвления полезно добавить столбец «какая ветвь выбрана»: это защищает от ошибки, когда ученик выполняет обе ветви подряд.

Разберём этот фрагмент. Начальные значения: n = 4, s = 1. Цикл перебирает i от 1 до 4. После i = 1: s = 1. После i = 2: s = 2. После i = 3: s = 6. После i = 4: s = 24. Цикл закончился, на экран выводится 24 — это факториал числа 4.

| Шаг | i | s после шага | Проверка условия |
|:---|:---|:---|:---|
| начало | — | 1 | — |
| 1 | 1 | 1 | 1 в диапазоне |
| 2 | 2 | 2 | 2 в диапазоне |
| 3 | 3 | 6 | 3 в диапазоне |
| 4 | 4 | 24 | 4 в диапазоне |
| конец | 5 | 24 | 5 вне диапазона |

> Типичная ошибка — начинать накопитель с нуля там, где идёт умножение. С s = 0 произведение всегда останется нулём. Для суммы начальное значение 0, для произведения — 1.

```python
n = 4
s = 1
for i in range(1, n + 1):
    s = s * i
print(s)                # 24
```

## 4\. Ветвление: разбор по ветвям

При трассировке ветвления главное — не выполнять лишнего. Проверка идёт сверху вниз: как только условие оказалось истинным, выполняется его блок, а все остальные ветви пропускаются целиком, вместе с их условиями. Поэтому порядок ветвей меняет результат: строгое условие должно стоять выше общего.

Проверим три входа. Для x = −5 первое условие истинно: y = 5, остальные ветви не проверяются. Для x = 3 первое условие ложно, второе истинно: y = 6. Для x = 10 первое ложно (10 не меньше 0), второе ложно (10 не меньше 10), значит, работает else: y = 11. Особый случай — x = 0: он не меньше нуля, поэтому попадает во вторую ветвь и даёт y = 0.

| Вход x | Первое условие | Второе условие | Ветвь | Результат y |
|:---|:---|:---|:---|:---|
| −5 | истинно | не проверяется | первая | 5 |
| 0 | ложно | истинно | вторая | 0 |
| 3 | ложно | истинно | вторая | 6 |
| 10 | ложно | ложно | else | 11 |

> Ошибка на границе — самая частая в заданиях с ветвлением. Сравнение x < 10 и x <= 10 дают разные наборы входов: во втором случае число 10 попадает во вторую ветвь и результат меняется с 11 на 20.

```python
x = int(input())
if x < 0:
    y = -x
elif x < 10:
    y = x * 2
else:
    y = x + 1
print(y)
```

## 5\. Циклы: число повторений и накопители

Цикл — единственная конструкция, где число шагов зависит от данных. Для while оно заранее неизвестно и определяется тем, как быстро меняется переменная условия. Ускорение или замедление этого изменения меняет результат целиком: если делить на 3 вместо 2, итераций станет меньше, а итоговое значение другим.

Проследим: 200 → 100 (k = 1) → 50 (2) → 25 (3) → 12 (4) → 6 (5) → 3 (6) → 1 (7). Теперь условие 1 > 1 ложно, цикл закончен, выводится «1 7». Обратите внимание на шаг 25 → 12: деление нацело отбрасывает остаток, поэтому последовательность не совпадает с точным делением пополам.

| Итерация | n до тела | n после тела | k |
|:---|:---|:---|:---|
| 1 | 200 | 100 | 1 |
| 2 | 100 | 50 | 2 |
| 3 | 50 | 25 | 3 |
| 4 | 25 | 12 | 4 |
| 5 | 12 | 6 | 5 |
| 6 | 6 | 3 | 6 |
| 7 | 3 | 1 | 7 |

> Последняя проверка условия в таблицу значений не входит: когда n = 1, тело уже не выполняется, и k остаётся равным 7, а не 8. Именно на этом шаге чаще всего ошибаются при подсчёте итераций.

```python
n = 200
k = 0
while n > 1:
    n = n // 2
    k = k + 1
print(n, k)
```

## 6\. Возможные результаты: перебор вариантов

Чтобы найти все возможные результаты, не нужно перебирать все числа. Достаточно разбить входы на классы, внутри которых программа ведёт себя одинаково: по выбранной ветви, по чётности, по числу цифр. Каждый класс даёт один результат или короткую формулу, и множество результатов складывается из них.

Для x от 1 до 3 работает первая ветвь: получаются 2, 4, 6. Для x от 4 до 6 работает вторая: получаются 1, 2, 3. Объединяем: возможные результаты — 1, 2, 3, 4, 6. Значение 5 не получается ни при одном входе, хотя лежит внутри диапазона. Это и есть ответ на вопрос «может ли программа вывести 5» — не может.

> Вопрос «какие результаты возможны» проверяют обратным ходом: берут подозрительное значение и смотрят, есть ли вход, который его даёт. Отсутствие такого входа нужно доказать разбором всех ветвей, а не фразой «не получилось».

```python
x = int(input())        # 1 <= x <= 6
if x <= 3:
    y = x * 2
else:
    y = x - 3
print(y)
```

## 7\. Разобранные примеры

### Пример 1. Трассировка цикла с умножением

**Условие.** Определите, что выведет программа и что она вычисляет:
n = 4
s = 1
for i in range(1, n + 1):
    s = s * i
print(s)

**Решение.** Выписываем переменные: n = 4, s = 1. Цикл перебирает i = 1, 2, 3, 4. После первого шага s = 1 · 1 = 1. После второго s = 1 · 2 = 2. После третьего s = 2 · 3 = 6. После четвёртого s = 6 · 4 = 24. Затем i становится 5, диапазон исчерпан, цикл заканчивается. На экран выводится 24.

**Ответ:** 24; программа вычисляет факториал числа 4, то есть произведение всех чисел от 1 до 4.

### Пример 2. Все ветви одного алгоритма

**Условие.** Для программы
x = int(input())
if x < 0:
    y = -x
elif x < 10:
    y = x * 2
else:
    y = x + 1
print(y)
определите результат при x = −5, x = 0 и x = 10. Объясните, почему для x = 0 выбрана вторая ветвь.

**Решение.** При x = −5 первое условие −5 < 0 истинно: y = −(−5) = 5, остальные ветви пропускаются. При x = 0 первое условие ложно, потому что 0 не меньше 0; второе условие 0 < 10 истинно, значит, работает вторая ветвь: y = 0 · 2 = 0. При x = 10 оба условия ложны: 10 не меньше 0 и не меньше 10, поэтому выполняется else: y = 10 + 1 = 11.

**Ответ:** 5, 0 и 11 соответственно.

### Пример 3. Множество результатов

**Условие.** Какие значения может вывести программа
for x in range(1, 5):
    if x % 2 == 0:
        print(x * 10)
    else:
        print(x + 1)
и в каком порядке они появляются?

**Решение.** Цикл перебирает x = 1, 2, 3, 4. Для x = 1 условие ложно, выводится 1 + 1 = 2. Для x = 2 условие истинно, выводится 2 · 10 = 20. Для x = 3 выводится 4. Для x = 4 выводится 40. Всего четыре вывода, и все они различны.

**Ответ:** 2, 20, 4, 40 — именно в таком порядке; множество возможных результатов содержит четыре значения.

## 10\. Итоги урока

На этом уроке вы узнали:

✅ **Результат как следствие входных данных.** Алгоритм детерминирован: вход определяет выход; один и тот же вход — всегда один и тот же результат.

✅ **Возможные результаты: перебор вариантов.** Один вход — один результат; много входов — множество результатов.
