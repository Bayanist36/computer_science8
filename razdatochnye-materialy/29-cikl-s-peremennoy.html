1Ключевые определения

Цикл с переменной (счётный цикл) — цикл, в котором число повторений задаётся заранее перечислением значений переменной-счётчика.
Накопитель — переменная, которая до цикла получает начальное значение, а внутри цикла на каждом шаге изменяется, собирая результат.
Простое число — натуральное число, большее единицы, которое делится без остатка только на 1 и на само себя.

3Опорный конспект

ЦИКЛ С ПЕРЕМЕННОЙ (for)

for i in range(...):     # для каждого i из диапазона
    тело                 # отступ 4 пробела

range(n)          0 .. n-1
range(a, b)       a .. b-1     правая граница НЕ входит
range(a, b, s)    шаг s;  при s < 0 - обратный ход
range(1, 101)     числа от 1 до 100

ШАБЛОНЫ
  накопитель: s = 0  до цикла;  s = s + i  в теле
  счётчик:    k = 0  до цикла;  k = k + 1  в теле

ТИПОВЫЕ ЗАДАЧИ
  делимость:  if n % d == 0  ->  d делитель n
