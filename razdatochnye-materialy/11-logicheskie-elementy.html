1Ключевые определения

Логический элемент (вентиль) — электронная схема с одним или несколькими входами и одним выходом, которая реализует одну логическую операцию над двоичными сигналами.
Комбинационная схема — схема из логических элементов, выход которой определяется только текущей комбинацией входных сигналов.

3Опорный конспект

ЛОГИЧЕСКИЕ ЭЛЕМЕНТЫ (ВЕНТИЛИ)

Вентиль = схема, реализующая одну логическую операцию
  1 - высокий уровень, 0 - низкий уровень

НЕ (инвертор):  A -> ¬A        0->1, 1->0
И  (AND):  1 только если все входы 1
ИЛИ (OR):  1 если хотя бы один вход 1

  A  B | A∧B  A∨B
  0  0 |  0    0
  0  1 |  0    1
  1  0 |  0    1
  1  1 |  1    1

СХЕМА: выход одного -> вход другого
