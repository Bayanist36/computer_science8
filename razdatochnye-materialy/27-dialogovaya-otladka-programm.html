ОТЛАДКА: три вида ошибок
  синтаксис  -> не запускается, есть номер строки
  выполнение -> падает на данных (ValueError, ZeroDivision)
  логика     -> работает, но ответ неверный

ДИАЛОГОВАЯ ОТЛАДКА
  точка останова ---> программа стоит на строке
  шаг с заходом ----> одна строка, внутрь функции
  шаг без захода ---> строка целиком
  продолжить -------> до следующей остановки
  окно переменных --> значения СЕЙЧАС

Задание 1. а) синтаксическая: до запуска, есть номер строки; б) времени выполнения: ValueError на конкретных данных; в) логическая: программа работает, но результат неверный; г) синтаксическая: отсутствует обязательное двоеточие.

Задание 2. Начальное значение mx = 0 неверно: оно заведомо больше всех отрицательных чисел, поэтому ни одно не становится максимумом. Начинать нужно с первого введённого числа: mx = int(input()), а затем сравнивать с остальными. Для набора −5, −2, −9 правильный ответ −2.
