1Ключевые определения

Таблица истинности — таблица, в которой для всех возможных наборов значений логических переменных указаны значения логического выражения.
Равносильные логические выражения — выражения, принимающие одинаковые значения при всех возможных наборах значений входящих в них переменных.

1Ответы к заданиям

Задание 1. Строки 000–111. A ∨ B: 0, 1, 1, 1, 1, 1, 1, 1. ¬C: 1, 0, 1, 0, 1, 0, 1, 0. F = 0, 0, 1, 0, 1, 0, 1, 0. Единицы стоят в строках 010, 100, 110: там C = 0 и хотя бы одна из переменных A или B истинна.

Задание 2. 2 переменные — 4 строки; 3 — 8; 5 — 32; 8 — 256. Число строк равно 2ⁿ, где n — число различных переменных; каждая новая переменная удваивает таблицу.

Задание 3. Верный столбец: 0, 0, 0, 1. Ученик поставил единицу в строке 01, где A = 0, а конъюнкция при нулевом операнде всегда равна нулю. Кроме того, его столбец содержит две единицы и похож на столбец B: значение 0, 1, 0, 1 повторяет значения второй переменной, значит ученик копировал столбец B, а не вычислял операцию.

Задание 4. Оба столбца одинаковы: 0, 0, 0, 0, 0, 1, 1, 1 для строк 000–111. Выражения равносильны; подтверждается распределительный закон: A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C). Единицы появляются только там, где A = 1 и хотя бы одна из переменных B, C истинна.
