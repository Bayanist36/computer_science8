Задание 1. Трассировка линейного алгоритма

Выполните алгоритм при a := 3: b := a · 2; a := b − a; b := a + b. Заполните таблицу состояний и назовите итоговые значения.

Задание 2. Сумма квадратов

Выполните алгоритм: s := 0; нц для i от 1 до 5; s := s + i · i; кц. Чему равно s и сколько итераций выполнило тело цикла?

Задание 3. Сумма цифр числа

Выполните алгоритм при n := 13: k := 0; нц пока n ≠ 0; k := k + n mod 10; n := n div 10; кц. Чему равно k?

1Ответы к заданиям

Задание 1. Шаг 1: b := 3 · 2 = 6, состояние a = 3, b = 6. Шаг 2: a := 6 − 3 = 3, состояние a = 3, b = 6. Шаг 3: b := 3 + 6 = 9, состояние a = 3, b = 9. Ответ: a = 3, b = 9.

Задание 2. Тело выполнилось 5 раз: s = 1 + 4 + 9 + 16 + 25 = 55. Ответ: s = 55, итераций 5.

Задание 3. Первая итерация: n mod 10 = 3, k = 3, n := 1. Вторая: n mod 10 = 1, k = 4, n := 0. Условие 0 ≠ 0 ложно, цикл завершён. Ответ: k = 4, то есть сумма цифр числа 13.

Задание 4. Ученик считает проверки итерациями. Проверок действительно семь, но последняя проверка (1 > 1) ложна, и тело после неё не выполняется. Итераций шесть, поэтому k = 6.
