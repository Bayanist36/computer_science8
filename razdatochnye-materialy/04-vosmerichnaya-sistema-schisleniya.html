1Ответы к заданиям

Задание 1. 0 — 000, 1 — 001, 2 — 010, 3 — 011, 4 — 100, 5 — 101, 6 — 110, 7 — 111. 34₈ = 011 100 = 11100₂; 607₈ = 110 000 111 = 110000111₂.

Задание 2. а) 010 111 100 = 10111100₂; б) 111 101 011 = 111101011₂; в) 001 000 010 = 1000010₂.

Задание 3. а) 001 011 011 = 133₈ (91 в десятичной); б) 100 111 = 47₈ (39); в) 011 001 = 31₈ (25).

Задание 4. 2024 : 8 = 253 (остаток 0); 253 : 8 = 31 (5); 31 : 8 = 3 (7); 3 : 8 = 0 (3). Читаем снизу вверх: 3750₈. Проверка: 3·512 + 7·64 + 5·8 + 0 = 1536 + 448 + 40 = 2024.
