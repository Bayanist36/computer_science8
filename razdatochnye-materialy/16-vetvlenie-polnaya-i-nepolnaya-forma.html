1Ключевые определения

Условие — утверждение, которое может быть истинным или ложным; в алгоритме оно записывается с помощью операции сравнения.
Ветвление — алгоритмическая конструкция, в которой выполнение той или иной группы команд зависит от истинности условия.
Неполное ветвление — ветвление, в котором группа команд выполняется только при истинном условии, а при ложном не выполняется ни одна команда.
Составное условие — условие, образованное из простых условий с помощью логических связок И, ИЛИ, НЕ.

1Ответы к заданиям

Задание 1. а) полная; б) неполная; в) полная; г) неполная — при годной детали никакого особого действия не требуется, она просто идёт дальше по конвейеру.

Задание 2. а) x % 2 == 0; б) x >= 10 and x <= 99; в) x < 0 and y > 0; г) (y % 4 == 0 and y % 100 != 0) or y % 400 == 0.

Задание 3. При x = 4 условие истинно: y = 8. При x = 0 условие 0 > 0 ложно: y = 0 − 5 = −5. При x = −3 условие ложно: y = −3 − 5 = −8. Обратите внимание на граничное значение 0: оно попадает в ветвь «иначе», потому что сравнение строгое.

Задание 4. Из ромба выходят две стрелки: «да» ведёт к блоку dop := (bag − 20) * 150, «нет» — к блоку dop := 0; после этих блоков стрелки сходятся и ведут к выводу dop и овалу «Конец». Форма полная, так как доплата определяется для обоих исходов.
