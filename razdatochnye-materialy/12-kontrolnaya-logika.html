Задание 1. А1 — б (0 ∨ 1 = 1); А2 — в (2⁴ = 16); А3 — а (0 ∨ 1 = 1, инверсия даёт 0); А4 — б; А5 — а (¬(1 ∧ 1) = 0). Всего 5 баллов.

Задание 2. Б1: 1 ∧ 0 ∧ 1 = 0. Б2: 0 ∧ 0 = 0, ¬A = 1, F = 0 ∨ 1 = 1. В1: наборы 00–0, 01–1, 10–1, 11–0 (исключающее ИЛИ). В2: F = (¬A ∧ ¬B) ∨ (A ∧ B). В3: F = (A ∧ B) ∨ C; при 1,0,0 получаем (0) ∨ 0 = 0; при 1,1,0 получаем 1 ∨ 0 = 1. Итого 13 баллов.

Задание 3. А1 — б (0 ∨ 1 = 1); А2 — в (2³ = 8); А3 — а (1 ∧ 1 = 1, инверсия 0); А4 — б; А5 — а. Всего 5 баллов.

Задание 4. Б1: 1 ∧ 1 = 1. Б2: 1 ∨ 0 = 1, инверсия даёт 0. В1: F = 1 на наборах 010, 100, 110 (три набора из восьми). В2: F = ¬((A ∧ B) ∨ (C ∧ D)); A ∧ B = 0, C ∧ D = 1, дизъюнкция 1, инверсия 0. В3: F = (A ∨ B) ∧ C; F = 1 на наборах 011, 101, 111 — три набора. Итого 13 баллов.
