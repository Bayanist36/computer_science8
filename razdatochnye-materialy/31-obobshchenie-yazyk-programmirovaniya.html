1Ответы к заданиям

Задание 1. Линейная — a = int(input()), действия один раз по порядку. Ветвление — if условие: elif: else:, выбор одного из вариантов. Цикл с условием — while условие:, число повторений заранее неизвестно. Цикл с переменной — for i in range(a, b):, число повторений известно. Перебор строки — for ch in s:, обработка каждого символа.

Задание 2. Условие выполняется для i = 2, 4, 6, 8. Накопитель: 2, затем 6, 12, 20. Счётчик k = 4. На экран выводится «20 4».

Задание 3. Ошибки: после заголовка цикла нет двоеточия; в условии стоит «=» вместо «==»; тело ветвления не имеет отступа и печатает все d подряд. Исправление: for d in range(1, n + 1): затем с отступом if n % d == 0: и ещё с отступом print(d). Результат: 1, 2, 3, 4, 6, 8, 12, 24.

Задание 4. а) 3 6 9; б) 5 + 0 + 7 + 4 = 16; в) три раза (о, о, о на позициях 0, 2 и 4).
