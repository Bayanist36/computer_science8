1Ответы к заданиям

Задание 1. Системы счисления: основание и вес разряда, задание — перевести число в двоичную систему. Математическая логика: высказывание и таблица истинности, задание — построить таблицу для составного выражения. Алгоритмы и исполнители: конструкция и исполнитель, задание — проследить алгоритм по шагам. Программирование: переменная и цикл, задание — определить, что выведет программа.

Задание 2. а) 11111101001₂, 3751₈, 7E9₁₆. б) 101101₂ = 32 + 8 + 4 + 1 = 45; 345₈ = 192 + 32 + 5 = 229; 2A₁₆ = 2 · 16 + 10 = 42. в) 1011 + 1101 = 11000 (11 + 13 = 24); 1101 − 111 = 110 (13 − 7 = 6); 101 · 11 = 1111 (5 · 3 = 15).

Задание 3. При A = 0, B = 0: не 0 или 0 = 1. При A = 0, B = 1: не 0 или 0 = 1. При A = 1, B = 0: не 0 или 1 = 1. При A = 1, B = 1: не 1 или 1 = 1. F истинно на всех наборах — это тавтология: если A истинно, истинна вторая часть, если A ложно, истинна первая. Высказывание о числе 2025 истинно: сумма цифр 9, значит, число делится на 9, и 2025 больше 2000.

Задание 4. Тело выполняется, пока x меньше 100. После 14 шагов x = 98, условие 98 < 100 истинно, поэтому выполняется ещё один шаг и x становится 105. На следующей проверке 105 < 100 ложно, цикл заканчивается. Выведено 105, тело выполнилось 15 раз.
