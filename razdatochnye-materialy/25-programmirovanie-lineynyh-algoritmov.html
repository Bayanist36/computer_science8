1Ключевые определения

Линейный алгоритм — алгоритм, в котором все команды выполняются последовательно, в порядке записи, и каждая ровно один раз.
Арифметическое выражение — запись из чисел, переменных и знаков арифметических операций, значение которой вычисляется по правилам приоритета.

3Опорный конспект

ЛИНЕЙНЫЙ АЛГОРИТМ: команда 1 -> ... -> команда N
  каждая выполняется ровно один раз

ОПЕРАЦИИ:  +  -  *   / (float)   // (целое)   % (остаток)   ** (степень)
ПРИОРИТЕТ: 1) **   2) * / // %   3) + -   4) скобки
СВЯЗЬ:  a = (a // b) * b + a % b
  17 // 5 = 3    17 % 5 = 2    17 / 5 = 3.4

ТИПЫ:  int(3.9) = 3   round(3.5) = 4   round(2.5) = 2
  10 / 2 = 5.0   (деление всегда float)

ОШИБКИ: 2x -> 2 * x    x^2 -> x ** 2
  a + b / 2 -> (a + b) / 2
  10 / 0 -> ZeroDivisionError

1Ответы к заданиям

Задание 1. а) 3 2 = 9, 4 * 9 = 36, 36 // 6 = 6, 100 - 6 = 94. б) 10 + 2 = 12, 12 * 3 = 36, 36 % 7 = 1. в) степень выполняется справа налево: 3 2 = 9, 2 ** 9 = 512.

Задание 2. 17 // 5 = 3; 17 % 5 = 2; -17 // 5 = -4; -17 % 5 = 3. Проверка для отрицательного числа: (-4) * 5 + 3 = -20 + 3 = -17.
