1Ключевые определения

Цикл с условием — алгоритмическая конструкция, в которой группа команд повторяется, пока проверяемое перед каждым повторением условие остаётся истинным.
Счётчик цикла — переменная, которая изменяется на каждом повторении и входит в условие продолжения цикла.

3Опорный конспект

ЦИКЛ С УСЛОВИЕМ (while)
 [ условие ? ] --нет--> выход
      | да
 [ тело цикла, изменение ]
      +--> снова к проверке условия

Python:
  i = 1
  while i <= 5:
      print(i)
      i += 1        # без этой строки - ВЕЧНЫЙ ЦИКЛ

Условие проверяется ДО тела; сразу ложно - 0 повторений

ЕВКЛИД:  while b != 0:  a, b = b, a % b   -> НОД = a
ЦИФРЫ:   n % 10 - цифра, n // 10 - убрать её

1Ответы к заданиям

Задание 1. Выведется 10 7 4 1. Проверка: 10 > 0, печать 10, i = 7; печать 7, i = 4; печать 4, i = 1; печать 1, i = −2; условие −2 > 0 ложно, цикл завершён. Тело выполнилось 4 раза.

Задание 2. В теле цикла не меняется переменная i, входящая в условие, поэтому условие i <= 5 всегда истинно. Нужно добавить строку i += 1 в тело цикла с тем же отступом, что и print. После исправления программа выведет 1 2 3 4 5 и остановится.

Задание 3. 1071 % 462 = 147 (462 · 2 = 924, 1071 − 924 = 147); пара (462, 147). 462 % 147 = 21 (147 · 3 = 441); пара (147, 21). 147 % 21 = 0; пара (21, 0). Цикл завершён: 3 итерации, НОД = 21. Для сравнения: 1071 = 21 · 51, 462 = 21 · 22, общих делителей больше нет.

Задание 4. Программа: p = 1, затем цикл while n > 0 с телом p *= n % 10 и n //= 10, после цикла print(p). Для 4729: p = 1 · 9 · 2 · 7 · 4 = 504. Для 105: 1 · 5 · 0 = 0 — ноль среди цифр обнуляет произведение, это правильный ответ, а не ошибка.
