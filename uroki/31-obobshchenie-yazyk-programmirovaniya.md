### 3\. Обобщение и систематизация (15 мин)

**Учитель:** Тема осваивалась по частям: переменная, ввод-вывод, ветвление, циклы, символы. Итог темы — умение прочитать незнакомую программу и сказать, что она делает, а затем записать свою по условию задачи.

#### 3\.1. Маршрут темы: от переменной до цикла (~2 мин)

<note type="quote">
  Программа — запись алгоритма на языке программирования, которую может выполнить компьютер.
</note>

**Учитель:** В языке программирования немного конструкций, но из них собираются любые программы. Сначала появились переменные и присваивание: появилась возможность хранить промежуточные результаты и давать им имена. Затем — ветвление: программа научилась принимать решения по условию. Потом — циклы: одни и те же действия стало можно выполнять многократно, не копируя код. Наконец, строки добавили второй тип данных, для которого работают те же приёмы перебора.

**Учитель:** Полезно помнить, что любая программа, которую мы писали, состоит из трёх слоёв: данные (переменные и их типы), действия (присваивание, ввод, вывод) и управление (ветвления и циклы). Ошибка почти всегда лежит в одном из них, и искать её надо, начиная с данных: часто программа верна, но получает на вход не то, что ожидалось.

<note type="quote">
  Самая частая причина «странного» результата — тип данных, а не логика. input() всегда возвращает строку, поэтому сравнение n > 0 для n = input() либо даёт ошибку, либо работает не так, как ожидалось.
</note>

#### 3\.2. Сводка конструкций языка (~2 мин)

**Учитель:** Сводная таблица ниже — то, что нужно уметь воспроизвести по памяти на контрольной. В левом столбце конструкция, во втором — её запись на Python, в третьем — ситуация, когда её применяют.

**Учитель:** Ветвление и цикл объединяет ключевая идея — условие. В if оно решает, выполнять ли блок; в while — продолжать ли повторения. Именно поэтому логические операции and, or, not нужны в обоих случаях, а ошибки в условиях приводят к неверной работе всей программы.

**Учитель:** Обратите внимание на порядок ветвей: сначала проверяется более строгое условие, а общий случай остаётся в else. Если поменять ветви местами, число 42 попадёт в первую же подходящую ветвь и более точная проверка уже не выполнится.

| Конструкция | Запись | Когда применяют |
|:---|:---|:---|
| Линейная | a = int(input()) | действия выполняются один раз по порядку |
| Ветвление | if условие: ... elif ... else: ... | нужно выбрать один из вариантов |
| Цикл с условием | while условие: | число повторений заранее неизвестно |
| Цикл с переменной | for i in range(a, b): | число повторений известно заранее |
| Перебор строки | for ch in s: | нужно обработать каждый символ текста |

```python
x = int(input())
if x % 2 == 0 and x > 10:
    print("чётное и больше десяти")
elif x % 2 == 0:
    print("чётное, но небольшое")
else:
    print("нечётное")
```

#### 3\.3. Данные и преобразования типов (~2 мин)

**Учитель:** У каждой переменной есть тип, и тип определяет, какие операции допустимы. Сложение чисел и склейка строк записываются одинаковым знаком «плюс», но ведут себя по-разному: 2 + 3 даёт 5, а "2" + "3" даёт "23". Смешивать типы в одной операции нельзя.

**Учитель:** Преобразование выполняется функциями int(), float() и str(). Функция int("42") даёт число 42, а int("4.5") приводит к ошибке ValueError, потому что строка не является записью целого числа — для неё нужен float("4.5").

| Тип | Пример | Что хранит |
|:---|:---|:---|
| int | 42 | целое число |
| float | 3.5 | число с дробной частью |
| str | "42" | последовательность символов |
| bool | True | одно из двух логических значений |

<note type="quote">
  Функция print() выводит значения через пробел и не добавляет пояснений, поэтому "5" и 5 на экране выглядят одинаково. Ошибка типа обнаруживается не по выводу, а по операции: "5" + 3 даёт TypeError.
</note>

#### 3\.4. Как читать чужую программу: трассировка (~2 мин)

**Учитель:** Трассировка — единственный надёжный способ сказать, что выведет программа, не запуская её. Порядок работы такой: выписать переменные и их начальные значения, затем выполнять строки по одной и записывать в таблицу, как меняются значения. Для цикла таблица заполняется по итерациям, а не по строкам кода.

**Учитель:** Разберём этот фрагмент. Сначала n = 100, k = 0. Условие 100 > 1 истинно, поэтому n становится 50, k = 1. Далее 25 и 2, затем 12 и 3, затем 6 и 4, затем 3 и 5, затем 1 и 6. Теперь условие 1 > 1 ложно, цикл заканчивается, и на экран выводятся значения 1 и 6.

| Номер шага | n до шага | n после шага | k |
|:---|:---|:---|:---|
| 1 | 100 | 50 | 1 |
| 2 | 50 | 25 | 2 |
| 3 | 25 | 12 | 3 |
| 4 | 12 | 6 | 4 |
| 5 | 6 | 3 | 5 |
| 6 | 3 | 1 | 6 |

<note type="quote">
  Обратите внимание на деление нацело: 25 // 2 = 12, а не 12,5. Если бы в программе стоял обычный знак «/», значение стало бы вещественным, условие n > 1 выполнялось бы почти бесконечно, и результат оказался бы совсем другим.
</note>

```python
n = 100
k = 0
while n > 1:
    n = n // 2
    k = k + 1
print(n, k)
```

#### 3\.5. Типичные ошибки: что искать в первую очередь (~2 мин)

**Учитель:** На контрольной проверяющий смотрит не только на результат, но и на запись. Пять ошибок встречаются чаще остальных, и почти все они связаны с синтаксисом, а не с алгоритмом.

**Учитель:** Отдельно стоит запомнить ошибку с делением. Операция «/» всегда даёт вещественный результат, а «//» — целую часть. При работе с цифрами числа нужна именно целая часть, иначе остаток от деления никогда не станет нулём и цикл не закончится.

| Ошибка | Как проявляется | Как исправить |
|:---|:---|:---|
| Нет int() при вводе | сравнение строки с числом, TypeError | n = int(input()) |
| = вместо == | SyntaxError в условии | if n % 2 == 0: |
| Нет двоеточия | SyntaxError после условия | поставить «:» в конце строки |
| Сбит отступ | тело цикла выполняется не то число раз | выровнять блок четырьмя пробелами |
| Граница range | не хватает последнего значения | range(1, n + 1) |

<note type="quote">
  Ошибка отступа в Python — не оформление, а синтаксис. Строка с неверным отступом либо вызовет IndentationError, либо окажется вне цикла, и тогда выполнится один раз вместо нужных ста.
</note>

#### 3\.6. Как выбрать конструкцию под задачу (~2 мин)

**Учитель:** Порядок действий при решении задачи почти всегда одинаков. Сначала выписываем, что дано и что нужно получить, и какого типа эти величины. Затем ищем в формулировке повторяющееся действие: «для каждого числа», «для всех цифр», «пока не...». Если повторений заведомо известное количество — берём for и range; если работа идёт до наступления события — while.

**Учитель:** Этот фрагмент показывает, как соединяются приёмы разных уроков: число превращается в строку, строка перебирается циклом for, каждый символ преобразуется в цифру функцией int(), результат проверяется ветвлением. Именно так выглядит типовая задача итогового урока.

<note type="quote">
  Проверка на малых числах спасает от большинства ошибок: подставьте n = 1, n = 9, n = 10 и посмотрите, совпадает ли вывод с ожидаемым. Если расходится на границе — почти всегда виновата граница range или условие цикла.
</note>

```python
n = 2025
s = 0
for d in str(n):
    s = s + int(d)
print(s)                    # 9
if s % 9 == 0:
    print("делится на 9")
```
