### 3\. Изучение нового материала (20 мин)

**Учитель:** Составное высказывание вычисляют, а не «понимают»: значение каждой части подставляют в выражение и последовательно заменяют операции их результатами. Порядок замен задаёт приоритет, а скобки могут его изменить.

#### 3\.1. Что значит вычислить составное высказывание (~4 мин)

<note type="quote">
  Истинность составного высказывания — его значение (0 или 1), которое оно принимает при данных значениях входящих в него элементарных высказываний.
</note>

**Учитель:** Составное высказывание отличается от элементарного тем, что содержит другие высказывания внутри себя. Если известны значения всех внутренних частей, значение целого определяется однозначно: его можно получить механически, не вдумываясь в смысл фразы. В этом и сила логики — она позволяет заменить понимание вычислением.

**Учитель:** Вычисление всегда идёт одинаково: выписываем выражение, подставляем вместо букв нули и единицы, затем заменяем операции их результатами, пока не останется одно число. Каждая замена уменьшает число операций на одну, поэтому процесс обязательно заканчивается. Для выражения с четырьмя операциями понадобится ровно четыре шага.

**Учитель:** Полезно сразу договориться о форме ответа: число 0 или 1 плюс словесная расшифровка «ложно» или «истинно». Запись «получилось примерно истинно» недопустима, потому что в логике нет степеней истинности — есть только два значения.

| Шаг | Что делаем | Пример для F = A ∧ (B ∨ ¬C) при A = 1, B = 0, C = 1 |
|:---|:---|:---|
| 1 | Записываем выражение и значения переменных | A ∧ (B ∨ ¬C) |
| 2 | Вычисляем действие во внутренних скобках | ¬C = ¬1 = 0 |
| 3 | Продолжаем по приоритету внутри скобок | B ∨ 0 = 0 |
| 4 | Выполняем последнюю операцию и записываем ответ | 1 ∧ 0 = 0 |

<note type="quote">
  Значения переменных в задаче задаются один раз и не меняются по ходу решения. Если в выражении A ∧ (B ∨ ¬A) буква A встретилась дважды, она принимает одно и то же значение в обоих местах, поэтому отрицание ¬A вычисляют сразу для всех вхождений.
</note>

#### 3\.2. Приоритет логических операций (~4 мин)

**Учитель:** Если в выражении несколько разных операций, они выполняются не слева направо, а по старшинству. Старшая операция — отрицание: оно применяется к ближайшему высказыванию раньше всех. Следующая по старшинству — конъюнкция, самая младшая — дизъюнкция. Мнемоническое правило короткое: **НЕ, И, ИЛИ**, от старшего к младшему.

**Учитель:** Аналогия с арифметикой здесь почти полная: в выражении 2 + 3 · 4 сначала умножают, потому что умножение старше сложения, и лишь потом складывают. Так же в A ∨ B ∧ C сначала вычисляют B ∧ C, а результат присоединяют к A. Разница только в том, что «умножением» здесь служит конъюнкция, а «сложением» — дизъюнкция.

**Учитель:** Отрицание старше всех, но его действие ограничено ближайшим операндом: в записи ¬A ∧ B отрицается только A. Если нужно отрицать всё выражение, его заключают в скобки: ¬(A ∧ B). Это различие — источник самой частой ошибки в теме, и на нём стоит задержаться.

| Приоритет | Операция | Знак | Пример записи |
|:---|:---|:---|:---|
| 1 (старшая) | отрицание | ¬ | ¬C |
| 2 | конъюнкция | ∧ | B ∧ ¬C |
| 3 (младшая) | дизъюнкция | ∨ | A ∨ B ∧ ¬C |

<note type="quote">
  Приоритет — это соглашение о записи, а не свойство самой фразы. Поэтому одну и ту же мысль можно записать по-разному, и ответственность за однозначность лежит на том, кто составил выражение. Если сомневаетесь, как вас поймут, ставьте скобки.
</note>

#### 3\.3. Скобки меняют порядок (~4 мин)

**Учитель:** Скобки работают как в арифметике: всё, что внутри, вычисляется до операций снаружи. При вложенных скобках движение идёт изнутри наружу — сначала самая внутренняя пара, затем следующая. В выражении ¬((A ∨ B) ∧ C) порядок такой: A ∨ B, затем конъюнкция с C, и только потом отрицание результата.

**Учитель:** Разница между выражениями A ∨ B ∧ C и (A ∨ B) ∧ C не косметическая. Возьмём A = 1, B = 1, C = 1. В первом случае сначала B ∧ C = 1 ∧ 1 = 1, затем 1 ∨ 1 = 1. Во втором сначала A ∨ B = 1, затем 1 ∧ C = 1 ∧ 1 = 1 — здесь значения совпали. А при C = 0 первый вариант даст 1 ∨ 0 = 1, второй — 1 ∧ 0 = 0. Один и тот же набор значений приводит к разным ответам, и виноваты только скобки.

**Учитель:** Практическое правило оформления: ставьте скобки всюду, где порядок может быть понят двояко. Лишняя пара скобок не меняет значения, недостающая — меняет. Единственное исключение — внешние скобки вокруг всего выражения: запись (A ∨ B) и A ∨ B означают одно и то же, и в ответах их обычно опускают.

```text
Сравним при A = 1, B = 1, C = 0

A ∨ B ∧ C   = 1 ∨ (1 ∧ 0) = 1 ∨ 0 = 1
(A ∨ B) ∧ C = (1 ∨ 1) ∧ 0 = 1 ∧ 0 = 0
```

#### 3\.4. Как оформить решение по шагам (~4 мин)

**Учитель:** Аккуратная запись решения экономит время на проверке. На каждом шаге выписывайте выражение целиком, заменяя только одну операцию её значением; остальные части переписывайте без изменений. Так видно, что именно изменилось, и ошибку легко найти, вернувшись на шаг назад.

**Учитель:** Типичная ошибка — считать слева направо, «как читается». В выражении A ∨ B ∧ ¬C такой счётчик сначала сложит A и B, и результат окажется другим. Второй источник ошибок — потеря отрицания при переносе: ученик записывает ¬C = 0, а дальше подставляет C = 1. Поэтому промежуточные значения лучше подписывать: рядом с шагом писать, что именно вычислено.

**Учитель:** Последний шаг — смысловая проверка. Переведите результат обратно на русский язык и спросите себя, согласуется ли он со здравым смыслом. Если выражение описывает реальную ситуацию, а ответ ей противоречит, вероятнее всего, ошибка в расстановке скобок или в значениях элементарных высказываний.

```text
Дано: A = 1, B = 0, C = 1.  Найти F = A ∧ (B ∨ ¬C).

1) ¬C = ¬1 = 0
2) B ∨ ¬C = 0 ∨ 0 = 0
3) A ∧ (B ∨ ¬C) = 1 ∧ 0 = 0

Ответ: F = 0, высказывание ложно.
```

#### 3\.5. От фразы к значению (~4 мин)

**Учитель:** Многие задачи начинаются не с выражения, а с фразы на русском языке. Порядок перевода всегда один: выделить элементарные высказывания и обозначить их буквами, определить связки, записать выражение знаками и расставить скобки по смыслу. Только после этого подставляют значения и вычисляют.

**Учитель:** Союз «но» почти всегда означает конъюнкцию: «дорого, но надёжно» значит «дорого и надёжно». Оборот «неверно, что» ставит отрицание перед всей следующей за ним частью, поэтому такую часть нужно закрывать скобками: «Неверно, что A и B» — это ¬(A ∧ B), а не ¬A ∧ B.

**Учитель:** Программа полезна как проверка: в Python действует тот же приоритет `not`, `and`, `or`, поэтому записанное выражение можно вычислить и сверить со своим решением. Совпадение не гарантирует правильности перевода фразы, но расхождение всегда означает ошибку — либо в переводе, либо в арифметике нулей и единиц.

| Слова в фразе | Знак в выражении |
|:---|:---|
| «и», «а также», «но», «при этом» | ∧ |
| «или», «либо» в перечислительном смысле | ∨ |
| «не», «неверно, что» | ¬ |
| «если …, то …» | в базовый набор не входит |

```python
A, B, C = True, False, True          # значения высказываний
print(A and (B or not C))            # False
print((A or B) and not C)            # False
print(not (A and B) or C)            # True
```
