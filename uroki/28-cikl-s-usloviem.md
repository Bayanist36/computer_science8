### 3\. Изучение нового материала (20 мин)

**Учитель:** Если число повторений заранее неизвестно, программа должна повторять действия, пока выполняется условие. Цикл `while` — это «пока», и его главная опасность в том, что условие может никогда не стать ложным.

#### 3\.1. Зачем программе цикл (~4 мин)

<note type="quote">
  Цикл с условием — алгоритмическая конструкция, в которой группа команд повторяется, пока проверяемое перед каждым повторением условие остаётся истинным.
</note>

**Учитель:** Цикл — это конструкция, которая заставляет программу вернуться назад и выполнить те же команды снова. Если число повторений известно, его можно посчитать заранее; если неизвестно — повторяют до тех пор, пока выполняется некоторое условие. Второй случай и называется циклом с условием.

**Учитель:** В Python такой цикл записывается словом `while` («пока»). После него, как и у `if`, ставится условие и двоеточие, а тело цикла выделяется отступом. Отличие в том, что после выполнения тела управление возвращается к проверке условия, а не идёт дальше.

<note type="quote">
  Условие цикла формулируют как условие продолжения: «пока i не больше пяти», а не «пока i меньше или равно пяти — стоп». Ошибка в формулировке даёт либо лишнее повторение, либо ни одного.
</note>

```text
Схема цикла while:

        (начало)
           |
      [ i <= 5 ? ] --нет--> (выход из цикла)
           | да
     [ тело цикла ]
     [ i = i + 1  ]
           |
           +------ обратно к проверке
```

#### 3\.2. Как работает while (~4 мин)

<note type="quote">
  Счётчик цикла — переменная, которая изменяется на каждом повторении и входит в условие продолжения цикла.
</note>

**Учитель:** Порядок работы `while` всегда одинаков: проверить условие, если истинно — выполнить тело, вернуться к проверке, и так до первого ложного результата. Если условие ложно с самого начала, тело не выполнится ни разу — это не ошибка, а нормальное поведение.

**Учитель:** Программа выведет `1 2 3 4 5 готово`. Переменная `i` здесь — счётчик: она хранит номер текущего повторения. Без строки `i += 1` счётчик не меняется, условие `i <= 5` остаётся истинным навсегда, и цикл никогда не закончится.

<note type="quote">
  Тело цикла должно влиять на условие. Если внутри цикла ни одна переменная из условия не меняется, программа зацикливается: она не падает с ошибкой, а просто работает бесконечно, и её приходится останавливать вручную.
</note>

```python
i = 1
while i <= 5:
    print(i, end=" ")
    i += 1
print("готово")
```

#### 3\.3. Вечный цикл и ошибки счётчика (~4 мин)

**Учитель:** Зацикливание — самая частая ошибка в теме. Программа при этом выглядит безобидно: она что-то печатает или считает, просто никогда не останавливается. В среде Python это видно по бесконечному потоку вывода и «зависшему» окну; остановить программу можно прерыванием выполнения (Ctrl+C в консоли или кнопка остановки в среде).

**Учитель:** Второй по частоте источник проблем — граница. Цикл `while i < 5` при `i = 1` и шаге 1 выполнит тело четыре раза, а `while i <= 5` — пять. Прежде чем запускать программу, полезно вручную проверить два значения: начальное и то, на котором цикл должен остановиться.

| Ошибка | Как выглядит | Что произойдёт |
|:---|:---|:---|
| Счётчик не меняется | while i <= 5: print(i) | бесконечный цикл |
| Шаг больше нужного | while i <= 5: ... i += 2 | обработаны не все значения |
| Неверное направление | i = 5, затем i += 1 | тело не выполнится ни разу |
| Условие с >= вместо > | while i < 5 ... i >= 5 | лишнее или недостающее повторение |

<note type="quote">
  Цикл, который не выполнился ни разу, — тоже повод для проверки, а не для радости. Если программа «ничего не сделала», чаще всего начальное значение уже нарушает условие: например, i = 10 при условии i < 5.
</note>

#### 3\.4. Алгоритм Евклида (~4 мин)

**Учитель:** Алгоритм Евклида — древний способ найти наибольший общий делитель двух чисел, и он идеально ложится на цикл с условием. Правило такое: пока второе число не равно нулю, заменяем пару (a, b) парой (b, остаток от деления a на b). Когда второе число стало нулём, первое и есть НОД.

**Учитель:** Строка `a, b = b, a % b` в Python выполняется особым образом: сначала вычисляются оба значения справа, и только потом они присваиваются. Поэтому обмен не портит данные — в других языках для этого понадобилась бы временная переменная.

<note type="quote">
  Условие `b != 0` проверяется до тела, поэтому при вводе второго числа, равного нулю, цикл не выполнится ни разу, и программа сразу выведет НОД, равный первому числу. Это математически верно.
</note>

```python
a = int(input("Первое число: "))
b = int(input("Второе число: "))
while b != 0:
    a, b = b, a % b
print("НОД =", a)
```

#### 3\.5. Разбор цифр числа (~4 мин)

**Учитель:** Пока число больше нуля, у него есть хотя бы одна цифра, и с ней можно что-то сделать. Последняя цифра получается остатком от деления на 10, а чтобы перейти к следующей, число делят нацело на 10. Эти два действия в цикле позволяют обработать все цифры без знания длины числа.

**Учитель:** Программа выведет `сумма цифр: 22 количество: 4`. Заметим, что переменная `n` уничтожается по ходу работы: после цикла она равна нулю. Если исходное число ещё понадобится, его сохраняют в отдельной переменной до цикла.

<note type="quote">
  Для n = 0 цикл не выполнится ни разу, и количество цифр получится 0, хотя в числе 0 одна цифра. Это крайний случай, который нужно обрабатывать отдельно: проверять `if n == 0` до цикла. Для отрицательных чисел предварительно берут модуль.
</note>

```python
n = 4729
s = 0
k = 0
while n > 0:
    s += n % 10
    k += 1
    n //= 10
print("сумма цифр:", s, "количество:", k)
```

## Приложение: опорный конспект для доски

```
ЦИКЛ С УСЛОВИЕМ (while)
 [ условие ? ] --нет--> выход
      | да
 [ тело цикла, изменение ]
      +--> снова к проверке условия

Python:
  i = 1
  while i <= 5:
      print(i)
      i += 1        # без этой строки - ВЕЧНЫЙ ЦИКЛ

Условие проверяется ДО тела; сразу ложно - 0 повторений

ЕВКЛИД:  while b != 0:  a, b = b, a % b   -> НОД = a
ЦИФРЫ:   n % 10 - цифра, n // 10 - убрать её
         while n > 0:  s += n % 10; n //= 10
ПРОВЕРЬ: первое значение, последнее, ноль
```
