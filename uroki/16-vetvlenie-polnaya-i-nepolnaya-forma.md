### 3\. Изучение нового материала (20 мин)

**Учитель:** Ветвление превращает линейный алгоритм в алгоритм с выбором: исполнитель проверяет условие и идёт по одной из двух дорог. В полной форме действие предусмотрено для обоих исходов проверки, в неполной — только для одного, и путать эти формы нельзя.

#### 3\.1. Условие — вопрос с двумя ответами (~4 мин)

<note type="quote">
  Условие — утверждение, которое может быть истинным или ложным; в алгоритме оно записывается с помощью операции сравнения.
</note>

**Учитель:** Ветвление начинается с условия. Условие — это утверждение, про которое можно сказать только одно из двух: оно истинно или ложно. «Число 7 больше числа 3» — истинно, «число 7 чётное» — ложно, а «число 7 красивое» условием не является, потому что проверить его нельзя.

**Учитель:** Простое условие содержит одно сравнение. В математике используют знаки <, >, ≤, ≥, =, ≠, а в программах на Python — свои обозначения. Важно запомнить разницу между знаком присваивания и знаком сравнения: одиночное «равно» кладёт значение в переменную, двойное — сравнивает два значения и даёт истину или ложь.

**Учитель:** Условие не выполняется, а проверяется: исполнитель вычисляет его значение и получает «да» или «нет». После этого он выбирает, по какой ветви идти. Именно поэтому условие изображают ромбом с двумя выходами, а не прямоугольником действия.

| Сравнение | Математика | Python | Истинно при |
|:---|:---|:---|:---|
| больше | a > b | a > b | a = 7, b = 3 |
| меньше | a < b | a < b | a = 3, b = 7 |
| не меньше | a ≥ b | a >= b | a = 7, b = 7 |
| равно | a = b | a == b | a = 5, b = 5 |
| не равно | a ≠ b | a != b | a = 5, b = 4 |

<note type="quote">
  Классическая ошибка новичка — написать в условии `if x = 5` вместо `if x == 5`. В Python такое выражение вызовет сообщение об ошибке, а в некоторых других языках молча изменит значение переменной, и алгоритм будет работать совсем не так, как задумано.
</note>

#### 3\.2. Полная форма ветвления (~4 мин)

<note type="quote">
  Ветвление — алгоритмическая конструкция, в которой выполнение той или иной группы команд зависит от истинности условия.
</note>

**Учитель:** **Ветвление** — конструкция, в которой порядок выполнения команд зависит от истинности условия. В полной форме предусмотрены действия для обоих исходов: одна группа команд выполняется, если условие истинно, другая — если ложно.

**Учитель:** На блок-схеме полное ветвление выглядит так: ромб с условием, из него две стрелки с подписями «да» и «нет», каждая ведёт к своему блоку действий, а затем обе дороги сходятся в одну и алгоритм продолжается. В записи на алгоритмическом языке используют слова «если — то — иначе».

**Учитель:** В программе на Python та же конструкция записывается через `if` и `else`, а принадлежность команд к ветви показывают отступы. Отступ — не украшение: именно он говорит компьютеру, какие строки относятся к ветви «то», а какие — к ветви «иначе».

<note type="quote">
  Обе ветви одновременно не выполняются никогда. После завершения выбранной ветви управление переходит к первой команде после ветвления — на схеме это место, где две стрелки снова соединяются.
</note>

```text
если a > b
  то max := a
  иначе max := b
всё
```

```python
if a > b:
    max = a
else:
    max = b
```

#### 3\.3. Неполная форма ветвления (~4 мин)

<note type="quote">
  Неполное ветвление — ветвление, в котором группа команд выполняется только при истинном условии, а при ложном не выполняется ни одна команда.
</note>

**Учитель:** В неполной форме ветвь «иначе» отсутствует: команды выполняются только тогда, когда условие истинно, а при ложном условии исполнитель просто переходит к следующей команде. Так поступают, когда при одном исходе делать ничего не нужно.

**Учитель:** Классический пример — вычисление модуля: если число отрицательное, его нужно заменить противоположным; если положительное или нулевое, менять нечего. Записывается это одной ветвью без «иначе».

**Учитель:** Различать формы полезно по вопросу: «Что должно произойти, если условие ложно?» Если есть конкретное действие — нужна полная форма, если действия нет — неполная. Этот вопрос стоит задавать себе до того, как рисовать схему.

<note type="quote">
  Неполная форма — не «урезанная» полная, а самостоятельная конструкция. Добавлять пустую ветвь «иначе» с единственной командой «ничего не делать» не нужно: такая запись только запутывает читателя.
</note>

```python
if x < 0:
    x = -x
print(x)
```

#### 3\.4. Составные условия (~4 мин)

<note type="quote">
  Составное условие — условие, образованное из простых условий с помощью логических связок И, ИЛИ, НЕ.
</note>

**Учитель:** Одного сравнения хватает не всегда. «Число двузначное» — это сразу два требования: оно не меньше 10 и не больше 99. Такое условие называют составным, а его части соединяют логическими связками.

**Учитель:** Связка `and` требует, чтобы оба простых условия были истинны одновременно; `or` достаточно одного истинного; `not` меняет истину на ложь и наоборот. При вычислении действует порядок: сначала `not`, затем `and`, затем `or`, но надёжнее ставить скобки — тогда условие читается однозначно и без знания приоритетов.

| Связка | Смысл | Пример записи | Истинно при |
|:---|:---|:---|:---|
| and | И, оба сразу | x > 0 and x < 10 | x = 5 |
| or | ИЛИ, хотя бы одно | x < 0 or x > 100 | x = 150 |
| not | НЕ, отрицание | not (x == 0) | x = 7 |

<note type="quote">
  Двойное неравенство 0 < x < 10 в Python работает как составное условие, но в большинстве школьных языков (Паскаль, КуМир) его записывают через and: x > 0 and x < 10. Если перенести python-запись в такую среду, программа будет работать неверно.
</note>

#### 3\.5. Вложенные ветвления и выбор из нескольких случаев (~4 мин)

**Учитель:** Ветвь может содержать любое число команд, в том числе ещё одно ветвление. Такая конструкция называется вложенной: сначала проверяется одно условие, и только внутри выбранной ветви — второе. В Python вложенность видна по отступам: каждая следующая ступень сдвинута вправо.

**Учитель:** Когда случаев больше двух, удобнее не вкладывать ветвления друг в друга, а построить цепочку «иначе если». В Python для этого есть `elif`: условия проверяются сверху вниз, и выполняется ветвь первого истинного условия, а остальные даже не рассматриваются.

**Учитель:** Из-за такого порядка условия нельзя расставлять как попало. Если первым поставить `mark >= 30`, то ученик с 90 баллами получит 2: проверка остановится на первом истинном условии, и до более точных условий дело не дойдёт.

<note type="quote">
  В цепочке elif условия принято располагать от самого строгого к самому мягкому. Проверяйте алгоритм на границах: 85, 70, 50 и 30 баллов должны давать тот результат, который задуман.
</note>

```python
if mark >= 85:
    print(5)
elif mark >= 70:
    print(4)
elif mark >= 50:
    print(3)
elif mark >= 30:
    print(2)
else:
    print(1)
```
