## Цели урока

**Образовательная:** сформировать понятие восьмеричной системы счисления; научить переводить числа из восьмеричной в двоичную и обратно через триады, а также в десятичную через развёрнутую форму.

**Развивающая:** развивать умение находить короткий путь решения за счёт свойства системы (8 = 2³) вместо громоздких вычислений.

**Воспитательная:** воспитывать понимание практической ценности систем счисления: восьмеричная запись используется в реальных инструментах.

### 3\. Изучение нового материала (20 мин)

**Учитель:** Восьмеричная система — это «сжатая» двоичная: одна восьмеричная цифра заменяет ровно три двоичных разряда. Поэтому перевод между ними не требует вычислений, а только разбиения записи на тройки цифр.

#### 3\.1. Зачем нужна восьмеричная система (~4 мин)

**Учитель:** Двоичная система удобна электронике, но неудобна человеку: число 366 в двоичной записи занимает девять знаков, и в этой цепочке легко потерять разряд. Решение простое — договориться записывать двоичные разряды группами. Если группа содержит три разряда, то у неё всего восемь возможных состояний: от 000 до 111. Каждому состоянию можно дать одну цифру от 0 до 7 — так и получается восьмеричная система.

**Учитель:** Главное свойство, на котором держится вся тема: 8 = 2³. Именно поэтому три двоичных разряда в точности соответствуют одной восьмеричной цифре, и наоборот. Между десятичной и двоичной системами такой простой связи нет, а между восьмеричной и двоичной она есть — и переводить можно без вычислений.

**Учитель:** Связь эта не только теоретическая. Восьмеричная запись десятилетиями применяется в настройках прав доступа к файлам в Unix и Linux: запись chmod 755 означает конкретный набор разрешений. Восьмеричные коды используют и при записи управляющих символов: последовательность \101 означает код 65, то есть латинскую букву A.

<note type="quote">
  Основание 16 даёт такую же удобную связь с двоичной системой, только одна шестнадцатеричная цифра заменяет уже четыре разряда. Обе системы служат одной цели — сократить двоичную запись.
</note>

#### 3\.2. Алфавит и веса разрядов (~4 мин)

<note type="quote">
  Восьмеричная система счисления — позиционная система счисления с основанием 8, в которой используются цифры от 0 до 7.
</note>

**Учитель:** Восьмеричная система — позиционная, с основанием 8. Её алфавит содержит восемь цифр: 0, 1, 2, 3, 4, 5, 6, 7. Веса разрядов растут в восемь раз: 8⁰ = 1, 8¹ = 8, 8² = 64, 8³ = 512, 8⁴ = 4096. Уже на четвёртом разряде вес превышает четыре тысячи, поэтому восьмеричные записи получаются короткими.

**Учитель:** Значение восьмеричного числа вычисляется по общей формуле развёрнутой формы: цифра умножается на 8 в степени номера разряда, произведения складываются. Для числа 745: 7 · 64 + 4 · 8 + 5 · 1 = 448 + 32 + 5 = 485. Никаких особых правил для восьмеричной системы придумывать не нужно — формула одна для всех оснований.

| Номер разряда | 0 | 1 | 2 | 3 | 4 |
|:---|:---|:---|:---|:---|:---|
| Вес, 8 в степени | 1 | 8 | 64 | 512 | 4096 |

<note type="quote">
  В записи восьмеричного числа не может быть цифр 8 и 9. Запись 289₈ — ошибка, а не «число в восьмеричной системе». Если в задании встретилась такая цифра, значит, основание системы указано неверно.
</note>

#### 3\.3. Триады: восьмеричная и двоичная (~4 мин)

**Учитель:** Таблица триад — сердце урока, и её стоит выучить: она маленькая, но избавляет от всех вычислений. Восемь цифр дают восемь трёхразрядных кодов, и каждый код — это двоичная запись самой цифры, дополненная слева нулями до трёх знаков.

**Учитель:** Перевод из восьмеричной системы в двоичную делается заменой каждой цифры её триадой: 745₈ → 111 100 101 → 111100101₂. Перевод в обратную сторону — разбиением двоичной записи на тройки справа налево: 101101110₂ → 101 101 110 → 556₈. Разбивать нужно именно справа, потому что младший разряд должен попасть в конец последней триады.

**Учитель:** Если при разбиении слева остаётся группа из одной или двух цифр, её дополняют нулями до трёх: 10111₂ → 010 111 → 27₈. Дополнение не меняет значения, потому что добавленные нули стоят в старших разрядах. А вот в готовом ответе ведущий ноль уже не нужен: 010 111 даёт запись 27, а не 027.

| Восьмеричная цифра | Двоичная триада | Восьмеричная цифра | Двоичная триада |
|:---|:---|:---|:---|
| 0 | 000 | 4 | 100 |
| 1 | 001 | 5 | 101 |
| 2 | 010 | 6 | 110 |
| 3 | 011 | 7 | 111 |

<note type="quote">
  Две самые частые ошибки: разбиение слева направо (получается другое число) и потеря нулей внутри триады. В записи 1001₂ группы такие: 001 и 001, то есть 11₈, а не 10₈ и не 1₈.
</note>

#### 3\.4. Перевод в десятичную и обратно (~4 мин)

**Учитель:** Перевод восьмеричного числа в десятичную систему выполняется развёрнутой формой, как и для любого основания. Для коротких чисел это удобнее всего: 556₈ = 5 · 64 + 5 · 8 + 6 = 320 + 40 + 6 = 366. Проверить себя можно через двоичную запись: 101101110₂ = 256 + 64 + 32 + 8 + 4 + 2 = 366.

**Учитель:** Обратный перевод из десятичной системы выполняется делением на 8 с записью остатков. Остатки при делении на 8 могут быть любыми числами от 0 до 7 — это и есть восьмеричные цифры. Читаем их снизу вверх, как при переводе в двоичную систему. Для 2024: 2024 : 8 = 253 (остаток 0), 253 : 8 = 31 (остаток 5), 31 : 8 = 3 (остаток 7), 3 : 8 = 0 (остаток 3). Получаем 3750.

**Учитель:** Третий путь — через двоичную систему: перевести число в двоичную запись делением на 2, затем разбить её на триады. Он длиннее, зато не требует помнить степени восьмёрки. На практике выбирают тот способ, который быстрее в конкретной задаче: для коротких чисел — развёрнутая форма, для длинных — триады.

<note type="quote">
  Остаток при делении на 8 — это уже готовая восьмеричная цифра, переводить его никуда не нужно. Ошибка — записывать остаток 5 как 101, а потом склеивать такие «коды»: получится неверная запись.
</note>

```text
2024 -> 8
2024 : 8 = 253  остаток 0
 253 : 8 =  31  остаток 5
  31 : 8 =   3  остаток 7
   3 : 8 =   0  остаток 3
Читаем снизу вверх: 3750

Проверка: 3*512 + 7*64 + 5*8 + 0 = 1536 + 448 + 40 = 2024
```

#### 3\.5. Как не ошибиться: проверка и сравнение (~4 мин)

**Учитель:** Восьмеричные числа легко перепутать с десятичными, потому что запись состоит из привычных цифр. Число 40₈ — это 32, а не сорок; 100₈ — это 64, а не сто. Поэтому основание всегда указывают нижним индексом, а при сравнении чисел из разных систем сначала переводят их в одну.

**Учитель:** Самоконтроль устроен просто: любой ответ можно получить двумя путями. Перевели 745₈ в двоичную через триады — проверьте результат развёрнутой формой. Перевели 2024 в восьмеричную делением — проверьте умножением цифр на веса разрядов. Если два пути дали одно число, ошибки почти наверняка нет.

**Учитель:** В Python восьмеричные числа записываются с префиксом 0o, а функция oct переводит десятичное число в восьмеричную запись. Эти команды удобны для проверки домашних заданий: они не объясняют алгоритм, но мгновенно показывают, верен ли ответ.

```python
>>> oct(2024)
'0o3750'
>>> int('745', 8)
485
>>> int('0o3750', 8)
2024
```

```

веса: 1  8  64  512  4096
ключ: 8 = 2^3  ->  одна цифра = ТРИ двоичных разряда

ТРИАДЫ
 0=000  1=001  2=010  3=011
 4=100  5=101  6=110  7=111

  745(8) -> 111 100 101 -> 111100101(2)

8 -> 10: развернуть по весам
  556(8) = 5*64 + 5*8 + 6 = 366

  2024 -> 3750(8)

ПРИМЕНЕНИЕ: chmod 755 = 111 101 101 (rwx r-x r-x)
```
