### 3\. Изучение нового материала (20 мин)

**Учитель:** Программа — это алгоритм, переведённый на формальный язык, который понимает машина. Между замыслом и работающей программой стоят переводчик-транслятор и набор инструментов программиста — система программирования.

#### 3\.1. От алгоритма к программе (~4 мин)

<note type="quote">
  Язык программирования — формальный знаковый язык, предназначенный для записи алгоритмов в виде, пригодном для выполнения компьютером.
</note>

**Учитель:** Алгоритм, записанный словами, человек поймёт, а компьютер — нет. Фраза «возьми примерно половину» для машины бессмысленна: у неё нет ни опыта, ни здравого смысла, чтобы истолковать «примерно». Поэтому алгоритм приходится переписывать на языке, где каждая запись имеет ровно одно значение, — на языке программирования.

**Учитель:** Формальный язык устроен как игра с жёсткими правилами. У него есть **алфавит** — набор допустимых символов, **синтаксис** — правила построения конструкций и **семантика** — правила их смысла. Если нарушено хотя бы одно из трёх, программа не заработает: `pront("Привет")` выглядит почти правильно, но такого слова в алфавите языка нет.

<note type="quote">
  Программу нельзя «понять по смыслу», как понимают просьбу. Её можно только выполнить по правилам. Поэтому компьютер честно выполнит и бессмысленную с точки зрения человека команду, если она записана верно.
</note>

#### 3\.2. Языки высокого и низкого уровня (~4 мин)

**Учитель:** Самый низкий уровень — **машинный код**: команды записаны двоичными числами, и процессор выполняет их напрямую. Человеку такая запись почти недоступна: одна цифра не на месте — и команда означает совсем другое действие. Следующая ступень — **ассемблер**, где двоичным кодам сопоставлены короткие имена: `MOV`, `ADD`, `JMP`. Читать стало легче, но думать всё ещё приходится в терминах регистров и ячеек памяти.

**Учитель:** Языки **высокого уровня** позволяют записывать действие, а не последовательность операций процессора. В Python строка `print("Привет")` означает «выведи текст», и программисту не нужно знать, в каком регистре окажется каждый байт. Одна команда такого языка при переводе превращается в десятки машинных.

| Уровень | Пример записи | Близость к процессору | Читаемость |
|:---|:---|:---|:---|
| Машинный код | 10110100 00001001 | прямая | низкая |
| Ассемблер | MOV AH, 09h | высокая | низкая |
| Высокий уровень | print("Привет") | низкая | высокая |

<note type="quote">
  «Высокий уровень» — не оценка качества, а мера абстракции. Программа на ассемблере работает быстрее и занимает меньше памяти, но пишется дольше и легче ломается при переносе на другой процессор.
</note>

#### 3\.3. Компиляция и интерпретация (~4 мин)

<note type="quote">
  Транслятор — программа, которая переводит исходный текст программы в машинные команды.
</note>

**Учитель:** Программу на языке высокого уровня машина всё равно не понимает, поэтому нужен перевод. Его выполняет **транслятор**. Есть два принципиально разных способа перевода. Первый — перевести весь текст целиком и получить готовый файл с машинными командами: так работает **компилятор**. Второй — переводить и сразу выполнять по одной команде: так работает **интерпретатор**.

**Учитель:** Разница хорошо видна на аналогии с книгой. Компилятор — переводчик, который сначала переводит весь роман, а потом отдаёт читателю готовый том. Интерпретатор — синхронист, который переводит фразу за фразой по ходу выступления: если в середине оратор запнётся, слушатель это услышит, но предыдущие фразы уже прозвучали.

| Свойство | Компилятор | Интерпретатор |
|:---|:---|:---|
| Когда переводит | всю программу до запуска | по одной команде во время работы |
| Когда видна ошибка | до запуска | при выполнении этой строки |
| Скорость работы | выше | ниже |
| Пример языка | C++, Паскаль | Python |

<note type="quote">
  Ошибка в последней строке программы на Python проявится только тогда, когда выполнение до неё дойдёт. Компилятор нашёл бы её сразу, ещё до первого запуска. Именно поэтому интерпретатор удобен для обучения: программа запускается одной командой, без отдельного этапа сборки.
</note>

#### 3\.4. Система программирования (~4 мин)

<note type="quote">
  Система программирования — набор программных средств, обеспечивающих создание, трансляцию, отладку и выполнение программ.
</note>

**Учитель:** Одного языка мало: чтобы получить работающую программу, нужен набор инструментов. Его называют **системой программирования**. В минимальном виде это редактор кода, транслятор и отладчик; к ним добавляются библиотеки — заранее написанные наборы команд для типовых задач: вывода на экран, работы с файлами, вычислений.

**Учитель:** Современные системы программирования объединяют все инструменты в одном окне и называются **средами разработки**. В поставку Python входит среда IDLE: в ней есть редактор с подсветкой синтаксиса, кнопка запуска и окно вывода. Отдельно существуют более мощные среды — PyCharm, Visual Studio Code, — но принцип тот же: текст, перевод, запуск, отладка.

| Инструмент | Назначение |
|:---|:---|
| Редактор кода | набор и правка текста программы |
| Транслятор | перевод программы в машинные команды |
| Отладчик | пошаговое выполнение и поиск причин ошибок |
| Библиотека | готовые команды для типовых задач |

#### 3\.5. Первая программа на Python (~4 мин)

**Учитель:** Команда `print` — самая простая в Python: она выводит на экран то, что стоит в скобках. Текст (в программировании его называют строкой) заключается в кавычки, число пишется без них. Кавычки — часть записи, а не часть текста: `print("Привет")` покажет `Привет` без кавычек.

**Учитель:** Если в скобках перечислить несколько значений через запятую, `print` выведет их в одну строку, разделив пробелом. Выражение без кавычек Python сначала вычислит, а потом покажет результат. Именно из-за этого `print("2+3")` и `print(2+3)` дают разные ответы.

**Учитель:** Файл с программой сохраняют с расширением `.py`, например `hello.py`. В IDLE запуск выполняется клавишей F5 или командой Run → Run Module. Если в тексте есть синтаксическая ошибка — незакрытая скобка, пропущенная кавычка, — программа не начнёт выполняться вовсе: интерпретатор сначала проверяет запись целиком.

<note type="quote">
  Текст в кавычках выводится буквально, выражение без кавычек вычисляется. `print("2+3")` покажет `2+3`, а `print(2+3)` — число `5`. Путаница между строкой и выражением — самая частая ошибка новичка.
</note>

```python
print("Привет, 8 класс!")
print("Сегодня:", "9 ноября")
print(2026 - 2012)
```
