### 3\. Изучение нового материала (20 мин)

**Учитель:** Обратная задача анализа алгоритма: известен результат — нужно восстановить вход. Обратный ход превращает программу в цепочку уравнений, но деление нацело и ветвление стирают часть информации, поэтому ответом часто становится не одно число, а целое множество.

#### 3\.1. Прямая и обратная задача (~4 мин)

<note type="quote">
  Обратная задача анализа алгоритма — задача, в которой по известному результату работы алгоритма требуется найти входные данные, при которых этот результат получается.
</note>

**Учитель:** Прямая задача анализа алгоритма решается исполнением: подставили вход, прошли по шагам, прочитали выход. Обратная задача ставит вопрос наоборот: известен выход, найти вход. Формально это поиск всех значений, при которых алгоритм даёт заданный результат, и именно слово «всех» делает задачу содержательной.

**Учитель:** Ответов может быть три типа. Первый: решение единственное — так бывает, когда все операции обратимы однозначно. Второй: решений несколько — типичный случай, когда в программе есть ветвление или деление нацело. Третий: решений нет — программа в принципе не может выдать такое значение, и это нужно доказать, а не просто не найти ответ.

**Учитель:** Разница между операциями видна сразу. Прибавление константы обратимо: из результата вычитаем ту же константу. Умножение на ненулевое число обратимо, но только если результат делится нацело. Деление нацело и остаток от деления информацию теряют: из результата 5 после n // 2 нельзя узнать, было ли n равно 10 или 11.

| Операция | Обратное действие | Сколько решений |
|:---|:---|:---|
| a = a + 7 | вычесть 7 | одно |
| a = a * 3 | разделить на 3 | одно, если делится нацело |
| a = a // 2 | взять 2a и 2a + 1 | два |
| a = a % 10 | восстановить нельзя | бесконечно много |
| a = -a | взять противоположное | одно |

<note type="quote">
  Обратный ход работает только для операций, которые действительно выполнялись. Если ветвь не была выбрана, её уравнение не имеет отношения к делу — решение из «чужой» ветви нужно отбросить проверкой условия.
</note>

#### 3\.2. Обратный ход по присваиваниям (~4 мин)

**Учитель:** Обратный ход — это решение цепочки уравнений с конца. Пусть программа состоит из присваиваний a = a * 3, затем a = a + 4, затем a = a // 2, и вывела 20. Обозначим значение перед каждым шагом новой буквой: перед делением было b, перед прибавлением c, на входе a. Тогда b // 2 = 20, c + 4 = b, a * 3 = c.

**Учитель:** Первое уравнение даёт не одно значение, а два: b равно 40 или 41, потому что и 40 // 2, и 41 // 2 равны 20. Второе уравнение: c = b − 4, то есть 36 или 37. Третье: a * 3 равно 36 или 37, но 37 на 3 не делится, значит, остаётся только c = 36 и a = 12.

**Учитель:** Ключевой приём — отсечение вариантов по делимости и по типу данных. Промежуточные значения в программе с целочисленными операциями тоже целые, поэтому вариант, при котором a * 3 = 37, невозможен: он требует дробного a. Такое отсечение и делает обратный ход конечным.

<note type="quote">
  Не путайте деление нацело с обычным: уравнение b // 2 = 20 имеет два целых решения, а уравнение b / 2 = 20 — только одно. Именно поэтому в обратных задачах с // ответом часто оказывается промежуток.
</note>

```text
Вывод:                         a // 2 = 20
Шаг назад:                     a = 40 или 41
Предыдущий шаг:                a + 4 = 40 или 41  ->  a = 36 или 37
Первый шаг:                    a * 3 = 36 или 37  ->  a = 12

Проверка: 12 * 3 = 36, 36 + 4 = 40, 40 // 2 = 20
```

#### 3\.3. Ветвление: одно уравнение на каждую ветвь (~4 мин)

**Учитель:** Ветвление размножает решения: если программа может пойти по двум разным путям, то для каждого пути получается своё уравнение, и каждое даёт свой вход. Главное правило — решение, найденное для ветви, должно удовлетворять её условию. Иначе оно не относится к этой ветви и должно быть отброшено.

**Учитель:** Пусть программа вывела 8. Для первой ветви уравнение 2x = 8 даёт x = 4; проверяем условие: 4 >= 0 истинно, решение подходит. Для второй ветви уравнение −x = 8 даёт x = −8; проверяем: −8 >= 0 ложно, значит, ветвь else действительно выбрана, и решение подходит. Итого два ответа.

| Ветвь | Условие ветви | Уравнение | Кандидат | Проверка условия |
|:---|:---|:---|:---|:---|
| первая | x >= 0 | 2x = 8 | 4 | подходит |
| вторая | x < 0 | −x = 8 | −8 | подходит |

<note type="quote">
  Если поменять условие на x > 0, число 0 перестанет попадать в первую ветвь: для результата 0 решение x = 0 найдётся уже во второй ветви, а не в первой. Поэтому проверять условие ветви нужно для каждого кандидата отдельно.
</note>

```python
x = int(input())
if x >= 0:
    y = x * 2
else:
    y = -x
print(y)
```

#### 3\.4. Циклы и потеря информации (~4 мин)

**Учитель:** Цикл с известным числом повторений разворачивается в цепочку одинаковых операций, и обратный ход выполняется столько же раз, сколько было итераций. Если тело цикла делит число нацело на 2, то один обратный шаг превращает значение v в промежуток от 2v до 2v + 1, а каждый следующий шаг удваивает ширину промежутка.

**Учитель:** Восстанавливаем вход. Перед последним делением n было 10 или 11. Перед вторым — от 20 до 23. Перед первым — от 40 до 47. Все восемь значений дают на выходе 5, и ни одно другое число этого не даёт: 39 после трёх делений даёт 4, а 48 даёт 6.

**Учитель:** С остатком от деления дело хуже: уравнение n % 10 = 7 имеет бесконечно много решений — все числа, оканчивающиеся на 7. Если таких условий в программе несколько, восстановить вход можно только в пределах известного диапазона, например «двузначное число».

| Сколько делений прошло | Промежуток значений | Ширина |
|:---|:---|:---|
| 1 | от 10 до 11 | 2 |
| 2 | от 20 до 23 | 4 |
| 3 | от 40 до 47 | 8 |

<note type="quote">
  Ширина промежутка после k делений нацело на 2 равна 2 в степени k. Это удобно помнить: три деления дают 8 вариантов, четыре — 16, десять — больше тысячи, и тогда обратную задачу решают подбором с проверкой.
</note>

```python
n = int(input())
for i in range(3):
    n = n // 2
print(n)                # 5
```

#### 3\.5. Подбор с проверкой и оформление ответа (~4 мин)

**Учитель:** Когда промежуток решений широкий, а уравнение с остатком не решается в общем виде, используют подбор с проверкой: перебирают допустимые входы и оставляют те, при которых программа даёт нужный результат. Подбор не отменяет рассуждения — он его дополняет: диапазон перебора берут из условия задачи, а полноту ответа обеспечивает полный проход по диапазону.

**Учитель:** Порядок действий при решении обратной задачи одинаков. Сначала выписываем цепочку действий программы и отмечаем, какие из них обратимы однозначно. Затем идём с конца, получая на каждом шаге уравнение или промежуток. Потом отсекаем кандидатов по ограничениям: тип данных, знак, разрядность, условие ветви. В конце подставляем каждое решение в программу и убеждаемся, что оно даёт заданный результат.

**Учитель:** Эта программа подтверждает результат обратного хода: перебор всех чисел от 1 до 99 оставляет ровно восемь значений — от 40 до 47. Такой перебор полезен и как проверка, и как способ решить задачу, когда аналитический путь слишком громоздок.

<note type="quote">
  Ответ «x = 12» без пояснения, почему нет других решений, на проверке считается неполным. Обратная задача почти всегда требует либо перечисления всех значений, либо доказательства единственности.
</note>

```python
res = []
for x in range(1, 100):
    y = x
    for i in range(3):
        y = y // 2
    if y == 5:
        res.append(x)
print(res)              # 40..47
```

## Приложение: опорный конспект для доски

```
ОБРАТНАЯ ЗАДАЧА: ДАН РЕЗУЛЬТАТ, НАЙТИ ВХОД

ПРЯМАЯ:   вход ---> программа ---> выход
ОБРАТНАЯ: вход <--- обратный ход <--- выход

ОБРАТИМОСТЬ ОПЕРАЦИЙ
  +7      -7                    одно решение
  *3      /3 (если делится)     одно решение
  //2     2a, 2a+1              два решения
  %10     восстановить нельзя   бесконечно много

ОБРАТНЫЙ ХОД = СИСТЕМА УРАВНЕНИЙ С КОНЦА
  a*3 -> a+4 -> a//2 = 20
  a//2=20 -> 40,41 -> -4 -> 36,37 -> /3 -> a = 12

ВЕТВЛЕНИЕ: своё уравнение на каждую ветвь
  решение проверяем по условию ветви

ЦИКЛ: k делений нацело -> промежуток шириной 2^k
  3 деления: 40..47  (8 значений)

ОТВЕТ: все решения + проверка подстановкой
```
