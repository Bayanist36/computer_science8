### 3\. Изучение нового материала (20 мин)

**Учитель:** Линейная программа выполняет команды строго по порядку и не умеет выбирать. Оператор ветвления даёт ей второе измерение: теперь ход работы зависит от условия, а условие записывается как логическое выражение.

#### 3\.1. Почему линейной программы недостаточно (~4 мин)

<note type="quote">
  Ветвление — форма организации действий, при которой выполнение одной или другой последовательности команд зависит от истинности некоторого условия.
</note>

**Учитель:** Линейная программа похожа на рецепт, в котором нет ни одного «если»: сделай это, потом это, потом это. Так решается задача «найти площадь прямоугольника по двум сторонам». Но стоит спросить у программы «а число-то положительное?» — и линейная схема ломается: ответ зависит от того, что ввели.

**Учитель:** Ветвление позволяет выполнять разные действия при разных исходных данных. Условие в нём — это выражение, которое может быть истинным или ложным: `x > 0`, `x % 2 == 0`, `a != b`. Программа проверяет условие и идёт по той ветке, которая соответствует результату проверки.

<note type="quote">
  Условие в ветвлении — не вопрос «какое число больше», а проверка, у которой ровно два исхода: истина или ложь. Формулируйте условие так, чтобы на него можно было ответить «да» или «нет».
</note>

```text
Схема ветвления:

        (начало)
           |
      [ x > 0 ? ]
      да /     \ нет
        /       \
  [ "плюс" ]  [ "не плюс" ]
        \       /
         \     /
         (конец)

Ромб — проверка условия, прямоугольники — действия.
```

#### 3\.2. Оператор if: как Python записывает выбор (~4 мин)

<note type="quote">
  Условный оператор — команда языка программирования, которая выполняет группу действий только при истинности указанного условия.
</note>

**Учитель:** В Python выбор записывается оператором `if`. После слова `if` идёт условие, после условия — двоеточие, а с новой строки, с отступом, — команды, которые выполняются только при истинном условии. Отступ в четыре пробела и есть граница ветки: всё, что написано с отступом, принадлежит ей.

**Учитель:** Во фрагменте выше от программы зависит только одна строка. Строка `print("Работа завершена")` написана без отступа, поэтому выполняется всегда — и при положительном числе, и при отрицательном. Это самый частый источник недоразумений: ученик ставит отступ «для красоты» или, наоборот, забывает его, и программа ведёт себя не так, как задумано.

<note type="quote">
  Отступ нельзя смешивать: если начали блок четырьмя пробелами, не используйте табуляцию. Python сообщит об ошибке `IndentationError` или `TabError` ещё до запуска программы.
</note>

```python
x = int(input("Введите число: "))
if x > 0:
    print("Число положительное")
print("Работа завершена")
```

#### 3\.3. Полная форма, неполная форма и цепочка elif (~4 мин)

**Учитель:** Если после «сделать» нужно ещё и «иначе сделать другое», применяют полную форму с `else`. `else` пишется без условия и без двоеточия после условия — только с двоеточием. Ветка `else` выполняется тогда, когда условие `if` оказалось ложным.

**Учитель:** Когда вариантов больше двух, удобна цепочка `elif` (сокращение от else if). Проверка идёт сверху вниз: как только одно условие оказалось истинным, выполняется его ветка, а остальные условия уже не проверяются.

**Учитель:** При `ball = 50` первое условие ложно, второе истинно — выводится «средний уровень». При `ball = 80` истинно уже первое условие, и до проверки `>= 50` дело не доходит.

| Форма записи | Как выглядит | Сколько веток |
|:---|:---|:---|
| Неполная | if условие: | одна, может не выполниться |
| Полная | if условие: else: | две, выполняется ровно одна |
| Цепочка | if, затем elif, затем else | столько, сколько условий, плюс else |

<note type="quote">
  Порядок условий — часть алгоритма. Если в примере выше поставить `ball >= 50` первым, то для 95 баллов программа скажет «средний уровень»: до более строгого условия очередь не дойдёт.
</note>

```python
ball = int(input("Баллы: "))
if ball >= 80:
    print("высокий уровень")
elif ball >= 50:
    print("средний уровень")
else:
    print("низкий уровень")
```

#### 3\.4. Составные условия: and, or, not (~4 мин)

<note type="quote">
  Составное условие — условие, образованное из простых условий с помощью логических операций and, or и not.
</note>

**Учитель:** Одного сравнения часто мало. «Число двузначное и чётное» — это два простых условия, соединённых логической операцией `and`. «Число отрицательное или больше ста» — два условия, соединённых `or`. Логическая операция `not` отрицает условие: `not (x > 0)` истинно ровно тогда, когда ложно `x > 0`.

**Учитель:** Приоритет операций такой: сначала `not`, потом `and`, потом `or`. Скобки меняют порядок, поэтому сложное условие всегда полезно заключать в скобки — так его проще читать и проверять.

**Учитель:** В Python двойное сравнение `10 <= x <= 99` записывается так же естественно, как в математике. Оно истинно, когда выполняются оба неравенства; то же самое можно записать через `and`, но короче читается именно двойное сравнение.

| a | b | a and b | a or b |
|:---|:---|:---|:---|
| истина | истина | истина | истина |
| истина | ложь | ложь | истина |
| ложь | истина | ложь | истина |
| ложь | ложь | ложь | ложь |

<note type="quote">
  `and` требует выполнения обоих условий, `or` — хотя бы одного. Условие `x > 0 or x < 10` истинно всегда: любое число либо больше нуля, либо меньше десяти. Такие условия — типичная логическая ошибка.
</note>

```python
x = int(input("Введите число: "))
if 10 <= x <= 99 and x % 2 == 0:
    print("двузначное чётное")
else:
    print("не подходит")
```

#### 3\.5. Граничные случаи и типичные ошибки (~4 мин)

**Учитель:** Ветвление легко написать, но трудно написать правильно: ошибки прячутся не в синтаксисе, а в границах. Сравнение `x > 10` и `x >= 10` отличается ровно одним входным значением — и именно оно чаще всего встречается в проверочной работе. То же с чётностью: `x % 2 == 0` истинно для чётных, включая ноль и отрицательные чётные числа.

**Учитель:** Отдельная ловушка — сравнение вещественных чисел. Результат вычисления `0.1 + 0.2` в Python равен не ровно `0.3`, а `0.30000000000000004`, поэтому условие `D == 0` для дискриминанта может не сработать там, где математически ноль и есть. В таких задачах сравнивают с малой величиной: `abs(D) < 1e-9`.

| Ошибка | Как написано | Как надо |
|:---|:---|:---|
| Путаница присваивания и сравнения | if x = 5: | if x == 5: |
| Нет отступа у тела ветки | if x > 0: print(x) | тело с отступом в 4 пробела |
| Ветка else перед elif | else: ... elif ... | elif идёт до else |
| Потерян двоеточие | if x > 0 | if x > 0: |

<note type="quote">
  Хороший тест проверяет не только «типичное» значение. Для задачи «больше ли число десяти» нужны как минимум три проверки: 25 (истина), 3 (ложь) и 10 (граница, ответ «нет», если сравнение строгое).
</note>

Python:
