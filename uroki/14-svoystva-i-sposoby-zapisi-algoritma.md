### 3\. Изучение нового материала (20 мин)

**Учитель:** Алгоритм отличается от простого перечня действий тем, что его можно проверить: он разбит на шаги, однозначен, конечен и годится не для одного случая, а для целого класса задач. Научимся находить нарушения этих свойств и записывать один и тот же алгоритм четырьмя разными способами.

#### 3\.1. Алгоритм и его исполнитель (~3 мин)

<note type="quote">
  Алгоритм — описание конечной последовательности шагов в решении задачи, приводящей от исходных данных к требуемому результату.
</note>

**Учитель:** Слово «алгоритм» происходит от латинского написания имени аль-Хорезми — математика, работавшего в Багдаде в IX веке. Его труды по правилам вычислений переводили на латынь, и имя Algorithmi постепенно стало нарицательным: так называли любое точное правило счёта.

**Учитель:** Современное школьное определение короче исторического и опирается на два элемента: исходные данные и результат.

**Учитель:** Обратите внимание на слово «исполнитель». Алгоритм всегда адресован кому-то: человеку, роботу, компьютеру, швейной машине. Исполнитель, который выполняет команды буквально и не задумывается о смысле, называется формальным. Компьютер — формальный исполнитель: он не поймёт намёка и не исправит опечатку, зато выполнит правильную программу миллион раз без устали и без ошибок.

**Учитель:** Чтобы описание стало алгоритмом, оно должно обладать пятью свойствами. Их удобно проверять по очереди, как чек-лист перед сдачей работы.

| Свойство | Что означает | Вопрос для проверки |
|:---|:---|:---|
| Дискретность | Состоит из отдельных команд | Можно ли разбить на пронумерованные шаги |
| Понятность | Все команды входят в СКИ | Поймёт ли эти слова исполнитель |
| Определённость | Каждая команда понимается однозначно | Даст ли другой человек тот же результат |
| Результативность | За конечное число шагов есть результат | Может ли выполнение длиться бесконечно |
| Массовость | Решает класс однотипных задач | Годится ли для других исходных данных |

#### 3\.2. Дискретность и понятность (~3 мин)

<note type="quote">
  Дискретность — свойство алгоритма состоять из отдельных команд, выполняемых последовательно одна за другой.
</note>

<note type="quote">
  Понятность — свойство алгоритма содержать только команды, входящие в систему команд исполнителя.
</note>

**Учитель:** **Дискретность** означает, что алгоритм разбит на отдельные законченные шаги, которые исполнитель выполняет один за другим. Между шагами нет ничего «половинчатого»: нельзя выполнить команду наполовину и перейти к следующей. Запись «возьмите муку, добавьте воды и замесите тесто» дискретностью не обладает: непонятно, где заканчивается один шаг и начинается другой.

**Учитель:** **Понятность** требует, чтобы в записи встречались только команды, входящие в систему команд исполнителя. У Чертёжника есть команда «опустить перо», у калькулятора её нет, поэтому один и тот же текст будет алгоритмом для одного исполнителя и бессмысленным набором слов для другого.

<note type="quote">
  Понятность — свойство не текста, а пары «текст и исполнитель». Инструкция «нажмите F5» понятна человеку за компьютером и совершенно непонятна роботу-пылесосу.
</note>

#### 3\.3. Определённость и результативность (~3 мин)

<note type="quote">
  Определённость — свойство алгоритма, при котором каждая команда имеет единственное толкование, а одинаковые исходные данные всегда дают одинаковый результат.
</note>

**Учитель:** **Определённость** (её ещё называют детерминированностью) означает, что каждая команда понимается единственным образом. Если двое учеников, выполняя один алгоритм с одними и теми же данными, получили разные ответы, значит, в записи есть неоднозначность. Команда «прибавьте к числу немного» этому требованию не удовлетворяет: «немного» каждый понимает по-своему.

**Учитель:** **Результативность** означает, что выполнение алгоритма заканчивается за конечное число шагов получением результата. Алгоритм не имеет права «крутиться» бесконечно, ожидая чуда. Если в записи есть повторение, оно обязано когда-нибудь прекратиться.

**Учитель:** В этом фрагменте значение x не меняется, поэтому условие x > 0 остаётся истинным всегда: цикл не закончится никогда. Свойство результативности нарушено, хотя дискретность и понятность в порядке.

<note type="quote">
  Ловушка: наличие цикла само по себе не нарушает результативность. Нарушает её цикл, который не может завершиться, — например, такой, где условие выхода никогда не станет ложным.
</note>

```text
нач
  взять x
  пока x > 0
    вывести x
кон
```

#### 3\.4. Массовость (~3 мин)

<note type="quote">
  Массовость — свойство алгоритма решать целый класс однотипных задач при различных исходных данных.
</note>

**Учитель:** **Массовость** означает, что алгоритм пригоден для решения целого класса однотипных задач, а не для единственного случая. Алгоритм «сложить два числа» массовый: подставьте 3 и 5, 100 и 200, −7 и 2 — запись не изменится, изменится только результат. Запись «сложить 3 и 5» массовостью не обладает: это не предписание, а готовый ответ.

**Учитель:** Именно массовость делает алгоритмы ценными. Врач описывает не «как лечить Петю», а протокол лечения болезни; инженер рисует не «эту деталь», а чертёж детали с размерами-параметрами. Программист пишет функцию, которая работает для любого допустимого аргумента, иначе программа была бы бесполезной.

<note type="quote">
  В бытовых инструкциях массовость иногда сознательно не выполняют: «как пройти в кабинет 215» описывает один маршрут. В учебных задачах по информатике массовость считается обязательным свойством алгоритма.
</note>

#### 3\.5. Словесная запись и псевдокод (~3 мин)

**Учитель:** Записать алгоритм можно по-разному, и каждый способ решает свою задачу. Самый доступный — **словесная запись**: пронумерованный список команд. Требования к ней простые: одна команда на пункт, глагол в повелительном наклонении, никаких «и ещё немного помешайте».

**Учитель:** Словесная запись хороша для коротких алгоритмов и для объяснения человеку. Её недостаток — громоздкость: как только появляются условия и повторения, текст становится похож на запутанный абзац из учебника литературы, и ошибку в нём заметить трудно.

**Учитель:** **Псевдокод** — промежуточная форма: служебные слова берутся из языка алгоритмов, а вычисления записываются математическими знаками. В школьной практике используют конструкцию «нач — кон» со словами «ввод», «вывод», «если», «пока».

**Учитель:** Псевдокод не исполняется компьютером: это запись для человека. Именно поэтому в нём допустимы русские слова «ввод» и «вывод», которых нет ни в одном языке программирования. Зато псевдокод не зависит от синтаксиса конкретной среды и легко переписывается в любую программу.

```text
алг Площадь(арг a, b, рез S)
нач
  ввод a, b
  S := a * b
  вывод S
кон
```

#### 3\.6. Блок-схема по ГОСТ и программа (~3 мин)

**Учитель:** **Блок-схема** — графическая запись: каждый шаг изображается фигурой стандартной формы, а порядок шагов показывают стрелки. Формы фигур закреплены государственным стандартом ГОСТ 19.701-90 «Схемы алгоритмов, программ, данных и систем», поэтому блок-схему поймёт инженер на любом предприятии.

**Учитель:** Главное достоинство схемы — наглядность: связи между шагами видны сразу, а не вычитываются из текста. Именно поэтому блок-схемы используют при проектировании программ и при объяснении сложных алгоритмов.

**Учитель:** **Программа** — запись алгоритма на языке программирования, предназначенная для исполнения компьютером. Она самая строгая: лишняя скобка, пропущенное двоеточие или неверный отступ делают программу неработоспособной.

**Учитель:** Сравните: один и тот же алгоритм умножения двух чисел записан четыре раза — словами, псевдокодом, схемой и программой. Смысл один, а адресаты разные: человеку удобнее текст, инженеру — схема, компьютеру — программа.

| Фигура | Назначение | Надпись внутри |
|:---|:---|:---|
| Овал | Начало и конец алгоритма | Начало, Конец |
| Прямоугольник | Действие, вычисление | S := a * b |
| Параллелограмм | Ввод и вывод данных | ввод a, b |
| Ромб | Проверка условия | a > b |
| Прямоугольник с двойными стенками | Вызов вспомогательного алгоритма | Площадь(a, b) |

<note type="quote">
  В блок-схеме стрелка обязательна: без неё непонятно, какой блок выполняется следующим. У линейного алгоритма стрелка одна и идёт сверху вниз, у ветвления стрелок две — об этом на следующем уроке.
</note>

```python
a = float(input("a = "))
b = float(input("b = "))
S = a * b
print("S =", S)
```

### 4\. Первичное закрепление (12 мин)

**Учитель:** Теперь закрепим материал. Работаем по заданиям — часть устно, часть письменно.

**Задание 1. Алгоритм или не алгоритм.** Определите, какие из описаний являются алгоритмами, и назовите нарушенное свойство:
а) «Найдите сумму двух чисел»;
б) «Сложите 2 и 3»;
в) «Увеличивайте число, пока оно не станет большим 10» (без указания, на сколько увеличивать);
г) «Повторяйте упражнение, пока не надоест»;
д) «Отмерьте 200 г муки, всыпьте в миску, добавьте 100 мл воды, перемешайте 2 минуты».

**Задание 2. Соответствие свойств.** Установите соответствие между ситуацией и нарушенным свойством:
1) команда «добавьте соли по вкусу»; 2) алгоритм зациклился и не выдаёт ответ; 3) алгоритм работает только для числа 100; 4) исполнитель не знает команду «умножить».

**Задание 3. Блок-схема по словесному алгоритму.** Составьте блок-схему алгоритма «Перевести рубли в копейки»: ввести количество рублей r, вычислить k := r · 100, вывести k. Укажите, какие фигуры ГОСТ понадобятся и в каком порядке они соединяются.

**Задание 4. Символы блок-схемы.** Какая фигура ГОСТ 19.701-90 используется в каждом случае:
а) проверка, больше ли a, чем b; б) запись «S := a · b»; в) ввод стороны квадрата; г) начало алгоритма; д) вызов вспомогательного алгоритма?

**Задание 5. Чтение блок-схемы.** По схеме «Начало → ввод x, y → z := x · x − y → вывод z → Конец» найдите результат при x = 6, y = 4. Изменится ли схема, если взять x = 10, y = 1? Ответ объясните.

**Задание 6. Практическая работа на компьютере.** Откройте текстовый процессор (Word или Writer) и постройте блок-схему из задания 3. Порядок действий: вкладка «Вставка» → «Фигуры» → группа «Блок-схема» → выберите «Начало/Конец» (овал), «Процесс» (прямоугольник), «Данные» (параллелограмм). Расставьте фигуры сверху вниз, соедините их стрелками из группы «Линии», подпишите каждую фигуру, выделите все объекты и сгруппируйте, затем сохраните файл под именем blockschema.

**Учитель:** Проверим. Поднимите руку, у кого получился другой ответ. Разберём вместе.

*Ожидаемый ответ:* а) алгоритм, массовый; б) не алгоритм — нарушена массовость (одна задача, готовый ответ); в) не алгоритм — нарушена определённость (не указан шаг изменения); г) не алгоритм — нарушена результативность (условие «надоест» не проверяемо, окончание не гарантировано); д) алгоритм: шаги дискретны, количества точны, результат определён.

*Ожидаемый ответ:* 1 — Г, 2 — В, 3 — А, 4 — Б.

*Ожидаемый ответ:* Нужны три типа фигур: овал «Начало», параллелограмм «ввод r», прямоугольник «k := r · 100», параллелограмм «вывод k» и овал «Конец» — всего пять блоков. Порядок: Начало → ввод r → k := r · 100 → вывод k → Конец, блоки соединены стрелками сверху вниз; ромб не нужен, потому что алгоритм линейный.

### 5\. Обобщение и систематизация (3 мин)

**Учитель:** Подведём итог. Ответьте на контрольные вопросы:

2. В чём состоит свойство дискретности?

   *(Когда все его команды входят в систему команд исполнителя.)*
4. Чем определённость отличается от результативности?
   *(Определённость требует единственного толкования команд, результативность — получения результата за конечное число шагов.)*
5. Что означает массовость алгоритма?
   *(Пригодность решать целый класс однотипных задач при разных исходных данных.)*
6. Какие способы записи алгоритма вы знаете?
   *(Словесный, псевдокод, блок-схема, программа.)*

**Учитель:** Запишите главное, что нужно запомнить по теме «Свойства алгоритма. Способы записи алгоритма»:

- Алгоритм — описание конечной последовательности шагов в решении задачи, приводящей от исходных данных к требуемому результату.
- Дискретность — свойство алгоритма состоять из отдельных команд, выполняемых последовательно одна за другой.
- Определённость — свойство алгоритма, при котором каждая команда имеет единственное толкование, а одинаковые исходные данные всегда дают одинаковый результат.
- Массовость — свойство алгоритма решать целый класс однотипных задач при различных исходных данных.
